# IP Valuation Readiness

The system supports cost, probability-adjusted DCF, relief-from-royalty and market-comparable scenarios. Missing inputs HOLD. Automated output is not an appraisal, fairness opinion, tax opinion or guaranteed value.

## Fail-closed rule

Unknown, missing, contradictory, superseded or unverified evidence remains `HOLD`. No public page carries private evidence bodies, credentials, fingerprints, protected calibration or counsel work product.
