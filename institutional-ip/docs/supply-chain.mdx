# Software Supply-Chain Evidence

Release evidence binds exact source head, artifact digest, CycloneDX/SPDX candidates, SLSA provenance, vulnerability status and rollback. Unsigned or unverified provenance and missing vulnerability evidence remain HOLD.

## Fail-closed rule

Unknown, missing, contradictory, superseded or unverified evidence remains `HOLD`. No public page carries private evidence bodies, credentials, fingerprints, protected calibration or counsel work product.
