# Diligence Runbook

Every diligence package reconciles exact main and candidate heads, source/evidence classes, private custody, title, classification, release evidence, valuation inputs, commercial proof, rollback, specialist review and Agent D. Generated files and CI do not create quorum.

## Fail-closed rule

Unknown, missing, contradictory, superseded or unverified evidence remains `HOLD`. No public page carries private evidence bodies, credentials, fingerprints, protected calibration or counsel work product.
