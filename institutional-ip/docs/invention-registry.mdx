# Master Invention Registry

The registry assigns stable candidate IDs and records documentary states. Repository authorship, prompt authorship, executive role and file possession are not legal inventorship. Prior-art searches and counsel review remain separate evidence gates.

## Fail-closed rule

Unknown, missing, contradictory, superseded or unverified evidence remains `HOLD`. No public page carries private evidence bodies, credentials, fingerprints, protected calibration or counsel work product.
