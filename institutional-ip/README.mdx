# CrownThrive Master IP Diligence System

This system turns CrownThrive technology, methods, frameworks and operating know-how into stable evidence candidates without pretending that a generated record proves inventorship, ownership, patentability, appraisal value, customers or revenue.

## Five connected systems

1. **Master Invention Registry** — stable families, source/evidence references, conception and reduction-to-practice states, public-disclosure timeline, prior-art status and protection-strategy candidates.
2. **Chain-of-Title Evidence Graph** — creation, contribution, assignment, license, consent, restrictions, disputes, termination and successor records.
3. **Valuation Readiness** — cost, DCF, relief-from-royalty and market scenarios with mandatory source inputs and professional-review gates.
4. **Software Supply-Chain Evidence** — exact source heads, SBOMs, provenance, vulnerability evidence, artifact digests, rollback and release state.
5. **Commercial Proof** — verified external interviews, LOIs/design partners, paid pilots, payments, usage, retention, renewal and expansion.

## Institutional wiring

Framework Factory emits a candidate intake envelope. CHLOM remains the rights authority. The IP system validates title/evidence readiness and passes only references and digests. ThriveEvergreen remains the exclusive commercial activation authority and receives a preflight result, never an ECAC from this system. Repository federation requires exact heads, OIDC and non-voting transport. Private agreements, evidence bodies and protected logic remain in Vault/private custody.
