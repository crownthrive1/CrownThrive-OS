# CrownThrive Estate Evidence Candidate — September 4, 2026

This branch runs a bounded, public-only crawl for 105 domain and Vercel surfaces drawn from the canonical CrownThrive asset registry and the connected Vercel team inventory.

It does not read Gmail or Outlook, authenticate to customer areas, submit forms, mutate checkout, upload customer content, expose credentials, or treat public response content as a rights grant.

Each fetched response receives a binary SHA-256 and normalized-content fingerprint. Each target receives a deterministic observation fingerprint, availability classification, robots/sitemap evidence, and a public-page ledger. All results remain `HOLD_DAIL_UNBOUND` until the canonical CHLOM DAIL append and readback succeed.

The GitHub Actions run publishes JSON, CSV, and Markdown evidence as a retained workflow artifact. The artifact is an audit candidate, not a customer entitlement issuance, commercial activation, or public Go Flipbooks release.
