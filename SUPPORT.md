# CrownThrive Support & Repository Routing 💬

This repository is CrownThrive's public-safe institutional documentation and implementation map. Use the route below that matches what you need so private information does not end up in a public issue.

## Public documentation questions and corrections

A public GitHub issue is appropriate for:

- broken or incorrect public documentation;
- missing or broken public-safe links;
- public terminology, naming, navigation, accessibility, or formatting problems;
- a public-safe correction supported by a source you are authorized to share;
- reproducible defects in repository tooling that do not expose restricted information.

Use the repository issue templates where available. Do not include credentials, private account data, customer records, protected evidence, private contracts, or security-sensitive details.

## Private security, privacy, or credential issues

Do **not** open a public issue for:

- vulnerabilities or exploit paths;
- exposed secrets, tokens, passwords, API keys, cookies, or recovery material;
- private customer, contributor, employee, child, payment, identity, legal, health, or journal data;
- protected rights evidence or private contracts;
- private incident logs or exploit-enabling operational details.

Follow `SECURITY.md` and contact **contact@crownthrive.com** with the subject:

`Private Security Report — <affected platform or repository>`

Send only the minimum information needed to route the report. Request a controlled transfer method for protected evidence.

## Account, order, payment, or entitlement support

Do not publish order numbers, payment details, customer information, download links, entitlements, disputes, refund evidence, or account identifiers in a GitHub issue.

Contact **contact@crownthrive.com** and identify the relevant CrownThrive platform or product. Include only the minimum non-sensitive reference information needed to locate the matter.

A Stripe receipt, checkout success, or provider message is evidence from that provider and does not by itself establish a CrownThrive license, rights grant, entitlement, settlement, or other institutional state.

## Licensing, rights, partnership, media, or business inquiries

For licensing, permissions, rights, media, commercial relationships, platform partnerships, ecosystem collaboration, or business inquiries, contact:

**contact@crownthrive.com**

Public repository visibility does not grant permission to reproduce, commercialize, train on, sublicense, or otherwise exploit CrownThrive Material. See `LICENSE` and `TRADEMARKS.md`.

## Contribution questions

Before opening a pull request, read:

- `CONTRIBUTING.md`;
- `CODE_OF_CONDUCT.md`;
- `AGENTS.md`;
- `LICENSE`;
- `SECURITY.md` when applicable.

If contribution authority or rights are unclear, contact **contact@crownthrive.com** before submitting protected or third-party material.

## Response expectations

CrownThrive does not promise a specific response time through this public repository. Security, privacy, rights, payment-integrity, and safety matters may be prioritized by severity and evidence.

This repository is not an emergency service. If a situation involves immediate danger or requires emergency assistance, use the appropriate local emergency resources rather than GitHub support channels.
