# PentaRoute v3 Federation

CrownThrive-OS consumes the canonical Phase 3 PentaRoute registry from `crownthrive1/chlom-protocol/registry/pentaroute-v3.json`.

Canonical family: PentaRoute, PentaTun, PentaBeata, PentaFetch, PentaGet, PentaHead, PentaOptions, PentaPost, PentaPut, PentaPatch, PentaDelete.

Live proof:
- https://tzajnzshmtzjenqulehq.supabase.co/functions/v1/pentaroute
- https://tzajnzshmtzjenqulehq.supabase.co/functions/v1/pentabeata

Support must not redefine transport authority. Mutation authority remains operation-level, exact-path, Phase 3 write certification governed by CHLOM/PentaRoute v3. D3 and universal delete are not delegated.
