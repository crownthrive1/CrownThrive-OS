# Wave 7 Lane A — Substantive Successor

Lane A handles only low-risk records that may already have a substantive current successor. Its purpose is to increase verification throughput, not to create new authority.

## Admission gate

A record may enter only when its stable inventory identity, current target route, source relationship, and current-state family are known. It must not carry unresolved legal, rights, economic, investment, patent, franchise, identity, restricted, secret, credential, settlement, payment, provider-write, or production authority meaning.

The successor must satisfy the current substantive threshold and meaningful internal-link requirement established by [Wave 6](/knowledge/documentation-substantive-rebuild-wave-6). Claims remain governed by [Evidence, Claims and Proof](/standards/evidence-claims-and-proof-standard).

## Required receipt

```yaml
inventory_id:
legacy_title:
current_anchor:
body_threshold_passed: false
internal_link_threshold_passed: false
source_compatibility_passed: false
d2_safe: false
high_risk_flags: []
prior_wave_overlap: false
result: OPEN
parent_review_required: true
```

Only a receipt with every applicable gate passing may become `substantive_current_successor_machine_verified_parent_review`.

## Failure behavior

Failure is non-destructive. The record returns to OPEN or routes to [Lane B](/knowledge/documentation-wave-7-lane-b-specialist-evidence). It is never promoted because a title, keyword, platform name, or thematic similarity looks plausible.

## Quality objective

Lane A is optimized for exactness, deduplication, link integrity, and source-compatible current-state reconciliation. Queue speed is secondary to preserving the institutional record.
