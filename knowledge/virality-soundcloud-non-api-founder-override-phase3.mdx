## Virality Music SoundCloud Non-API Operating Rule

**Founder direction effective:** August 20, 2026  
**Current state:** adopted operating constraint unless separately superseded through governed authority

## Rule

CrownThrive / Virality Music does **not** use SoundCloud APIs as an institutional integration lane. Agents and services must not request, store, configure, certify, schedule, invoke or depend on SoundCloud API credentials, OAuth flows, authenticated SoundCloud API reads/writes, webhooks or API-dependent jobs.

The historical identifier `soundcloud.sync.daily` remains only as a drift-detection/retirement lineage marker and must not be reactivated as an API integration.

## Permitted public playback

Official public SoundCloud oEmbed, standard iframe playback and the public HTML5 Widget control surface may be used as credential-free presentation mechanisms where their own terms and product requirements allow it. Autoplay remains off by default unless a separately governed experience requires otherwise.

A working public player proves playback/presentation only. It does not prove authenticated metrics, ownership, rights, monetization, audience identity or API capability.

## Metrics and evidence

Permitted evidence includes authorized non-API reports/exports, separately supplied provider reports, accepted dated baselines and public observations classified no stronger than their evidence supports. Public observation remains `observed_unverified` unless corroborated.

**CrownLytics** remains the measurement/recommendation-evidence authority for normalized CrownThrive metrics. PentaAnalytics/PentaData may process governed evidence but do not manufacture stronger provenance.

## Penta operating binding

- PentaMedia / PentaStudios — playback and media-surface operation.
- PentaAnalytics / PentaData — governed measurement and evidence normalization.
- PentaStatus / PentaNurture — public-player health and drift monitoring.
- PentaDocs / PentaScribe — policy, evidence and terminology continuity.
- PentaCredentials / PentaCertify — enforce that no prohibited SoundCloud API credential/adapter path is promoted.

## Independent gates

Rights, canon, audience, accessibility, commerce, checkout, entitlement, distribution and production certification remain independent. This non-API rule does not itself authorize publishing, monetization, recommendation execution or customer-facing mutation.
