```text

> Cultural Imprint Engine
```

## Source precedence applied in this cohort

The macro seed uses this order:

1. current founder/institutional adjudication and accepted governance records;
2. verified current operational/legal evidence for the claim class;
3. current implementation architecture sources such as `S99`;
4. current/near-current doctrine sources `S91`, `S97`, `S98`;
5. management planning sources such as `S100`;
6. historical/target technical and prospectus sources;
7. current public representation as evidence of what is being said, not as automatic implementation authority.

A lower-precedence source is preserved even when it cannot control current state.

## Macro-to-micro propagation requirements

Each accepted macro record must become a parent/invariant for later seed cohorts.

Examples:

- every platform must resolve to one or more corridors and must not be typed as a framework solely from branding;
- every cultural/media/creative record must resolve CIE to Cultural Imprint Engine;
- every CHLOM component must carry `current`, `target`, `historical`, `research` or `unverified` implementation state independently;
- every MM Suites location/territory/economic record must inherit the legal-activation and schedule-version gates;
- every support article must resolve to source authority and projection state;
- every domain record must separate custody/registration from reachability and application capability;
- every phase label must carry a namespace;
- every platform-count metric must declare its counting universe.
