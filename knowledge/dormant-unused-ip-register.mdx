## Dormant and Unused IP Register

CrownThrive should not lose an asset merely because it is not being used today. Phase 2.7 creates a specific holding model for dormant, reserve, unactivated, experimental, merged, or superseded intellectual property.

## Required states

A dormant record should explicitly say whether it is:

- reserve
- research
- unactivated
- paused
- predecessor
- successor-pending
- merged
- renamed
- licensed-out
- sale candidate
- sunset
- archive-only

## Why this matters

The recovered CrownThrive corpus contains names and concepts that do not all appear in the current public operating map. Examples requiring disposition include BrandCards, ThriveRelay, Tribes, SuitePros, ThriveSeats, Backroad FM, MVP Roku, Melanated Culture & Heritage Museum, Digital Business Academy, NeuralCraft AI Studio, Ilyass.AI / Quantum Initiative, CrownJewel, Storytime, My CrownOasis, CrownThrive Music, ThriveStudio, Ops Oasis, ThriveMaps, SocialAIly, CrownApps, CrownInsights, ThriveFoundry, MV VoiceForge, and other historical or experimental records.

Their existence should trigger **classification**, not automatic activation.

## Minimum record

Every dormant asset should retain:

- stable institutional ID
- canonical and historical names
- asset type
- originating source
- first-known date
- last-known active date
- owner/control record
- related IP
- predecessor/successor links
- reason inactive
- current disposition
- commercialization options
- confidentiality class
- rights/evidence references
- owner validation status

## Agent rule

Agents must not publicly revive, sell, rename, license, or merge a dormant asset solely because a historical source mentions it. Any activation requires current authority, rights review, portfolio priority, and documented disposition.
