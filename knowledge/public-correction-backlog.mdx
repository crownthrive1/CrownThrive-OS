# Public Correction Backlog

This register does not authorize automatic website edits. It identifies public surfaces that should be reconciled against the approved claim register and current operating evidence.

## P0 corrections

### CrownThrive platform counts

Public surfaces currently contain 50\+, 60\+ and 80\+ ecosystem counts across different publication eras. Phase 2.98 reconfirmed this conflict on August 17, 2026: the current CrownThrive.com home page publishes `80+ platforms`, while the About/FAQ layer still publishes `over 60 integrated platforms` and `more than 60 core and auxiliary platforms`. Replace undated generic counts with either a dated approved metric or wording such as "a growing portfolio of platforms, brands, frameworks and operating assets" until the counting policy is automated. The public number should ultimately be generated from the canonical registry with explicit definitions for platform, brand, framework, engine, imprint, property, auxiliary asset, dormant asset and retired asset.

## Correction workflow

1. identify claim ID;
2. capture current public URL and wording;
3. identify authoritative source/evidence;
4. classify as temporal, stale, unsupported, ambiguous or false;
5. obtain required approval;
6. patch the public surface;
7. preserve prior wording in history;
8. verify redirects/SEO where naming changed;
9. record correction event and effective date.
