## 6. Growth and distribution

Crown Affiliates is explicitly connected to the Thrive Flywheel, CrownThriveU, CHLOM, CrownLytics, CrownPulse, ThrivePush, CrownRewards, AdLuxe, media, commerce, events, MM Suites and Locticians.

Affiliate economics remain versioned offer schedules rather than universal hard-coded percentages.

## 7. Sustainability and impact

P-12 Sustainability & Impact Evidence is restored into the architecture. EcoDrive/Stripe Climate/CII/ThriveFund claims require program-specific evidence, dates and correction history.

## 8. Platform integration principle

Every platform added during Phase 3 receives:

`stable ID → state/version → identity method → API/adapter profile → event map → rights/CHLOM map → commerce map → role surfaces → support owner → dependency/exit record`.

This lets CrownThrive integrate the portfolio incrementally rather than waiting for a single monolithic rewrite.

## 9. IP protection discipline

Phase 3 must preserve source files and hashes/references, confidentiality classes, lineage, implementation status and rights ownership. Historical patent-pending wording is not current patent status. Confidential Fingerprint/policy/economic implementation details stay outside public documentation.

## 10. Phase 3 gate

Sprint 0 should convert this manifest into machine-readable seed registries. Anything absent from the registries remains discoverable in the source/recovery backlog and cannot silently become production truth.
