# Forked Reference Dependencies

Forked repositories are governed reference dependencies. Their presence in the CrownThrive GitHub estate does not convert upstream code, documentation, trademarks, protocol specifications, or authorship into CrownThrive-originated IP.

| CrownThrive fork | Upstream/source | License observed | Permitted institutional use |
| --- | --- | --- | --- |
| `crownthrive1/public-apis` | `public-apis/public-apis` | MIT | API catalog discovery and taxonomy reference |
| `crownthrive1/openrtb` | parent `adserver-online/openrtb`; source `Tagtoo/openrtb` | Apache-2.0 | OpenRTB model/interoperability reference for PentaAds; not provider authority |
| `crownthrive1/stripe-node` | `stripe/stripe-node` | MIT | Stripe SDK integration/testing reference; not a credential, product, price, payment or account authority |

## Required fork controls

- retain upstream/source identity and license;
- pin the reviewed upstream/fork revision when incorporated;
- maintain a modification ledger for CrownThrive-authored changes;
- isolate forks from canonical CrownThrive product identity;
- never copy raw credentials, provider secrets, private customer data or protected CrownThrive internals into a public fork;
- security/license review precedes production incorporation;
- upstream success or documentation is not CrownThrive provider certification;
- prefer adapters around upstream code so CrownThrive contracts remain provider-neutral and replaceable.

## PentaAds guidance

OpenRTB structures can inform compatible schemas and validation, but PentaAds source authority remains the private `PentaAds-Placement-OS` repository, while ThriveBase remains operational state/evidence authority. The fork cannot authorize an AdLuxe/Adserver write or prove delivery.

## Commerce guidance

The Stripe SDK fork is a reference dependency only. CrownThrive commerce authority remains in governed Stripe account configuration, ThriveBase/CHLOM contracts, exact webhook/readback evidence, entitlements, refunds/disputes, and human-reserved money/rights gates.
