# Patent, Defensibility and Technical-Moat Register

The recovered institutional corpus includes patent-oriented drafts, CHLOM provisional-application materials, moat studies, sovereign-web architecture, infrastructure-evolution material, algorithmic concepts, and confidential implementation playbooks.

<Warning>
  A patent draft, provisional strategy document, invention disclosure, or research paper does **not** prove that a patent application was filed, remains pending, or resulted in an issued patent.
</Warning>

## Public-safe register fields

- `ip_record_id`
- working title
- asset/framework family
- source record
- invention/research date
- author/contributors
- confidentiality class
- draft / invention disclosure / counsel review / filed / abandoned / issued / unknown
- filing number only when verified and approved for disclosure
- related code or research
- related trademarks/content rights
- current owner/controller
- supersession relationships
- counsel-validation state

## Research families to preserve

The register should cover CHLOM technical inventions and protocol research, CrownThrive sovereign-web and infrastructure designs, identity/interoperability concepts, licensing/evidence systems, media/catalog valuation concepts, AI/automation governance techniques, phygital/booking/venue concepts, and other defensibility studies found in the Institutional Source Register.

## Defensibility is broader than patents

Institutional defensibility may also derive from:

- proprietary datasets and registries
- source lineage and evidence
- brand/trademark portfolio
- copyrighted code and media
- operating know-how
- confidential methods
- network effects
- platform integrations
- customer/community relationships
- training data and evaluation sets owned or lawfully controlled
- domain and distribution infrastructure
- cultural canon and story-world IP

Phase 3 should model these separately instead of forcing every moat into a patent narrative.
