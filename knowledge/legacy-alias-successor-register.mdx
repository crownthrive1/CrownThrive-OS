When current documentation encounters Kamora360, resolve it to **OpsOasis** unless the context is explicitly historical, forensic, contractual, archival or migration-related. Never silently rewrite the old source's wording; annotate its current successor state instead.

## Canonical rule

A current canonical term must have:

- an effective date or version;
- source authority;
- stable ID;
- prior aliases;
- successor/predecessor relationships;
- whether old URLs or public materials require redirect/correction;
- whether the legacy term remains valid in historical documents.

## Agent behavior

When an agent encounters a legacy term, it should resolve the stable ID first and then use the current canonical display name unless the task is historical, legal, forensic, or source-preserving.

Alias/successor records also drive public-safe domain and press routing. A predecessor domain may remain held for redirect, archive, defensive or continuity purposes without reactivating the predecessor brand. Public portfolio and press pages must link both the current identity and the preserved lineage where useful.
