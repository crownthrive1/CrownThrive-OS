## Purpose

Each S103 row is classified as `exact`, `alias`, `predecessor`, `framework_platform_split`, `composite_split`, or `unresolved`, then linked to existing canonical IDs and S100 portfolio rows only where those relationships are already supported by the institutional record.

## Mapping rules

- S103 source rows remain immutable historical identities.
- Canonical IDs are reused only when already present in the institutional record.
- S100 links express cross-source relationship, not one-to-one count equivalence.
- A row may map to multiple canonical IDs where the source combined legal organization, framework, platform, projection or implementation roles.
- Reserve, sunset and predecessor states do not become active merely because the S103 row existed.
- Current platform role and current implementation/deployment state remain separate.
- Later S104 v1.1 additions stay outside this 74-row historical universe.
