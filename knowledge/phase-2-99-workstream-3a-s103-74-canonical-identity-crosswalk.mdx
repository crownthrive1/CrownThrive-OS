## Phase 2.99 Workstream 3A — S103 74-Row Canonical Identity Crosswalk

## Purpose

This packet advances the exact S103 source-row recovery into a typed identity crosswalk. It does **not** force every historical row into a current platform ID. Each S103 row is classified as `exact`, `alias`, `predecessor`, `framework_platform_split`, `composite_split`, or `unresolved`, then linked to existing canonical IDs and S100 portfolio rows only where those relationships are already supported by the institutional record.

The crosswalk uses S103, the S100 68-row identity seed, the Phase 2.98 D6 long-tail disposition register, the macro source/claim seed, and current platform registries. Missing canonical IDs remain explicit rather than being invented.

## Mapping rules

- S103 source rows remain immutable historical identities.
- Canonical IDs are reused only when already present in the institutional record.
- S100 links express cross-source relationship, not one-to-one count equivalence.
- A row may map to multiple canonical IDs where the source combined legal organization, framework, platform, projection or implementation roles.
- Reserve, sunset and predecessor states do not become active merely because the S103 row existed.
- Current platform role and current implementation/deployment state remain separate.
- Later S104 v1.1 additions stay outside this 74-row historical universe.

The **classification layer** for `CT-COUNT-002` is now complete: all 74 recovered source rows have a deterministic mapping record and none are omitted, merged away or activated by naming similarity.

This does **not** close canonical resolution. Twenty rows remain `unresolved` because their stable canonical ID or exact current relationship is not yet sufficiently evidenced. Forty-nine S103 rows currently have a direct S100 portfolio relationship; the remaining S103 rows are frameworks, long-tail platforms, brands, media manifestations, predecessor/reserve identities or unresolved records absent from the 68-row management table.

No downstream phase entry or exit gate is relaxed by this packet.
