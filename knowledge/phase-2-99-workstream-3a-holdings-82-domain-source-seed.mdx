## Domain-state model

A current effective domain record must separate at least:

```yaml
domain_id:
source_domain_id:
registrable_domain:
kind: apex | subdomain | planned_subdomain
canonical_asset_id:
asset_lifecycle_state:
registrar:
registrant_or_custodian:
renewal_date:
auto_renew:
dns_authority:
dnssec:
tls_state:
http_state:
canonical_route:
redirect_target:
email_dependencies: []
deployment_refs: []
source_status:
current_verification_state:
last_verified_at:
evidence_refs: []
continuity_action:
```

A live DNS record can belong to a sunset/reserve asset, and a current platform can use a subdomain whose registrable parent is managed elsewhere. Domain state, platform lifecycle, provider state and deployment state are separate dimensions.
