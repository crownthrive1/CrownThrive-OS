## Documentation Rebuild — Wave 7 Quad-Lane Execution Contract

Wave 7 increases documentation throughput by running **four bounded work lanes in parallel** against the current **388 remaining P0 identities**. The throughput change is architectural, not evidentiary: no lane may lower the substantive-current threshold, invent source recovery, manufacture row identities, accept terminal dispositions, or convert a historical capability label into present-day authority.

The contract continues from [Documentation Substantive Rebuild — Wave 6](/knowledge/documentation-substantive-rebuild-wave-6), the [Documentation Gap & Article Rebuild Register](/knowledge/documentation-gap-article-rebuild-register), the [Documentation Reconciliation & Continuity Framework](/standards/documentation-reconciliation-continuity-framework), and [Evidence, Claims and Proof](/standards/evidence-claims-and-proof-standard).

## Four parallel lanes

| Lane | Purpose | Allowed output | Forbidden shortcut |
| --- | --- | --- | --- |
| A — Substantive successor | Verify low-risk current successor coverage | machine-qualified candidate for parent review | thematic similarity as proof |
| B — Specialist evidence | Route rights, economic, identity, governance and architecture collisions | evidence packet + hold/review recommendation | silent authority promotion |
| C — Historical body recovery | Reconstruct missing legacy bodies and source lineage | provenance-bound recovered body or explicit not-found state | inferred historical text |
| D — Terminal disposition preparation | Prepare canonical/merged/redirect/restricted/history/unresolved recommendations | disposition packet for authorized acceptance | self-accepting terminal disposition |

Each lane is independent. A record may be observed by multiple lanes, but only one lane may claim the active work lease for a given operation class. Cross-lane findings are additive and must be reconciled before any parent certification.

## Throughput multiplier

```yaml
execution_model: four_parallel_bounded_lanes
quality_gate_multiplier: 1.0
admission_threshold_reduction: 0
provenance_requirement_reduction: 0
parent_review_requirement_reduction: 0
remaining_p0_start: 388
terminal_authority_delegated: false
production_authority_delegated: false
```

"Quadruple output" therefore means four independently governed work queues, not four times as many unverified claims.

## Shared admission invariant

Every promoted substantive-successor candidate must still satisfy the existing threshold: a current successor that is substantive, internally connected, source-compatible, D2-safe, and free of unresolved authority conflicts. High-risk legal, securities/investment, patent, franchise/license, rights, economic, identity, restricted, settlement, credential, provider-write, payment, secret, or production meanings remain in their proper specialist lane.

## Deduplication and work leasing

Each record is keyed by stable inventory identity. A lane may acquire a lease only when the record is not already active for the same operation class. The work receipt must include:

```yaml
inventory_id:
lane:
source_refs: []
input_state:
proposed_output_state:
evidence_refs: []
conflicts: []
quality_checks: []
parent_review_required: true
terminal_acceptance: false
```

A failed quality check returns the record to OPEN/HOLD; it does not move the record forward merely to preserve throughput metrics.

## Exit rule

Wave 7 may report higher throughput only when receipts demonstrate completed work. Queue creation, classification, routing, or page creation alone does not count as a substantive P0 qualification. The official 61-qualified / 388-pending baseline remains unchanged until exact records pass the applicable gate.
