## Implementation described by the historical source snapshot

The following sections describe the source implementation recorded by this snapshot. They are not claims that these capabilities remain deployed or operational now.

### Public institution

The public surface includes the institutional home, ecosystem architecture, portfolio atlas, corridors, platforms, CIE, CHLOM, the canonical eight-stage Thrive Flywheel, products and services, licensing, developers, proof, status, changelog, insights, partnerships, and support.

The public projection is scope-limited. Unknown states remain unknown. Provider capability is never presented as CrownThrive operating truth.

### Private control plane

The `/command` route group includes ecosystem, platform, repository, release, documentation, integration, ThriveBase, commerce, growth, agent, governance, evidence, convergence, incident, recovery, and settings views.

Authentication uses Sites/ChatGPT identity dispatch. Authorization is server-resolved from explicit Founder, operator, and auditor allowlists. Missing allowlists fail closed. No frontend visibility rule is treated as institutional authorization.

The control plane has **no production executor** in this release. Natural-language classification is advisory; a write can only create a governed proposal envelope.

### Evidence and DAIL-compatible records

A staged proposal writes a minimized action record, a server-HMAC-pseudonymized actor reference, an audit event, and canonical `ct-canonical-json-v1` evidence to D1 in one batch. Raw intent is not persisted.

The provider-safe migration creates the evidence chain head and a unique prior-link guard. Before the first authorized staged write, the server must install four append-only triggers through prepared statements. Installation failure returns `NOT_STAGED`; no write proceeds. Records remain `UNSIGNED` until certified signing infrastructure exists.

### Machine interfaces described by the source snapshot

The application publishes:

- `/.well-known/crownthrive.json`
- versioned `/api/public/v1/*` resources
- OpenAPI and AsyncAPI contracts
- JSON Schemas
- `llms.txt`
- a bounded, stateless public MCP source route with read-only `search`, `fetch`, and dry-run `assess_governed_intent`
- sitemap, robots policy, RSS, canonical URLs, social metadata, and JSON-LD

The MCP source is deployed, but provider-native declaration and ChatGPT connection are not active. Source presence is not reported as a connected capability.

## Reconciled authority boundaries

- **CIE** is the Cultural Imprint Engine and governs cultural imprint and alignment.
- **CHLOM** governs broader authority, rights, permissions, licensing, provenance, evidence, and control.
- **PentaGreen** is the Commerce & Economic Activation Authority and resolves qualifying economic action through governed economic controls.
- CIE and CHLOM interoperate; they are not interchangeable.
- Provider success is evidence, not institutional economic truth.
- SoundCloud APIs remain `not_applicable` under the Founder override.
