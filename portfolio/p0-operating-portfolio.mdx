# P0 Operating Portfolio

The August 2026 Holdings planning set identifies a **P0 operating portfolio** intended to concentrate scarce execution capacity on the assets that create institutional control, revenue, distribution, support, data, and compounding value.

This is a dated management priority set. It can change without changing the underlying stable asset IDs.

## P0 institutional control / spine

| Asset | Primary institutional job |
| --- | --- |
| CrownThrive Holdings | Proposed portfolio stewardship and capital allocation |
| CrownThrive | Operating hub, Hybrid Incubator, services and ecosystem entry |
| CHLOM | Rights, licensing, governance, evidence and remedies |
| CrownThrive ID | Identity, SSO/federation goal, roles and consent |
| CrownThrive IO / MCP | Integration, adapters, API/tool gateway and automation connectivity |
| OpsOasis | Internal operating/task/work management concept |
| Collab Portal | Controlled partner workspace, files, approvals and signatures |

## Control rule

P0 does not mean every listed asset is equally mature. Each requires a current **status**, **working transaction/delivery path**, **owner**, **support route**, **data events**, **rights record**, **dependencies**, and **next gate**.

## Phase 3 implication

Initial CHLOM and orchestration services should be tested against P0 use cases first. P1/P2 assets should consume the same institutional APIs after the spine is proven rather than multiplying bespoke integrations.
