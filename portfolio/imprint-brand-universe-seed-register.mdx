## Required record fields

Each identity must receive stable ID, type, owner, legal entity, aliases, predecessor/successor, corridor, CIE profile, audience, lifecycle, implementation state, rights evidence, domains/routes, products, platforms, licenses, source masters, current public wording, SEO profile and review date.

The Phase 2.99 founder documentation hard gate additionally requires:

- public-safe portfolio route;
- public-safe domain role(s) where known;
- internal links to platform/corridor/domain/alias/source/changelog records;
- press-room/media-kit route or archive press disposition;
- public `Powered by CrownThrive` relationship evidence where observed;
- compact page-level changelog/version history;
- explicit current-versus-historical disposition so a reserve/sunset identity cannot be mistaken for production.

## Collision rules

- a platform and an imprint may share a public name but require separate object IDs;
- a room inside a universe is not automatically an imprint;
- a backend engine is not automatically a public brand;
- a historical name is preserved but should not create a duplicate active identity;
- `MVP` always requires namespace;
- CrownApps/ThriveApps remain one stable identity with aliases until final naming ADR;
- ThriveStudio maps to CrownThrive Studios; AdLuxe Studio remains distinct.
