# Roster and Brand Directory

The **Roster + Brand Directory** is the authoritative institutional inventory of what CrownThrive calls, owns, controls, operates, incubates, licenses, archives, or publicly routes.

## Why it exists

CrownThrive's history contains overlapping product names, vendors, archived platforms, current properties, imprints, framework names, legacy descriptions and new successor systems. Search engines and old pages should not determine the current organization chart.

## Record classes

The directory should distinguish:

- legal entities;
- operating platforms;
- customer-facing brands;
- imprints and media channels;
- internal engines/services;
- governance frameworks;
- programs and initiatives;
- product families;
- domains/deployments;
- archived/sunset assets;
- historical aliases.

## Required fields

Each record should include stable ID, canonical name, aliases, class, parent/steward, corridor, status, priority, current description, canonical URL, owner/operator, rights relationship, predecessor/successor, source authority, public visibility and last review.

## Public routing

If a public asset is archived or renamed, its directory record should identify the current destination and preserve the old name as an alias. This allows support, AI, search, redirects and partner communications to resolve old references consistently.

## PentaMedia™

`ct.framework.pentamedia` is the canonical CrownThrive media-operations framework. PentaMedia™ maintains the operational continuity layer for CrownThrive media assets, including Melanated TV, MVP, Virality Music, Locticians media, FAST/linear/OD/SYND/live surfaces, HLS/embeds, EPG, SCTE-35, SSAI, VAST and AdLuxe monetization bindings.

PentaMedia is a framework/operator layer, not a replacement name for the media brands it maintains. Its current public operational projection is `public.pentamedia_public_status_v1`, and its institutional framework record is maintained in the ThriveBase Framework Factory registry.

## Phase 3 implication

The Roster becomes a core registry consumed by CrownThrive IO/MCP, Support, websites, analytics, CHLOM, the Orchestrator and future Holdings dashboards. PentaMedia is the canonical media-maintenance framework consumed by this institutional topology.
