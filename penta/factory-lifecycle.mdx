# Factory \+ Lifecycle Pentas

This lane converts authorized needs into built, certified, maintained and terminally reconciled institutional software/work.

## PentaFactory™

**Mission:** autonomous governed software/framework production factory. **Portal:** `/io/pentas/factory`. Canonical successor to the descriptive name **PentaFramework Factory**.

## PentaSuite™

**Mission:** PentaRFA-driven agent laboratory/workspace builder with bounded TTL and lease lifecycle. **Portal:** `/io/pentas/suite`. Materializes the software, tools, workspace and execution envelope needed for an approved agent/system role.

## PentaRFA™

**Mission:** governed Request for Agent intake/decision contract. **Portal:** `/io/pentas/rfa`. Captures purpose, scope, authority, tools, TTL, risks, dependencies and acceptance/denial/conditional-acceptance terms.

## PentaJobs™

**Mission:** work planning, queueing, deadlines, dependencies and software-factory dispatch. **Portal:** `/io/pentas/jobs`. Turns directives into traceable work units with owners and terminal dispositions.

## PentaCrons™

**Mission:** scheduled execution and timezone-aware maintenance-window governance. **Portal:** `/io/pentas/crons`. Scheduling never manufactures action authority.

## PentaSpecter™

**Mission:** evidence-driven failure, defect, maintenance and remediation planning. **Portal:** `/io/pentas/specter`. Observes and classifies failure signals, then routes bounded remediation.

## PentaPR™

**Mission:** pull-request lifecycle control, stacking, nurture and terminal disposition. **Portal:** `/io/pentas/pr`.

## PentaMerge™

**Mission:** governed merge execution and merge-readiness authority. **Portal:** `/io/pentas/merge`. Merge eligibility requires exact-head evidence and applicable checks.

## PentaCloser™

**Mission:** close verified gaps and PRs after bounded remediation windows. **Portal:** `/io/pentas/closer`. Closure requires a disposition: represented, merged/remediated, intentionally held, superseded or rejected.

## PentaRelease™

**Mission:** observe, classify, version, package, publish and read back releases. **Portal:** `/io/pentas/release`. Release claims are version-specific and evidence-scoped.

## PentaTime™

**Mission:** canonical scheduling, temporal policy, clock, TTL, deadline and scheduler authority. **Portal:** `/io/pentas/time`. **PentaClock** is a superseded alias.

## PentaWave™

**Mission:** versioned wave-to-wave execution packets and continuity handoffs. **Portal:** `/io/pentas/wave`. Preserves what changed, what remains, evidence, dependencies and next-wave obligations.

## Lifecycle contract

```text
NEED → RFA → SUITE/FACTORY → JOBS → BUILD/CERTIFY → PR → MERGE → RELEASE → NURTURE/SPECTER → CLOSER → WAVE/HANDOFF
```

Every step must retain exact identity, authority, evidence, version, dependency and rollback/terminal-state information.
