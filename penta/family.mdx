# Penta Family™

The **Penta Family™** is CrownThrive's institutional operating namespace for durable software systems, control authorities, workforce systems, execution primitives, and governed specialist operators.

<Info>
  Every named Penta is treated as a real institutional subsystem. Naming alone is not production readiness. Each Penta requires a canonical identity, bounded authority, documentation, portal route, status/readback contract, access model, audit trail, release history, dependencies, escalation path, and evidence appropriate to its function.
</Info>

## Universal institutional contract

Every independently operating Penta is assigned the canonical portal pattern `/io/pentas/{slug}` and SHALL expose, when applicable: **Overview · Operate · Status · Docs · Integrations · Access · Audit · Releases · Incidents · Costs · Dependencies**.

PentaDocs is the documentation plane. CrownThrive IO is the operating/control plane. PentaStatus owns health semantics and owner reporting; PentaMail is a delivery rail; PentaConcierge owns governed service intake and fulfillment routing.

## Documentation minimum for every Penta

Each Penta section and eventual dedicated guide carries the same required documentation envelope: **Charter/Overview, User Guide, Owner/Admin Guide, Operations Runbook, API/Integration Guide, Data Model, Security/Permissions, Status/Observability, Incident/Recovery, Release/Changelog, FAQ, terminology, dependencies/provider bindings, and deprecation/supersession instructions**.

## Production truth

A public page, generated file, credential reference, installed adapter, purchased service, successful redirect, or historical plan is not enough to call a Penta production-certified. Material execution remains evidence-scoped and fail-closed when authority, credential binding, certification, provider readback, or current-state evidence is absent.

## Naming reconciliation

- **PentaTime™** is canonical; **PentaClock** is a superseded alias.
- **PentaFactory™** is canonical; **PentaFramework Factory** is a superseded descriptive name.
- **PentaDocs™** is the CrownThrive institutional system; Mintlify is the current underlying documentation provider.
- Third-party provider names never replace CrownThrive system identities.

## Owner reporting

PentaStatus aggregates immediate critical events, daily operational digests, weekly family health/readiness, and monthly lifecycle/access/documentation/dependency/release posture. PentaMail may deliver those reports, but cannot redefine status truth.
