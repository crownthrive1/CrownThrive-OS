# Runtime \+ Transport Pentas

This lane provides bounded execution and transport primitives. These primitives do not create provider authority; each call remains constrained by the caller's certified route, credential binding, policy and evidence envelope.

## PentaRoute™

**Mission:** governed request, routing and orchestration family. **Portal:** `/io/pentas/route`. Owns route selection, policy checks, destination resolution and route evidence.

## PentaTun™

**Mission:** bounded runtime execution primitive. **Portal:** `/io/pentas/tun`. Runs only inside defined execution, time, resource and authority limits.

## PentaBeata™

**Mission:** heartbeat and liveness primitive. **Portal:** `/io/pentas/beata`. Produces machine-readable liveness/readback without treating liveness as proof of full functional readiness.

## PentaFetch™

**Mission:** bounded transport/fetch primitive. **Portal:** `/io/pentas/fetch`. Performs governed retrieval through certified provider/network paths.

## PentaGet™

**Mission:** certified read/request primitive. **Portal:** `/io/pentas/get`.

## PentaHead™

**Mission:** certified HEAD/request primitive. **Portal:** `/io/pentas/head`.

## PentaOptions™

**Mission:** certified OPTIONS/request primitive. **Portal:** `/io/pentas/options`.

## PentaPost™

**Mission:** certified creation/mutation primitive. **Portal:** `/io/pentas/post`. Mutation requires explicit material-action authority and audit evidence.

## PentaPut™

**Mission:** certified replacement/mutation primitive. **Portal:** `/io/pentas/put`.

## PentaPatch™

**Mission:** certified partial-mutation primitive. **Portal:** `/io/pentas/patch`.

## PentaDelete™

**Mission:** certified deletion primitive. **Portal:** `/io/pentas/delete`. Destructive execution requires explicit authorization, target proof, rollback/recovery consideration and terminal readback.

## Operating requirements

All runtime primitives require request identity, caller authority, certified binding, timeout/retry policy, idempotency rules where relevant, telemetry, status classification, audit receipt, error taxonomy and fail-closed behavior.
