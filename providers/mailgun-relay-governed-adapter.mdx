# Mailgun Relay — Governed Adapter

**Provider:** Mailgun / Sinch  
**Domain:** `relay.crownthrive.com`  
**State:** account API read verified; domain active; domain sending verified for the internal allowlist.

## Credential separation

CrownThrive maintains two distinct provider authorities:

1. an account API credential for account/domain management and reporting;
2. a domain sending credential restricted to message sending for the relay domain.

Raw values are Vault-only and are forbidden from GitHub, Mintlify, Drive plaintext, client code, logs and public artifacts.

## Current domain evidence

Current provider evidence shows the relay domain active with Automatic Sender Security enabled. Public-safe DNS state is:

- SPF: verified;
- DKIM: current rotating selectors active/verified; a legacy selector may be inactive;
- tracking CNAME: verified;
- DMARC: configured;
- receiving MX: not verified.

The unverified MX state does not block sending by itself. Receiving MX is required only when CrownThrive intends Mailgun to receive mail for the domain; it must not be changed merely to make a sending-only configuration look fully green.

## API budget semantics

The CrownThrive local monthly request limit is `-1`, meaning no local monthly ceiling. Provider rate limits, billing and abuse protections still apply.

## Send verification and boundary

A controlled internal-recipient canary was accepted by the provider and independently observed in the destination Gmail inbox. This verifies the domain-limited sending path for the tested internal scope; it does not authorize unrestricted outbound email.

The active adapter is JWT/admin protected, rate checked, uses an allowlisted set of internal recipients and sender local-parts, and records provider request evidence without returning the credential. General cold outreach, bulk sending and recipient expansion remain outside this certified scope and require their own suppression, opt-out, compliance and abuse-prevention controls.

No secret value is exposed through the public contract.
