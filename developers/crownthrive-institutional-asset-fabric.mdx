# CrownThrive Institutional Asset Fabric

**State:** CONTROLLED TEST / GOVERNED HOLD  
**Root plugin:** `ct.plugin.institutional-asset-fabric` version `0.1.0`  
**MCP server:** `ct.mcp.institutional-asset-fabric`  
**Runtime:** `crownthrive-institutional-asset-fabric` version `0.1.0`  
**Widget resource:** `ui://crownthrive/institutional-asset-fabric.html`

The CrownThrive Institutional Asset Fabric turns CrownThrive's reusable know-how into governed, versioned institutional assets rather than disconnected files or undocumented one-off automations.

The Fabric governs:

- plugins;
- institutional pallets;
- protected kernels;
- source scripts;
- signed execution plans;
- workflows;
- provider adapters;
- agent skills;
- prompt packs;
- schemas and event contracts;
- TEVV test suites;
- policies;
- widgets and dashboards;
- runbooks;
- license and commerce candidates;
- observability and continuity packages.

## Scale model

The first deterministic matrix covers:

- 40 CrownThrive domains;
- 20 asset archetypes;
- five deployment profiles;
- 4,000 governed blueprint candidates.

A blueprint is a machine-readable candidate, not a materialized source file or production-certified asset.

The curated first suite contains:

- 32 plugin packages;
- 24 institutional pallets;
- 16 protected kernels;
- 96 script specifications;
- 64 workflow specifications;
- 64 agent-skill specifications;
- 64 prompt-pack specifications;
- 32 TEVV suites;
- 32 policy packages;
- 32 operating runbooks;
- 160 bounded execution plans;
- eight cross-ecosystem bundles.

This is 456 curated asset records plus the 4,000-blueprint matrix. Candidate records are not misrepresented as deployed code.

## Operating lifecycle

`inventory -> classify -> fingerprint -> blueprint -> dependency graph -> compile plan -> source materialization -> tests -> independent certification -> controlled package -> supersession or promotion`

Separate gates apply to:

- installation;
- public submission;
- publication;
- provider writes;
- rights and licensing;
- pricing;
- fulfillment;
- checkout;
- entitlements;
- D3 decisions;
- sovereign governance.

Until the applicable installation gate passes, candidate assets are **not installed**. A controlled-test record, generated blueprint, source scaffold, or successful validator does not change that lifecycle state.

## No opaque executable binaries

The Fabric does not mass-produce unsigned `.exe` files or arbitrary native binaries. Executable capability is represented through reviewed source and signed execution plans with:

- allowlisted entrypoints;
- exact runtime class;
- source digest;
- least-privilege policy;
- timeout;
- idempotency;
- rollback;
- readback;
- owner/verifier separation.

A native binary can become a future asset only after reproducible-build, signing, malware, provenance, platform and rollback evidence.

Exact kernel implementation, scoring weights, thresholds and compiler policy remain in Vault. Public outputs contain contracts, scores, bands, blockers and digests only.

## Asset Controller mesh

The root controller is `ct.asset.agent-controller`.

It coordinates nine bounded specialists:

- catalog and fingerprints;
- compilation and packaging;
- dependencies and interoperability;
- bounded execution governance;
- custody and provenance;
- security, privacy and TEVV;
- lifecycle and continuity;
- commercialization;
- independent certification.

All are A2/D2 maximum, non-voting and unable to self-approve.

## Automated scrutiny

The internal controller runs at minute `:23` through PostgreSQL cron. It uses no additional ChatGPT scheduler slot.

Each cycle checks:

- credential-shaped manifest content;
- authority escalation;
- exact dependency state;
- missing test evidence;
- missing version records;
- missing execution plans;
- canonical-name collisions;
- unexpected installation, publication, checkout or entitlement state.

Findings are append-only and remain open until a different verifier accepts the evidence.

## Commercial packaging

Eight controlled-test suites organize the first estate:

- Core Governance, Identity & Evidence;
- Integration, Plugins & Automation;
- Security, TEVV, Observability & Continuity;
- Commerce, Licensing & Marketplace;
- Analytics, Communications & Advertising;
- Platform, Website & Documentation;
- Beauty, Culture, Media & Music;

Rights, pricing and checkout remain research-only. No fake MSRP or unsupported discounting is permitted.

## Promotion boundary

A blueprint count, asset record, generated source scaffold, CI PASS, readiness score or controller heartbeat is not production certification by itself.

Promotion requires exact source and version, dependencies, test receipts, security/privacy review, continuity, independent certification and every applicable rights, pricing, fulfillment, provider and governance gate.
