# CHLOM Wallet Phase C deterministic vectors

`phase-c-test-vectors.json` is the fixed controlled-test contract for HARP v1, EASOR v1 and Portable Wallet Capsule v1.

Run:

```bash
node developers/reference/chlom-wallet/vectors/test-phase-c-vectors.mjs
```

The vectors contain synthetic commitments only. They contain no customer data, provider credentials, signing material, live provider objects, chain transaction receipts or money movement.
