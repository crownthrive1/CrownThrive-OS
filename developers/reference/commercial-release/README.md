# Commercial Release Package Source Map

This directory is the public-safe machine source for the CrownThrive Launch, Ready, and Procure release-package agent.

- `commercial-gap-products.v1.json`: exact 30-product packaged inventory.
- `release-policy.v1.json`: 20 release gates and sovereign acceptance contract.
- `commercial-release-mcp-contract.v1.json`: fail-closed MCP surface.
- `chatgpt-sites-publication-contract.v1.json`: provider publication, readback, rollback, and reapply requirements.
- `convergence-queue.v1.json`: Wallet B→C, commercial-site, and domain-chain priority order.

Generated per-product packages are reproducible CI artifacts and restricted THIVEBASE run records. They are not committed as 30 redundant public snapshots.
