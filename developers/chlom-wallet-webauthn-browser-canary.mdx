## Browser source contract

The browser handoff is:

`developers/reference/chlom-wallet/passkey/browser-canary.mjs`

It performs the following sequence only when invoked from a user interaction at `https://wallet.crownthrive.com`:

1. Request controlled registration options.
2. Call `navigator.credentials.create()`.
3. Serialize and submit the registration result.
4. Request controlled authentication options.
5. Call `navigator.credentials.get()`.
6. Serialize and submit the assertion result.
7. Optionally repeat the assertion ceremony for recovery step-up.
8. Return receipt digests and controlled-test states without returning or persisting the access token.

The reference rejects:

- an origin other than the exact wallet origin;
- a non-secure context;
- a missing WebAuthn Credential Management API;
- a non-HTTPS function endpoint;
- a function endpoint with URL credentials or a fragment;
- a function endpoint whose path does not end in `chlom-wallet-passkey-control`;
- missing authenticated access material;
- registration/assertion results outside the controlled-test states.

## Execution prerequisites

The live controlled canary requires:

- a signed-in CrownThrive test subject with a valid JWT;
- the exact `https://wallet.crownthrive.com` origin;
- an HTTPS secure context;
- a supported platform or roaming authenticator;
- an explicit user gesture;
- the version-3 runtime and current policy digest;
- no production credential activation or smart-account binding;
- capture of only public receipt digests and controlled states.

A successful browser ceremony should return:

## Evidence and promotion rule

The browser gate closes only after an actual user-gesture ceremony produces exact controlled-test registration and assertion receipt digests against the current runtime version, hash, policy digest, repository head and authenticated test subject.

The result must then be independently reviewed. It cannot activate a production credential, replace a credential, bind a smart account, deploy an account, create custody, move value or advance the institutional phase by itself.
