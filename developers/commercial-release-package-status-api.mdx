# Commercial Release Package Status API

The `commercial-release-package-status` service exposes a sanitized aggregate read of the governed release-package estate. It is intended for authenticated operational dashboards, governed agents, and evidence reconciliation. It is not a customer checkout, product-delivery, credential, or sovereign-voting API.

## Contract

- method: `GET`
- authentication: valid Supabase JWT required
- mutation authority: none
- customer records: excluded
- credentials and Vault data: excluded
- private storage paths: excluded
- protected algorithm bodies: excluded
- cache policy: `no-store`

The response contains package and gate totals, per-platform totals, aggregate release states, and the latest sanitized execution receipt. It also repeats the hard controls `credit_only=true`, `checkout_enabled=false`, and `direct_provider_write=false`.

## Fail-closed behavior

- non-GET methods return `405`;
- unavailable server configuration returns `503`;
- database/readback failure returns a generic `502` without internal error bodies;
- the service-role credential remains runtime-only and is never returned;
- API success does not certify any product or authorize publication.
