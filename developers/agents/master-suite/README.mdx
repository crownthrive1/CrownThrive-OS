The Master Agent Suite is an additive set of capability packs and parent-scoped subagents. It changes neither the sovereign A/B/C/D/S voter set nor the eight-framework Factory sequence.

Public-safe repository contents include manifests, schemas, validators, compiler and linkage tooling, tests, and the read-only pull-request workflow. Private database migrations, provider locators, custody receipts, artifact hashes, fingerprint records, credentials, and recovery evidence remain in controlled storage.

The code may validate and compile candidates. It cannot activate an agent or framework, certify a committee, merge, deploy, publish, set a live price, create Stripe objects, enable checkout, issue entitlements, or count toward quorum.

Use `python scripts/validate_agent_capability_master_suite.py --validate` for manifest and invariant validation. A passing result is not governance acceptance or production evidence.
