## CrownThrive IO API Sandbox

CrownThrive IO API Sandbox is a deterministic, provider-free interface for testing CrownThrive-style API integrations without exposing a CrownThrive account, provider credential, customer record, payment record, or protected implementation.

> **Controlled-test boundary:** Version 1.0.0 is technically verified for synthetic use only. It is not a production customer API, commercial entitlement, priced offer, PentaCredits product, or statement of ECAC.

## Quickstart

<Steps>
  <Step title="Read health and contract state">
    Call `/health`, then read `/manifest` to confirm the public-safe authority envelope and `/openapi.json` for the executable OpenAPI 3.1 contract.
  </Step>
  <Step title="List synthetic fixtures">
    Call `/v1/links` with the documented test query, then select a fixture ID from the returned controlled-test data rather than inventing a production identifier.
  </Step>
  <Step title="Read one fixture and statistics">
    Use the fixture read and statistics routes. Treat every object and statistic as deterministic synthetic data.
  </Step>
  <Step title="Exercise the boundary">
    Verify that unsupported writes fail and that unknown query keys fail closed. Do not send customer data, credentials, provider IDs, or production records.
  </Step>
</Steps>

| Route | Purpose |
| --- | --- |
| `GET /health` | Read the versioned controlled-test status |
| `GET /manifest` | Read the public-safe product and authority envelope |
| `GET /openapi.json` | Read the OpenAPI 3.1 contract |
| `GET /v1/links` | List deterministic synthetic link fixtures |
| `GET /v1/links/{link_id}` | Read one synthetic fixture |
| `GET /v1/links/{link_id}/statistics` | Read explicitly synthetic, non-authoritative statistics |

`HEAD` is supported for read routes. `OPTIONS` provides allowlisted CORS preflight behavior. `POST`, `PUT`, `PATCH`, and `DELETE` return `405 Method Not Allowed`.

## Security and privacy

- The runtime contains no `Deno.env` access and makes no provider network request.
- Cross-origin access is limited to HTTPS CrownThrive and CrownThrive IO origins.
- Credentialed wildcard CORS is not enabled.
- Unknown query keys fail closed.
- Responses use no-store caching and browser hardening headers.
- A soft per-instance ceiling of 120 requests per minute limits accidental abuse. It is not an entitlement, billing quota, or SLA.
