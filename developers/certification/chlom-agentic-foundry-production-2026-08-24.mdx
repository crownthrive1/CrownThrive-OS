## SidecarForge

SidecarForge generalizes the already deployed parent-bound sidecar model. It does **not** replace the specialized Agent D delegated-certification sidecar mesh. Existing `ct.subagent.d-surrogate.*` identities remain the specialized independent-D lane; SidecarForge provides reusable non-sovereign work classes around the broader agent estate.

The initial classes are scope recon, evidence worker, drift guard, canary runner, patch builder, rollback verifier, security probe, interoperability adapter, Vault custodian, asset classifier, asset builder, asset verifier and public-safe documentation projector.

Hard invariants:

- maximum sidecar depth is one;
- no sidecar receives vote or quorum effect;
- no sidecar inherits parent authority;
- D3 is unavailable to the sidecar factory;
- second read is mandatory before an applicable parent mutation;
- D2 mutation paths require independent verification;
- sidecars do not receive independent external scheduler slots;
- raw-secret export is prohibited.

## Protected asset factory

AssetForge routes candidate assets through CrownThrive's existing institutional asset bindings, proprietary asset manifest/intake, Vault capability and DAIL controls. Candidate creation is not rights, publication, checkout, entitlement or monetization authority.

Supported initial candidate kinds are `algorithm`, `skill`, `prompt`, `script`, `package` and `product_candidate`. Protected-body custody is the default. Public documentation may expose contract identity and fingerprints while implementation bodies remain restricted.
