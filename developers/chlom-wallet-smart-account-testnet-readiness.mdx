# CHLOM Wallet smart-account testnet readiness

**State:** `HOLD_PREDEPLOYMENT`  
**Target chain:** Sepolia / `eip155:11155111`  
**External bytecode observation:** complete through two providers  
**Runtime codehash independent approval:** pending  
**Simulation:** not run  
**Broadcast:** disabled  
**Custody / money movement:** disabled

The next CHLOM Wallet blockchain step is not token issuance or an account deployment. It is an evidence sequence proving that a governed CrownThrive wallet identity can bind to a reviewed smart account without weakening passkey recovery, rights separation, provider portability or rollback controls.

## Read-only chain-code contract

The preflight implementation rejects:

- non-HTTPS external RPC URLs;
- embedded URL credentials;
- transaction, wallet, personal, miner, admin or debug methods;
- chain-ID mismatch;
- missing runtime code;
- absent approved runtime codehash;
- runtime-codehash mismatch.

