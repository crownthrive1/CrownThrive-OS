# Phase 2.98 Domain and API Discovery Ledger

## Purpose

The August 2026 Holdings management registry contains **82 domain records** across active, closed, reserved, utility and subdomain states. Phase 2.98 scans them without converting management status or scanner behavior into unsupported production claims.

**Scan layer:** public root/web retrieval plus visible developer/API documentation.

## State vocabulary

- `public-content-retrieved` — meaningful public content retrieved;
- `challenge/interstitial` — challenge page returned;
- `suspended-page` — host explicitly returned a suspended-account page;
- `scanner-unresolved` — public scan could not retrieve meaningful content; not proof of downtime;
- `public REST docs verified` — current public developer documentation retrieved;
- `API access claimed; docs not found` — product claim references API access but no public docs discovered;
- `not discovered in public scan` — no public docs found; not proof no API exists.
