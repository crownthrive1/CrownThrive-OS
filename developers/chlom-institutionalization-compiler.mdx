# CHLOM Institutionalization & Continuity Compiler

**Tool ID:** `ct.tool.chlom-institutionalization-compiler`  
**Algorithm:** `ct.algorithm.chlom.institutionalization-compiler.v1`  
**State:** `CONTROLLED_TEST`  
**Network access:** none  
**Write, signing, payment, rights and release authority:** none

The CHLOM Institutionalization & Continuity Compiler, or **CICC**, converts a completed engineering tranche into a deterministic institutional package. Its purpose is to prevent scripts, algorithms, decisions, tests, evidence, documentation, recovery controls, commercialization assumptions and agent handoffs from remaining chat-only or scattered across disconnected files.

CICC does not decide that work is safe, legally approved, commercially ready or production-authorized. It proves what was supplied, identifies what is missing, hashes the exact artifacts, and routes gaps to the proper independent lane.

## Deterministic compiler

The compiler:

1. validates package identity, semantic version and frozen source snapshot;
2. rejects absolute paths, traversal, symlinks and files outside the repository root;
3. hashes the exact bytes of every declared artifact with SHA-256;
4. scans the inventory for live secret-shaped material;
5. separates public, internal and restricted classifications;
6. prevents nonpublic artifacts from entering the public projection;
7. validates algorithm source-path and stable-ID relationships;
8. invokes the deterministic gap resolver;
9. canonicalizes the complete package;
10. computes the package digest over the package without its digest field;
11. emits stable, sorted JSON suitable for byte comparison.

Given the same source snapshot, compiler version, spec and artifact bytes, the output must be byte-identical.

## AI governance

CICC reserves an AI advisory extension for future classification, summarization and gap-explanation assistance. That extension is constrained to:

```yaml
advisory_only: true
decision_authority: false
write_authority: false
output_requires_independent_review: true
automatic_release: false
training_on_restricted_artifacts: false
```

A future AI-assisted run must record prompt, model, policy, source snapshot, input classification and output digest. AI output cannot replace source evidence, independent reviewer receipts, Rights review, Security review, Finance review or Phase Gate.

## Public and restricted projections

The committed public package contains artifact identifiers, paths, classifications, ownership, status, byte counts and digests. It does not contain the artifact bodies or restricted runtime records.

Restricted evidence remains in the private CHLOM/THIVEBASE control plane. CICC rejects private key material, seed phrases, live provider secrets and restricted artifacts marked for public projection.

## Rollback and correction

An institutional package is immutable evidence. Corrections produce a new package version and preserve the prior digest.

```yaml
rollback_mode: append correction package
in_place_manifest_mutation: false
last_known_good_snapshot_required: true
resume_automatic: false
```

CICC does not erase a failed or superseded package. It preserves lineage so future agents and reviewers can reconstruct what changed and why.
