## Verified provider facts

Squarespace Commerce API authentication uses a website-scoped API key or OAuth token in the HTTP `Authorization: Bearer` header. A key can access only its owning website. API keys remain valid while the merchant site remains active. The general Commerce API rate limit is 300 requests per minute, approximately five requests per second. API-key-authenticated Create Order requests have a separate limit of 100 requests/hour/site.

Current first-party documentation:

- https://developers.squarespace.com/commerce-apis/overview
- https://developers.squarespace.com/commerce-apis/authentication-and-permissions
- https://developers.squarespace.com/commerce-apis/making-requests
- https://developers.squarespace.com/commerce-apis/rate-limits
- https://developers.squarespace.com/commerce-apis/products

CrownThrive's local monthly request ceiling is `-1` for this service. That means no CrownThrive-imposed monthly ceiling; Squarespace provider throttles and any provider billing/plan constraints remain authoritative.

## Alt-text remediation lane

Squarespace Products API v2 provides a specific update-product-image endpoint that currently supports updating product-image alt text. CrownThrive has implemented the server-side capability contract, but its write capability remains **HOLD**.

The separate Ahrefs baseline remains 109 URLs with missing alt text. The first-page Squarespace Products read found only 4 blank product-image alt-text values among 318 image records. These are different evidence universes and must be reconciled across the full product/image inventory and crawl surface before any bulk write.

Promotion requires:

1. complete bounded product/image inventory;
2. correlation against the dated Ahrefs missing-alt baseline;
3. decorative-vs-informative classification;
4. context-aware candidate alt text;
5. independent verifier review;
6. one exact canary;
7. post-write readback;
8. recrawl/regression evidence;
9. rollback/reopen evidence.

No bulk alt-text mutation is authorized from the existence of the provider key alone.
