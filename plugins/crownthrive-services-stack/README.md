# CrownThrive Services Stack Control Plugin

**Plugin ID:** `ct.plugin.crownthrive-services-stack`  
**Version:** `0.1.0`  
**Runtime:** `0.1.0`  
**State:** controlled test / governed HOLD  
**MCP server:** `ct.mcp.crownthrive-services-stack`

The plugin is the public-safe control surface for the fourteen provider-independent CrownThrive shared services. It exposes contract discovery, provider/profile evidence, CHLOM CaaS decisions, non-executing route and binding plans, health, gaps, asset state, and receipts.

It does not expose credentials, private identity mappings, protected policies, private evidence bodies, payment authority, rights authority, legal compliance certification, D3 authority, or sovereign votes.

## Current state

- Edge runtime active in controlled test;
- JWT required;
- 13 tools;
- MCP resources and widget supported;
- 14 service modules;
- 32 provider bindings;
- five service profiles;
- 120 asset records;
- not installed, publicly submitted, published, commercially live, or customer-entitled.

Authenticated external MCP discovery and tool-call readback, deployed-boundary negative testing, widget accessibility/device evidence, contract/provider/profile certification, provider-exit testing, documentation navigation, rights/public-policy review, and governed submission remain open.
