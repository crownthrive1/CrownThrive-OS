## Penta Lifecycle

| Stage | Pentas | Purpose |
| --- | ---: | --- |
| [Discover](/pentas/lifecycle/discover) | **203** | Find needs, signals, candidates, dependencies or opportunities. |
| [Design](/pentas/lifecycle/design) | **407** | Specify contracts, topology, authority, data and operating boundaries. |
| [Build](/pentas/lifecycle/build) | **215** | Implement software, content, configuration or infrastructure. |
| [Verify](/pentas/lifecycle/verify) | **215** | Test, validate, certify and produce evidence. |
| [Release](/pentas/lifecycle/release) | **70** | Promote approved artifacts and configurations through governed release lanes. |
| [Operate](/pentas/lifecycle/operate) | **215** | Run the capability in its authorized production or non-production mode. |
| [Observe](/pentas/lifecycle/observe) | **215** | Measure status, outcomes, health, usage, drift and evidence freshness. |
| [Recover](/pentas/lifecycle/recover) | **41** | Repair, retry, rollback, restore or reconcile degraded state. |
| [Govern](/pentas/lifecycle/govern) | **407** | Review authority, policy, risk, rights, compliance and lifecycle disposition. |
| [Evolve](/pentas/lifecycle/evolve) | **407** | Version, migrate, supersede, retire or extend the capability. |
