## Release posture

Release `0.2.0` source custody is now pinned to the canonical no-loss source above. Historical source, inventory, provider-code, and public-browser compatibility evidence is preserved rather than rewritten. Live provider/runtime changes still require exact-head independent evidence.

Locticians live Brilliant Directories installation remains:

`HOLD_BD_TEMPLATE_WRITE_AUTHORITY`

This hold must not be relabeled as a live installation. Existing independently verified placements on other surfaces retain their own exact release evidence.

## Operating pipeline

`discover -> scan -> classify -> inventory resolve -> price/zone decision -> install contract -> consent/format policy -> connector write -> publish -> independent public/provider readback -> verify or rollback -> maintain`

## Required controls

- provider zone/site IDs come only from the current institutional inventory;
- provider credentials remain Vault references and never appear in docs/source/Drive;
- every placement has stable site, surface, zone, format, consent, source-version, and rollback identity;
- intrusive formats require explicit opt-in;
- advertising must remain distinguishable from editorial judgment;
- provider tag acceptance is not impression/fill/revenue proof;
- duplicate installation and duplicate billing are prohibited;
- money movement, payout, settlement, spend, and irreversible rights changes are D3/human-reserved unless separately authorized.
