## Standard

Every production Penta must declare and independently prove a `PENTA_SURVIVAL_CONTRACT`.

A Penta is not production-grade merely because an LLM can describe, plan or invoke it. Its survival footprint must remain inspectable and recoverable when the model, prompt, chat session or provider is unavailable.

## Required fields

```yaml
PENTA_SURVIVAL_CONTRACT:
  persistent_identity:
  persistent_state:
  deterministic_functions:
  queues:
  leases:
  recovery:
  evidence:
  authority_enforcement:
  health_check:
  model_dependency:
  degraded_without_model:
  replaceable_model:
  restart_behavior:
```

## Persistent identity

The contract must identify:

- canonical system and package IDs;
- source repository and exact release;
- state authority;
- provider and connector identities;
- federation and governance bindings;
- authority ceiling.

## Persistent state

State must exist outside the model context. It may include:

- registries;
- queues and jobs;
- leases;
- provider bindings;
- configuration references;
- receipts and evidence;
- recovery payloads;
- current and superseded release lineage.

## Deterministic functions

The Penta must enumerate functions that can run without model interpretation, such as:

- normalization and schema validation;
- routing and eligibility rules;
- state transitions;
- evidence hashing;
- provider reconciliation;
- readback and health checks;
- idempotency and duplicate prevention;
- rollback selection.

## Queues and leases

Long-running or retryable work requires durable queues, leases, idempotency keys, retry limits and dead-letter or hold behavior. A restarted worker must not unknowingly duplicate a spend, publish, payout or provider mutation.

## Recovery

Recovery must specify:

- source preimages;
- rollback payloads;
- restart checkpoints;
- public and provider rollback readback;
- supersession rather than evidence deletion;
- responsible actor and authority ceiling.

## Evidence

The contract must define what proves each state. Evidence may include exact source hashes, provider readback, public readback, database receipts, signed/immutable records and independently reproducible checks.

A model statement, plan, screenshot or self-authored PASS label is not sufficient evidence.

## Authority enforcement

Authority survives model replacement. The contract must explicitly preserve:

- default ceiling;
- D3/human-reserved actions;
- money-movement controls;
- rights and legal controls;
- secret access boundaries;
- destructive mutation policy;
- independent certification requirements.

## Health check

The Penta must expose deterministic health checks for its durable dependencies, including queues, leases, schedulers, credentials, provider state, source bindings, evidence stores, mirrors and recovery records.

## Model dependency

The contract must state what degrades without an LLM.

A valid pattern is:

- registered deterministic operations continue;
- inventory and provider synchronization continue;
- existing routing and policy continue;
- health and readback continue;
- novel interpretation or ambiguous classification enters a governed hold.

## Replaceable model

Production Pentas must not bind institutional identity to one model. A replacement model may assist through the same contracts, tools, policies and authority gates.

## Restart behavior

Restart must be reconstructable from durable sources such as:

- ThriveBase or another state authority;
- canonical source repositories;
- provider readback;
- PentaDocs and Drive mirrors;
- queues, leases and receipts;
- continuity and recovery records.

## Acceptance test

Ask:

> If the LLM disappeared tonight, what part of this Penta would still exist tomorrow morning?

A production Penta should still have identity, source, state, deterministic functions, queued work, authority boundaries, evidence, recovery, health checks and restart instructions. Only novel reasoning should degrade.

## Reference implementation

PentaAds Placement OS `0.2.0` includes `contracts/PENTAADS_SURVIVAL_CONTRACT.v1.json` as a concrete implementation of this standard.
