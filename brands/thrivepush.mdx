# ThrivePush — Engage Your Audience Without Requiring an App

ThrivePush is a web-push notification platform for collecting browser subscribers and sending targeted messages across supported desktop and mobile browsers. It combines rich notifications, subscriber analytics, campaigns, automated flows, segmentation, RSS-to-push, recurring schedules, progressive web apps, notification prompts, custom domains, exports and a developer API.

## What this helps you do

- Grow a permissioned subscriber audience directly from your website.
- Send rich notifications with images, URLs and up to two action buttons.
- Build welcome, education, offer and win-back flows.
- Segment subscribers by geography, device, OS, browser, language and custom parameters.
- Turn RSS updates into automatic push notifications.
- Schedule recurring campaigns by hour, weekday or day of month.
- Create a PWA wrapper for supported websites without building a native app.
- Export subscriber and performance data or automate through API endpoints.

## Availability and eligibility

ThrivePush is available at [**https://thrivepush.io**](https://thrivepush.io) and supports major modern browsers and operating systems. Web-push availability still depends on the visitor's device, browser capabilities and explicit permission. A site cannot silently enroll a visitor; subscriber consent is part of the product model.

## Key capabilities

### Rich push notifications

Add images, destination URLs and up to two custom buttons. Configure dynamic titles and descriptions, silent delivery, urgency and Time to Live so messages expire when they are no longer useful.

### Subscriber analytics

Review continent, country, city, device, browser, OS, referrer and activity logs. Custom parameters can support controlled personalization and segmentation.

### Campaigns

Create scheduled sends, use Spintax for controlled text variation, target segments and review post-campaign statistics.

### Flows

Build time-delayed automated journeys. A typical onboarding flow might send a welcome message after five minutes, education after one day, an offer after seven days and an upgrade or reactivation message later.

### Segmentation

Create subscriber groups from CSV imports or rules based on location, device class, OS, browser, language, source and custom parameters.

### RSS automations

Monitor an RSS feed and automatically generate push notifications from new entries, including title, description and destination URL.

### Recurring campaigns

Schedule repeating messages for specific times, days of week or days of month. Use recurring sends for genuinely recurring information, not repetitive spam.

### PWA builder

Create a Progressive Web App shell for a website without a native app build. PWA support varies by browser and device.

### Notification handlers and API

New-subscriber or operational events can route through Email, Webhook, Slack, Discord, Telegram, Microsoft Teams, SMS, phone call, WhatsApp, X, Google Chat and internal notifications. The API supports websites, subscribers, statistics, campaigns, personal notifications, flows, segments and handlers.

## How it works

<Steps>
  <Step title="Add your website">
    Register the site, then install the ThrivePush integration code and subscription prompt.
  </Step>
  <Step title="Collect permissioned subscribers">
    Explain what visitors will receive and let them choose whether to subscribe.
  </Step>
  <Step title="Create segments and a first flow">
    Start simple: welcome new subscribers, then separate by a meaningful attribute such as language or interest.
  </Step>
  <Step title="Send and measure">
    Review delivery, clicks and subscriber activity instead of optimizing only for total send volume.
  </Step>
  <Step title="Automate what is genuinely repeatable">
    Add RSS or recurring automations only after the manual campaign pattern proves useful.
  </Step>
</Steps>

## Privacy, communications and accessibility

ThrivePush states alignment with modern privacy regulations. Permission is not a one-time excuse to send anything forever: keep messages relevant, provide clear unsubscribe paths, respect suppression lists and avoid sending sensitive personal information in notification text that may be visible on a lock screen.

## Troubleshooting

**The subscribe prompt does not appear.** Check browser support, site integration, permission state and prompt targeting. A visitor who previously denied permission may need to change browser settings directly.

**Subscribers are not receiving messages.** Review browser/device compatibility, segment membership, TTL, campaign status and whether the subscriber's endpoint remains valid.

**A flow sends too often.** Review time delays and segment conditions. Automated sequences should reduce manual work, not multiply unwanted messages.

## Frequently asked questions

### Do visitors need to install an app?

No. ThrivePush uses supported browser push capabilities. PWA installation is a separate optional feature.

### Does ThrivePush support iPhone and iPad?

The public support matrix includes iOS and iPadOS, subject to Apple's browser/PWA requirements and OS capabilities.

### Is ThrivePush the same as CrownPulse?

No. ThrivePush sends permissioned browser notifications after a user subscribes. CrownPulse displays engagement widgets while a visitor is on the website.

### Can I automate blog or media alerts?

Yes. RSS automations can create push messages when a configured feed receives new content.
