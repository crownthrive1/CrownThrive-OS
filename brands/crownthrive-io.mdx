# CrownThrive IO — Unleash Your Digital World

CrownThrive IO is a self-serve digital presence and growth toolkit built for people who need to **publish, route, share, measure and automate** without stitching together a dozen small utilities. It combines bio pages, short links, static-site hosting, file links, vCards, event links, dynamic QR codes, web utilities, analytics, pixels and a developer API in one platform.

## What this helps you do

- Build a branded bio page or campaign hub.
- Shorten and route links with targeting, schedules and expirations.
- Transfer files and share contact or event information.
- Host lightweight HTML/CSS/JS sites.
- Create dynamic QR codes for URLs, Wi-Fi, vCards, calendars, locations and more.
- Measure geographic, device, referrer and campaign performance.
- Attach tracking pixels from major advertising and analytics providers.
- Use a developer API to automate links, statistics, QR codes, projects, pixels and custom domains.

## Availability and eligibility

CrownThrive IO is available as a self-serve service at [**https://crownthrive.io**](https://crownthrive.io). Features and limits depend on plan. Some deeper CrownThrive automation, ADE revenue-split automation and CHLOM-based policy or licensing features are **coming soon** and should not be treated as live CrownThrive IO functionality until announced.

## Core capabilities

### Bio Link Pages

Create customizable, mobile-first pages with your colors, branding, components, templates and SEO settings. Password protection and sensitive-content alerts are available for controlled sharing.

### URL Shortening and Smart Routing

Create compact links with timers, expiration dates, location/device/language targeting, A/B rotation, password protection, content warnings, app deep links and advanced cloaking options.

### Static Site Hosting

Upload HTML, CSS, JavaScript, images, video or audio and host a lightweight site directly through IO. Static sites can use analytics, password controls and automated tracking pixels.

### Dynamic QR Codes

Create branded QR codes with custom colors, gradients and logos. Templates support web links, vCards, Wi-Fi, calendars, locations and other common actions. Higher tiers support bulk QR generation for larger deployments.

### Analytics and Pixels

Review traffic sources, geographic insights, technology segments, browser/language behavior and campaign data. Pixel integrations include Facebook, Google Analytics, Google Tag Manager, LinkedIn, Pinterest, X, Quora, TikTok and Snapchat.

### Web Tools

CrownThrive IO also includes a broad toolbox for checking, text work, conversions, generators, developer tasks, image manipulation, time utilities and miscellaneous productivity jobs.

### Developer API

The API can support links, link statistics, QR codes, projects, pixels and custom domains. Keep credentials private and never publish real API keys in examples or support tickets.

## Thrive Flywheel mapping

CrownThrive IO often acts as an **activation and routing edge** in the Thrive Flywheel. Attention can arrive from AdLuxe, social, media, QR or referral sources; IO presents the action; ThriveSeat or ThriveTickets can handle the next transaction; CrownPulse can add social proof; ThrivePush can support permissioned re-engagement; and CrownLytics can measure the resulting journey.

A public example is [**https://crownthrive.io/kulturehouse**](https://crownthrive.io/kulturehouse), which demonstrates how an IO path can become a branded destination rather than a generic short link.

## Privacy, rights and accessibility

CrownThrive IO advertises analytics aligned with GDPR, CCPA and PECR. You are still responsible for using tracking, pixels, redirects and collected data lawfully for your own audience and jurisdiction. Use clear alt text, readable contrast and mobile-friendly layouts. Only upload files and media you have the right to distribute.

## Troubleshooting

**My QR code scans but opens the wrong place.** Check the destination attached to the underlying IO asset. Dynamic destinations can be updated without changing every printed code, but static exported QR images should be tested after any routing change.

**A short link is not behaving as expected.** Review scheduling, expiry, geo/device rules, A/B rotation and fallback destination settings.

**Analytics look lower than another analytics product.** Different tools count visitors, events and blocked tracking differently. Use CrownLytics when you need deeper behavior analysis and compare like-for-like definitions.

**A custom domain is not resolving.** Verify the DNS records shown in the IO dashboard and allow normal propagation time before escalating.

## Frequently asked questions

### Is CrownThrive IO just a link-in-bio builder?

No. Bio pages are one module. IO also provides short links, file/vCard/event links, static-site hosting, QR, web tools, analytics, pixels, projects, custom domains and API surfaces.

### Can I use CrownThrive IO by itself?

Yes. Ecosystem integrations are optional.

### Does CrownThrive IO include deeper CrownLytics analytics automatically?

No. IO has its own analytics. CrownLytics is a separate analytics product for more detailed behavior, heatmaps and session analysis.

### Are ADE and CHLOM integrations live?

Not all of them. Treat those deeper integrations as coming soon unless the specific feature is marked live in current product documentation.
