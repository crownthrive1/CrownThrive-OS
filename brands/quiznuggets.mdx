# QuizNuggets — Turn Knowledge Into Fast, Useful Checks

QuizNuggets is CrownThrive's quiz creation, publishing, embedding and competition platform. It can support quick knowledge checks, community quizzes, educational assessments and challenge-style experiences while keeping question sources, answer keys, explanations and review state visible enough for trustworthy use.

## What this helps you do

- Create or publish a quiz.
- Embed a quiz in another approved learning or campaign experience.
- Collect attempts and scores.
- Run quiz-based competitions where current rules support them.
- Use AI to help draft questions while preserving source/review controls.
- Separate a quiz score from a formal credential or professional license.

## Availability and eligibility

The current registry preserves **quiznuggets.com** as an active domain and QuizNuggets as a current strategic role. Exact provider, application engine, data, API and AI-generation controls still require current verification.

## How it works

<Steps>
  <Step title="Define the learning goal">
    Decide what the quiz should test and who the intended participant is.
  </Step>
  <Step title="Create questions and explanations">
    Use authoritative source material where accuracy matters. AI can assist drafting, but high-consequence questions require qualified review.
  </Step>
  <Step title="Publish or embed">
    Make the quiz available in the current allowed context and define attempts, scoring and competition rules.
  </Step>
  <Step title="Review results">
    Use scores as feedback or evidence according to the quiz's stated purpose.
  </Step>
  <Step title="Correct the source when needed">
    If a question or answer is wrong, fix the item and preserve correction/version history rather than silently rewriting past evidence.
  </Step>
</Steps>

## AI-assisted quiz generation

AI-generated questions should be labeled and reviewed according to subject risk. Compliance, Scripture/theology, credentialing and other high-consequence assessments should not rely solely on model-generated answer keys or explanations.

## Pricing

No authoritative current QuizNuggets pricing table is present in the source set used for this guide. Use the live product for any current free/premium limits, organization pricing, competition fees or API access.

## Scoring and credential boundaries

A QuizNuggets score can be a learning result or one piece of qualifying evidence. It does not automatically create CrownThriveU course completion, a professional license, mentor eligibility, employment or CHLOM authority.

## Thrive Flywheel mapping

QuizNuggets can support CrownThriveU courses, ThriveArena challenges, ThrivePeer learning checkpoints, onboarding for Affiliates/Ambassadors and other approved training flows. CrownRewards can support an approved quiz incentive only when an effective reward rule exists.

## Privacy and conduct

Do not use private customer, student or regulated records as quiz content without the appropriate authority. Competition attempts should use fair scoring and clear anti-cheating/moderation rules.

## Troubleshooting

**A quiz answer seems wrong.** Use the quiz correction/report path and provide the specific question and source concern.

**My score changed after a question correction.** The current quiz policy should state whether historical attempts are rescored or preserved under their original version.

**Can I use an AI-generated quiz for certification?** Only after the assessment, sources, review and credential rules have been approved for that purpose.

## Frequently asked questions

### Is QuizNuggets the same as ThriveArena?

No. QuizNuggets is quiz creation/assessment; ThriveArena is the broader competitive challenge and leaderboard layer.

### Can quizzes be embedded?

Embedding is part of the current strategic role preserved in the registry.

### Does passing a quiz automatically earn a certificate?

No, unless the current course/program explicitly defines that result as part of credential completion.
