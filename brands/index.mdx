## Status conventions

| Label | What it means |
| --- | --- |
| **Current** | Current public or institutional role supported by present evidence. |
| **Current with holds** | Current identity or service exists, but some integrations, providers, releases or capabilities remain unverified or coming soon. |
| **Coming soon** | Announced or being prepared, but not presented as generally available. |
| **Reserve** | Identity is preserved for possible future use; it is not an active-product claim. |
| **Sunset** | Prior product identity is retired or replaced. |
| **Predecessor / alias** | Older or alternate naming preserved for continuity. |
| **Historical** | Dated context only; no current implementation authority. |
