# Rotation 002 Product-Payload Recovery

Rotation 002 has verified control custody, but none of the 32 named complete-product delivery ZIP binaries was present in the accessible final export or recoverable Drive search. The state therefore remains:

## Closure predicate per SKU

A product leaves recovery only when the exact package is recovered or rebuilt from governed source and all of the following pass:

1. package filename and SKU agree;
2. required reading, editable, EPUB3, reader, landing, metadata, JSON-LD, rights, PentaGreen, manifest, hash, cover, and delivery components exist as applicable;
3. package SHA-256 and byte size are recorded;
4. producer/Library custody is durable;
5. Drive upload returns an exact file ID;
6. the Drive file is downloaded;
7. source and Drive bytes and SHA-256 match;
8. package, evidence, Master, PentaDocs, and PentaGreen projections converge;
9. provider and public-release states remain unchanged unless separately exercised.

Earlier source novels or control manifests cannot be substituted for missing adaptation-package binaries.
