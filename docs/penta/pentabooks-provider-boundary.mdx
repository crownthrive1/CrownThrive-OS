# PentaBooks Provider Boundary

PentaBooks content completion and package custody do not automatically create or verify a provider product, price, tax treatment, reader, entitlement, download limit, expiration policy, recovery route, refund behavior, public checkout, transaction, license, or public route.

PentaGreen advances those predicates only through exact provider objects and readback. A candidate value is not a price object. A route manifest is not a deployed route. A reader archive is not a published Go Flipbooks reader. A license template is not an executed license. A successful checkout test is not a customer sale.

Every public or commercial status must name the exact SKU, edition, provider, provider object, environment, test, timestamp, evidence receipt, and result.
