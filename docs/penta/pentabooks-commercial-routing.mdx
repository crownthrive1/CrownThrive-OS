# PentaBooks Commercial Routing

PentaBooks does not commercialize in isolation. It supplies governed canon, editions, packages, adaptation materials, rights boundaries, QA, corrections, and lineage to the wider CrownThrive ecosystem.

| Lane | Controlled role |
|---|---|
| PentaGreen | Exact rights, price, tax, fulfillment, entitlement, provider activation, and licensing handoff |
| Go Flipbooks | Hosted readers, previews, access control, page-count and availability readback |
| Backroad FM / Melanated Studios | Scripted audio, dramatic serials, interviews, creator commentary, premieres |
| Melanated TV / Melanated Voices TV | Screen pilots, interviews, cultural programming, development presentation |
| CrownThrive Studios | Readings, production development, recording, adaptation, performance capture |
| ThriveTickets / ThriveSeat / ThriveGather | Ticketing, seating, gathering, staged readings, premieres, workshops, live archives |
| GSO Rights Desk | Exact-scope adaptation, performance, merchandise, artwork, institutional, and media licenses |
| CrownThriveU / Impact Institute | Curriculum, facilitator guides, archive ethics, theatre, screenwriting, production education |
| PentaAds / AdLuxe Network | Ethical sponsor inventory around eligible programming and reader surfaces |
| CrownLytics | Discovery, preview, inquiry, checkout, entitlement, refund, recovery, engagement, and license reporting |
| CrownPulse / ThrivePush | Release signals, premiere notices, recovery messages, audience reengagement |
| CrownFluence / Ambassadors / Affiliates | Governed discovery and campaign distribution after activation |
| CrownRewards | Eligible closed-loop engagement and retention after commerce certification |

No lane may infer authority from another. Each handoff remains subject-specific, least-privilege, independently evidenced, and reversible without destroying accepted source work.
