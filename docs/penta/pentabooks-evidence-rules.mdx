# PentaBooks Evidence Rules

PentaBooks evidence binds an exact rotation, SKU, edition, artifact hash, provider object, environment, operation, timestamp, and result. A record proves only the predicates it explicitly demonstrates.

Evidence is append-only. Corrections link to the prior generation and preserve why the projection changed. Unknown, missing, stale, or contradictory facts remain visible as recovery or quarantine states.

The system never manufactures file IDs, registry rows, provider products, prices, readers, checkouts, transactions, entitlements, sales, revenue, or licenses. Candidate catalog value remains a planning value until provider activation and transaction evidence exist.
