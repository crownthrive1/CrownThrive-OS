## Source precedence

When sources disagree, reconcile in this order unless a formally approved governance record specifies otherwise:

1. Current approved CrownThrive OS/governance record.
2. Current canonical CrownThrive registry.
3. Current published policy/terms governing the affected service.
4. Current CrownThrive.com institutional/product copy.
5. Help Center recovery structure and historical content.

Do not silently copy stale terminology or legacy operational assumptions into new support documentation. Flag conflicts for review and preserve provenance.
