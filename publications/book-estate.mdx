# CrownThrive Book Estate

The CrownThrive Book Estate is a governed publishing system rather than a loose file directory. A title becomes a commercial edition only when its identity, source, rights, version, formats, pricing, fulfillment, reader route, checkout, and evidence agree.

```text
Source and canon
→ finished PDF / EPUB / editable master
→ cover, preview, mockup and buyer package
→ rights and license
→ SKU, price and commerce binding
→ controlled reader and fulfillment
→ provider readback
→ release evidence and improvement loop
```

## Ten-gate commercial release standard

A CrownThrive book reaches `SELL_READY` only when the relevant release record proves all applicable gates:

1. Identity and canon
2. Complete narrative or substantive content
3. Design and typography
4. Navigation and accessibility
5. Format package
6. Cover, mockup, and preview
7. Rights, license, and provenance
8. Price and commerce binding
9. Fulfillment, entitlement, and controlled-reader readback
10. Final QA, hash, and publication evidence

A Stripe product or price record does not by itself prove fulfillment. A Drive file does not by itself prove public publication. A repository page does not by itself prove deployment. Each state receives its own evidence.

## Current release states

| State | Meaning |
| --- | --- |
| `PACKAGE_READY` | Required customer and operational package files exist and passed bounded file QA. |
| `PRODUCT_PRICE_CREATED` | Stripe product and one-time price exist with the correct SKU and edition binding. |
| `CHECKOUT_HELD` | Commerce exists, but purchase is not activated because a downstream release gate remains open. |
| `FULFILLMENT_VERIFIED` | The exact buyer package can be delivered through the governed entitlement path and read back. |
| `PUBLIC_READER_VERIFIED` | The exact approved edition is accessible through its controlled Go Flipbooks reader route. |
| `SELL_READY` | Rights, package, price, checkout, fulfillment, reader, and final evidence all pass for that exact edition. |

## Ecosystem flywheel

PentaBooks and Go Flipbooks convert finished books into controlled editions. PentaDocs explains the institutional source and release logic. PentaPersonas can support catalog, support, sales, QA, and fulfillment workflows within bounded authority. PentaGreen evaluates commercial readiness. CHLOM preserves rights, provenance, licensing, and authority. DAIL records material transitions and readbacks. Stripe provides the payment object only after fulfillment and release gates are satisfied.

This creates a reusable publication loop:

```text
Book source
→ governed edition
→ preview and reader
→ product and price
→ purchase and entitlement
→ buyer delivery
→ telemetry and support
→ revised edition, bundle, class, course, or licensed adaptation
```

## What remains before paid activation

- Bind and verify the exact buyer ZIP through the production entitlement and delivery path.
- Publish and read back the exact public Go Flipbooks reader route for each new edition.
- Create Payment Links only after the fulfillment and reader gates pass, or create them inactive with an explicit hold state.
- Verify the post-purchase redirect, receipt metadata, customer access, download limits, expiration behavior, and recovery path.
- Append the terminal product-release evidence and update the master commercialization ledger.

## Governing principle

`DOCUMENTED ≠ PACKAGED ≠ PRICED ≠ FULFILLABLE ≠ PUBLISHED ≠ SELL_READY`.

The Book Estate preserves these distinctions so CrownThrive can scale publication volume without losing rights control, customer trust, or institutional memory.
