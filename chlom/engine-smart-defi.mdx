## Source basis

## Non-purpose

Smart DeFi does not:

- authorize investing merely because a strategy is profitable;
- guarantee yield or principal safety;
- make a protocol/provider trustworthy because it is allowlisted;
- bypass legal, tax, accounting or fiduciary requirements;
- convert CHLOM governance into an investment adviser;
- activate historical crypto/token assumptions today.

## Allowlist

The allowlist is not a trust certificate. It means the strategy passed the current admission profile at a point in time.

```text
allowlisted != risk free
allowlisted != permanently approved
```

Approval must have expiry/review conditions.

## Execution boundary

```text
candidate != authorization
authorization != provider execution
provider execution != reconciled position
```

Every real execution needs idempotency, provider readback and canonical reconciliation.

## Unwind triggers

Historical source language supports automated unwind triggers. Current-safe profiles can monitor conditions such as:

- strategy/security incident;
- provider status change;
- risk threshold breach;
- liquidity deterioration;
- asset depeg/market stress;
- legal/professional hold;
- oracle/data failure;
- treasury reserve need.

Exact trigger thresholds stay private when security/economic sensitivity requires.

## Emergency unwind

Emergency unwind authority must be pre-defined and bounded. If execution itself introduces greater risk, the system may HOLD/escalate rather than blindly automate.

## Performance reporting

Reports distinguish:


Provider-reported APY or balance is not institutional performance truth until reconciled.

## Failure modes

- strategy review expired -\> HOLD;
- provider unavailable -\> no new allocation;
- execution confirmation missing -\> unresolved;
- position value mismatch -\> reconciliation case;
- unwind fails -\> incident/escalation;
- risk data stale -\> HOLD;
- asset/provider unsupported -\> reject;
- professional/legal gate missing -\> no real-money activation.

## Test vectors

1. research strategy -\> no executable allocation;
2. approved controlled-test strategy \+ synthetic funds -\> simulation only;
3. real-money candidate missing professional gate -\> HOLD;
4. provider changes contract/address -\> re-certification required;
5. stale risk evidence -\> HOLD;
6. unwind trigger fires -\> authorized unwind path;
7. unwind provider fails -\> incident, not false closure;
8. provider reports yield -\> book not updated until reconciliation;
9. duplicate execution -\> idempotent protection;
10. historical DeFi whitepaper -\> no claim of current financial service.
