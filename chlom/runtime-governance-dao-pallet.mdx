## Historical purpose

The Governance (DAO) Pallet represented CHLOM's on-chain decision layer for proposals, voting, quorum, enactment and governed parameter/policy changes.

```text

   |
VALIDATION / DEPOSIT / ELIGIBILITY
   |
DELIBERATION / VOTING
   |
QUORUM + APPROVAL RULE
   |
   +--> REJECT
   +--> HOLD / EXPIRE
   +--> APPROVE
             |
          TIMELOCK
             |
          ENACTMENT
             |
          EVENT / AUDIT
```

## Historical DAO context

Historical CHLOM designs include token-weighted governance, councils/committees, CHM governance-token concepts, conviction/time-lock behavior and emergency controls. These are preserved as design lineage.

They are **not** evidence that CHLOM currently operates a tokenized DAO or that CHM exists as a live governance token.

## Eligible decision set

A governance result is meaningful only relative to the eligible decision makers for that proposal/version.

```text
eligible_weight = sum(weight of eligible decision makers)
participating_weight = sum(weight that participated)
quorum = participating_weight / eligible_weight
```

This formula is a generic/public-safe governance model. Historical source examples and current rules remain versioned separately.

## Approval rule

A generic approval ratio may be represented as:

```text
approval = yes_weight / decisive_participating_weight
```

The required majority/supermajority/threshold is a governed parameter, not defined by this article.

## Failure modes

### Proposal passes, execution fails

Decision remains approved; enactment state is failed/held until repaired or superseded.

### Eligible decision set changes mid-vote

Apply the adopted rule/version rather than silently changing denominator.

### Governance provider UI says passed, canonical tally unresolved

HOLD enactment until institutional result is reconciled.

### Malicious/invalid proposal technically passes vote

Higher-order constitutional/authority constraints can still prohibit enactment. Voting cannot manufacture authority outside the governance charter.
