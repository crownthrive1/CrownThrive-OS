## Composition rule

```text
FORMULA
 + INPUT EVIDENCE
 + VERSION
 + UNITS
 + AUTHORITY
 + RESULT
 + REVIEW
 + DAIL RECEIPT
 = GOVERNED CALCULATION
```

This is a composition invariant, not ordinary arithmetic. If a mandatory element is absent, the output may still be a simulation or draft calculation but it is not an institutionally governed result.

The formula/model ID, inputs and evidence, units/basis, rounding, policy/schedule version, executing service/actor, authority context, review state and DAIL receipt must remain reproducible. Corrections append a new calculation and supersession lineage rather than changing the historical result.

## Tests

Test complete record, missing version, stale evidence, unit mismatch, absent authority, missing review, DAIL append failure and corrected/superseded result.
