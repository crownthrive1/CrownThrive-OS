# FORM-016 — Historical Fee-Burn Percentage

## Formula identity

```yaml
formula_id: FORM-016
classification: historical_source_formula
origin: CHLOM historical whitepaper/tokenomics research
adopted: false
```

## Expression

```text
burn_amount = transaction_fee * burn_fraction
```

Historical CHLOM materials discuss illustrative burn fractions such as `20%` of a transaction fee. That percentage is not a current policy.

## Purpose

The historical mechanism was intended to create a usage-linked deflationary counterweight to token issuance and align token supply with network activity.

## Input semantics

`transaction_fee` must be a settled/assessed fee under the relevant token model; `burn_fraction` is a dimensionless fraction between 0 and 1. The expression does not determine the fee itself.

## Conservation/accounting

If a fee is split between burn and other recipients:

```text
transaction_fee = burn_amount + nonburn_allocations + residue
```

All destinations require deterministic accounting.

## Authority boundary

The formula is historical research. No CHLOM token burn, public token economics, monetary policy or investment expectation is activated by this page.

## Interaction with FORM-001

FORM-001 can use average burn per transaction `b`. FORM-016 can be one mechanism from which `b` might be estimated if an adopted fee and burn policy existed. The two formulas remain distinct.

## Tests

Test zero fee, zero burn fraction, fraction 1, fraction outside \[0,1\] rejected, currency/token unit mismatch and rounding at token precision.

## Versioning

Any future activated burn policy gets an adopted schedule/version and does not modify the historical source record.
