# FORM-028 — Paper Decomposition Completeness

## Formula identity

```yaml
formula_id: FORM-028
classification: derived_program_metric
origin: CHLOM paper-to-engineering decomposition pipeline
adopted_as_quality_metric: yes_for_reconstruction
```

## Expression

For recovered paper `p`, define an applicable dimension set such as concepts, claims, formulas, algorithms, schemas, diagrams, invariants and implementation links. A candidate decomposition score is:

```text
D_p = completed_applicable_dimensions / total_applicable_dimensions
```

A more explicit representation is:

```text
D_p = (Σ completed_j) / |A_p|
```

where `A_p` is the set of dimensions actually applicable to paper `p`.

## Purpose

The metric helps prevent a long paper from being marked 'recovered' after only its title or executive summary is documented. It measures **decomposition coverage**, not correctness or production readiness.

## Dimension rules

A dimension counts as completed only when its assets are individually registered/articleized where material. For example, a paper containing six substantive algorithms should not satisfy the algorithm dimension merely because one registry page says 'algorithms exist.'

## Applicability

Not every paper contains every dimension. A legal notice may have no formulas; a mathematical appendix may have no user-interface diagram. Non-applicable dimensions should be explicitly marked and excluded rather than counted as completed automatically.

## Suggested dimension record

```yaml
concepts: complete|partial|not_applicable
claims: complete|partial|not_applicable
formulas: complete|partial|not_applicable
algorithms: complete|partial|not_applicable
schemas: complete|partial|not_applicable
diagrams: complete|partial|not_applicable
invariants: complete|partial|not_applicable
implementation_links: complete|partial|not_applicable
```

Partial status can be reported separately rather than forced into binary arithmetic if the program wants finer granularity.

## What D\_p does not prove

`D_p = 1` does not mean the paper is current, adopted, implemented, public-safe or legally valid. It means the applicable intellectual contents have been accounted for under the reconstruction method.

## Tests

Test paper with all dimensions, paper with only three applicable dimensions, title-only source, restricted paper with private decomposition, partial algorithms and source later found to contain an additional appendix.

## DAIL evidence

Store source version, applicable-dimension determination, asset counts and article/registry references used to compute the score.

## Versioning

If decomposition dimensions expand, recalculate scores under a new metric version rather than rewriting historical completion claims.
