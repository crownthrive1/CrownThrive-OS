# FORM-009 — Rights-Set Conservation

## Formula identity

```yaml
formula_id: FORM-009
classification: derived_formal_invariant_from_source_requirements
origin: DLA hierarchy; LEX; sublicensing and source-rights lineage
adopted_as_design_invariant: yes_for_reconstruction
implementation_verified: not_by_documentation
```

## Invariant

Let:

- `R_source` = rights actually controlled at the source/root;
- `R_parent` = rights validly granted to a parent permission/license;
- `R_child` = rights granted by a child/sublicense/derivative permission.

Then:

```text
R_child ⊆ R_parent ⊆ R_source
```

Equivalent institutional language:

```text
child rights cannot exceed parent rights;
parent rights cannot exceed source rights.
```

## Purpose

This is one of CHLOM's core anti-rights-manufacture invariants. A marketplace listing, provider account, payment, smart contract or administrative action cannot create a right that is absent from the controlled source set.

## Rights dimensions

A `right` should not be modeled only as a label. It can include dimensions such as use type, medium/channel, territory, term, exclusivity, transferability, sublicensing depth, derivative-use permission, audience, quantity and other contractual constraints. Subset evaluation must account for those dimensions.

## Example

If a parent license permits:

```text
{streaming in United States, 2026, non-exclusive}
```

a child may narrow that scope to a particular platform or shorter period. It may not expand to worldwide perpetual exclusive rights.

## Empty and unknown sets

An empty controlled set cannot support a grant. An **unknown** source-right set is not treated as universal; the activation result should HOLD pending evidence.

## Multiple sources

If a grant depends on several source rights, composition must define whether all are required (intersection/dependency) or rights are independently contributed. Do not take a union merely because it produces the broadest set.

## Revocation/correction

When an upstream source right is revoked or corrected, descendants whose effective sets depend on it are recomputed. Historical grants remain recorded even if they become ineffective.

## Related algorithm

ALG-004 computes rights graph closure; ALG-005 validates sublicenses. FORM-009 is the mathematical invariant those procedures must preserve.

## Test obligations

Test exact equality, strict subset, attempted superset, disjoint rights, unknown source, expired parent, territory narrowing, term narrowing, prohibited derivative right and multi-level chain.

## DAIL evidence

Store source/parent/child version references and the rights-set calculation used for consequential authorization.
