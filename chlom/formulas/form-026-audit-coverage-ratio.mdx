# FORM-026 — Audit Coverage Ratio

## Formula identity

```yaml
formula_id: FORM-026
classification: derived_assurance_metric
origin: CHLOM continuous audit and certification requirements
adopted_target: false
```

## Expression

For an audit scope with `V` verified applicable control checks and `A` total applicable controls:

```text
coverage = V / A
coverage_pct = (V / A) * 100
```

provided `A > 0`.

## Purpose

Coverage quantifies how much of an identified control population received the required verification. It is useful for detecting incomplete evidence collection, skipped controls, partial audits and assurance gaps.

## What coverage does not mean

```text
100% coverage != every control passed
100% coverage != no fraud
100% coverage != legal compliance certification
100% coverage != independent assurance
```

Coverage measures **scope completion**, not the substantive result of each control.

## Denominator governance

The applicable-control set must be generated from the exact object, policy versions, jurisdiction, service type and audit scope. Removing difficult controls from the denominator to improve the percentage is invalid.

## Verified definition

A control counts as `V` only when the adopted evidence/reviewer requirements are satisfied. Merely attempting a test, reading a stale provider result or marking `N/A` without authority should not count as verified.

## Zero-applicable-controls case

If `A = 0`, the metric should be reported as `NOT_APPLICABLE` rather than divide by zero or claim 100% coverage.

## Companion metrics

Coverage should be reported beside pass/hold/deny counts, evidence freshness, finding severity and reviewer/certification state.

## Tests

Test full coverage, partial coverage, no applicable controls, attempted-but-unverified controls, authorized N/A, policy version adding controls and denominator tampering detection.

## DAIL evidence

Store the applicable control registry/version, verification records and resulting metric.

## Versioning

Metric semantics remain stable while audit policies define the denominator and verification requirements.
