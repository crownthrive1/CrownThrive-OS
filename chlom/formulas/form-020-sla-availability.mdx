# FORM-020 — SLA Availability Mathematics

## Formula identity

```yaml
formula_id: FORM-020
classification: standard_engineering_model_adopted_for_reference
origin: CHLOM SLA Metrics and observability lineage
adopted_target: false
```

## Expression

```text
availability = 1 - downtime / measurement_period
```

The metric is only meaningful when service boundary, measurement period, counted downtime, maintenance/exclusions, degradation treatment and evidence source are explicit. Time-based availability and request success rate are different metrics.

No contractual target is created by this article. Every report must retain the metric-definition version, period and source evidence so the SLA cannot be redefined after an outage.

## Tests

Test zero/full downtime, planned maintenance, partial degradation, missing telemetry, overlapping incidents and period boundaries.
