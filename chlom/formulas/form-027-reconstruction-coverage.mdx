# FORM-027 — Reconstruction Coverage Metrics

## Formula identity

```yaml
formula_id: FORM-027
classification: derived_program_metric_family
origin: CHLOM lost Help Center reconstruction
historical_baseline_denominator: 795
```

CHLOM recovery uses separate metrics so a recovered title is never confused with a recovered source body, a substantive reconstruction, an implementation mapping or a production certification.

```text
title_recovery_rate = recovered_titles / N
source_body_recovery_rate = recovered_source_bodies / N
substantive_reconstruction_rate = reconstructed_items / applicable_population
implementation_mapping_rate = mapped_items / applicable_technical_items
production_certification_rate = certified_items / applicable_implementation_items
```

For the current historical lost-Help-Center census, `N = 795` unless a later documented census supersedes it. Decomposing one recovered paper into many algorithms, formulas, pallets, widgets or theorem articles increases the institutional corpus without changing the historic denominator.

Every numerator requires machine-readable status; title-only and placeholder records cannot count as recovered bodies or completed implementations.

## Tests and evidence

Test title-only exclusion, duplicate source copies, restricted recovered body, one source decomposed into many articles and denominator revision. Snapshot every reported metric with census/status-registry version and calculation time.
