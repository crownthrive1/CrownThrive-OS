# FORM-010 — Effective Rights Intersection

## Formula identity

```yaml
formula_id: FORM-010
classification: derived_model
origin: rights graph and DLA/LEX requirements
adopted_as_reconstruction_invariant: yes
```

## Expression

```text
R_effective =
    R_claimed
    ∩ R_controlled
    ∩ R_license_scope
    ∩ R_jurisdiction
    ∩ R_time_valid
    ∩ R_channel
```

A requested use `u` can only be a rights PASS candidate when:

```text
u ∈ R_effective
```

## Set meanings

- `R_claimed`: rights the actor asserts are relevant;
- `R_controlled`: rights supported by source/chain-of-title evidence;
- `R_license_scope`: scope granted under the active DLA/license;
- `R_jurisdiction`: scope permissible in the applicable jurisdiction/policy context;
- `R_time_valid`: rights whose effective dates include the requested use time;
- `R_channel`: rights applicable to the requested media/platform/channel/use type.

Additional dimensions can be added as explicit intersections rather than hidden conditions.

## Why intersection

Effective authorization is constrained by **all** applicable bounds. A creator may own a work but have granted an exclusive field-of-use right elsewhere; a licensee may hold broad media rights but only in one territory; a valid right may expire before the requested event.

## Unknown values

If a required set cannot be resolved, the model should produce `UNKNOWN/HOLD`, not assume a universal set. This is critical for incomplete chain-of-title evidence.

## Empty intersection

If `R_effective = ∅` for the requested action, the rights portion of authorization fails.

## Relationship to policy

FORM-010 resolves rights scope, but final execution may still require identity, credentials, payment/economic conditions, policy controls and authority. It is therefore one component of a larger license-validity predicate.

## Provenance

Each set should be versioned and traceable to source events/records. A set computed from a provider listing alone is not equivalent to controlled rights unless that provider is explicitly authoritative for the needed claim.

## Tests

Test all sets equal, one narrow territory, expired time, wrong channel, claimed right not controlled, license narrower than ownership, empty intersection, unknown source set and one dimension corrected later.

## DAIL evidence

A consequential calculation records source refs, set versions, requested use and resulting effective set/determination.
