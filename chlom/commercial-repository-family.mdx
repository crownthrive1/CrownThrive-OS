## CHLOM Commercial Repository Family

CHLOM is maintained as a governed repository family rather than a single uncontrolled source tree.

## Canonical relationship

**Canonical public-safe governance parent:** `crownthrive1/CrownThrive-OS`

**Public commercial child:** `crownthrive/chlom-protocol`

Both GitHub repositories are public.

The parent is authoritative for the **managed public-safe commercial overlay**: current CrownThrive OS framing, canonical terminology, public licensing policy, public/private boundaries, factory controls, validators and projection rules.

The child is the public CHLOM technical and commercial surface: research, registries, schemas, public architecture, machine contracts, developer discovery, licensing, support, and verification artifacts.

Restricted institutional state remains outside public Git.

## Why the split exists

The parent/child relationship gives CrownThrive two simultaneous capabilities:

1. preserve an institutional source of current managed policy and public-safe projection rules; and
2. maintain a focused public CHLOM repository that developers, partners, researchers and commercial evaluators can inspect without exposing private evidence, secrets or confidential implementation logic.

The child retains unmanaged validated content such as registries, schemas, tests and historical research. The parent projection is non-destructive toward those paths.

## Rights model

Public visibility does **not** create a general open-source, open-content, commercial, patent, trademark, certification, model-training, redistribution, OEM or white-label license.

Commercial rights require an applicable CrownThrive agreement. The exact grant may define product/version, use, territory, term, users, environments, field of use, machine access, data/model rights, modification, distribution, branding, support, economics, audit, termination and remedies.

The parent repository's general `LICENSE` is supplemented by `CHLOM-REPOSITORY-FAMILY-LICENSE-ADDENDUM.md`. The managed public child receives its own CHLOM repository rights notice, commercial licensing notice and machine-access terms.

## Support and conversion funnel

Public CHLOM surfaces route users toward:

- CrownThrive corporate and partnership discovery;
- institutional documentation and support;
- developer integration evaluation;
- correction and security reporting;
- commercial licensing and enterprise discussions;
- research and education licensing;
- voluntary build support.

The verified voluntary support route currently used in GitHub funding metadata is the CrownThrive Stripe support link. No separate Buy Me a Coffee or Ko-fi endpoint is represented as verified unless CrownThrive later publishes one.

## Commercial classes

- Public / Community
- Developer / Integration
- Business / Commercial
- Enterprise / Institutional
- Ecosystem / Partner
- Research / Education
- OEM / Embedded / White-label when expressly licensed

These are pathways, not automatic grants.

## Projection factory

The parent factory flow is:

```text
managed public-safe source
→ validation
→ deterministic projection
→ exact upstream receipt
→ independent controls
→ child candidate pull request
```

The projection does not force-push, direct-write child `main`, self-merge or delete unmanaged child content.

## Maintenance boundary

Current targeted-maintenance governance allows branch-scoped founder-directed work, validation, deterministic build preparation, documentation, candidate registration and read-only observation while routine autonomous external mutation remains held until the maintenance release evidence gate passes.

That means CHLOM can continue to be engineered now without falsely claiming that scheduled child mutation or public commerce has been reactivated.

## Economic activation

The repository family can prepare commercial packages and integration candidates. Current economic state is downstream of PentaGreen / ECAC. A GitHub merge, provider event, public page or machine response cannot independently create a price, SKU, entitlement, checkout, payout or settlement.
