# Wireframe: MVP / TV / Ecosystem Widget Operations

## Wireframe identity

```yaml
wireframe_id: WIRE-MEDIA-WIDGET-001
source_family: recovered MVP widgets and TV/ecosystem widget operations
classification: source_grounded_functional_reconstruction
version: 1.0.0
```

## Purpose

This console governs reusable media/ecosystem widgets used across Melanated Voices Platform, Melanated Voices TV, Locticians TV, CrownThrive media surfaces and other authorized CrownThrive properties. It treats a widget as a governed content/integration object with rights, feed/source, placement, state and evidence rather than a block of unmanaged embed code.

## Widget registry

Each widget has stable widget ID/version, widget type, owning platform/pallet, content/source refs, permitted properties/placements, public/private data classification, feed/API dependencies, event subscriptions, accessibility state and current publishing status.

## Placement inventory

Show property/page/channel placements, order/region, audience/role eligibility, ad/member conditions, start/end windows and active version. A provider CMS slot is an alias to the canonical placement record.

## Content and rights panel

Every image/video/audio/text/brand asset used by a widget resolves to source-rights/DLA state appropriate for the placement/channel. Rights changes can HOLD or remove future widget projection without deleting historical publication events.

## Feed/source health

Display provider/API/feed adapter, schema version, last successful refresh, currentness, error/degraded state, quota/rate limit and fallback behavior. A stale content feed cannot masquerade as current merely because the widget shell renders.

## Publishing workflow

States:

```text
DRAFT
CONTENT_READY
RIGHTS_CHECK
POLICY_REVIEW
APPROVAL_PENDING
SCHEDULED
PUBLISHED
HOLD
SUSPENDED
EXPIRED
SUPERSEDED
```

Publishing requires the exact widget version, content/rights snapshot and any platform/campaign approvals.

## Moderation and correction

Content moderation/review findings, takedowns, corrections and reinstatement are append-only events. The console can replace the current projection while preserving prior publication lineage.

## Measurement

Show impressions/plays/clicks/engagement or other defined metrics with source/currentness and property/widget version. Provider analytics are evidence; CrownLytics/CrownPulse projections remain governed interpretations.

## TV/media scheduling

For TV/streaming contexts, widget/content state can include channel, program/segment association, schedule/effective window and playback/feed health. The wireframe does not assume one specific streaming provider.

## Layout

```text
WIDGET REGISTRY          PLACEMENTS
CONTENT / RIGHTS         FEED / SOURCE HEALTH
PUBLISHING QUEUE         MODERATION / CORRECTIONS
TV / SCHEDULE            MEASUREMENT
DAIL / AUDIT             DEPENDENCIES
```

## Security/privacy

Embed/API credentials stay vaulted. Widgets may display only approved data fields to the target audience; internal dashboard metrics and restricted user data cannot leak into public embeds.

## Tests

Test revoked media rights, stale feed, provider outage, widget version update, scheduled expiry, moderation hold, public/private field redaction, duplicate placement and cross-property analytics isolation.

## Versioning

Widget definition, placement, content and provider adapter versions are separate; historical published snapshots remain auditable.
