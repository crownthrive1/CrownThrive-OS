## Historical purpose

The SLA Metrics Pallet was designed to provide verifiable counters/measurements for service-level commitments that could influence governance, penalties, releases or remediation.

```text
SERVICE / PROVIDER ACTIVITY
          |
          v
NORMALIZED SLA MEASUREMENT
          |
          v
SLA METRICS PALLET
          |
    period / threshold / evidence
          |
          v
BREACH / PASS / REVIEW
```

## Metric definition comes first

A metric is invalid if its numerator, denominator, time window or exclusion rules are undefined.

```text
"uptime 99%"
    !=
valid SLA record
```

unless the measurement basis is documented.

## Availability example

A conventional public-safe model is:

```text
availability = eligible_uptime / eligible_total_time
```

The actual exclusion/maintenance rules are SLA-specific and must be versioned.

## SLA versus SLO

Current service architecture may distinguish contractual/service-level commitments from internal objectives. Historical source titles use SLA; current mappings should not claim contract enforceability unless an actual agreement creates it.

## Breach evaluation

```text
metric reconciled?
   no -> HOLD
   |
  yes
   v
applicable SLA version current for period?
   no -> HOLD
   |
  yes
   v
threshold satisfied?
   yes -> PASS
   no  -> BREACH CANDIDATE / policy remedy
```

A measurement breach is evidence; remedy authority comes from agreement/policy.

## Failure modes

- missing telemetry;
- clock skew;
- undefined maintenance exclusions;
- duplicate incident counting;
- provider-only measurement with no independent check;
- retroactive metric-definition change;
- wrong SLA version applied to period.

## Public / restricted split

Public-safe:

- metric definitions approved for disclosure;
- measurement methodology;
- aggregate public status where authorized.

Restricted:

- private SLA contracts;
- provider telemetry;
- incident detail;
- security availability events;
- penalty/remedy schedules.

## Invariants

```text
metric label != metric definition
provider dashboard != institutional metric automatically
SLA breach != remedy authority by itself
current SLA version != historical period version
missing telemetry != PASS
aggregate availability != security status
historical pallet != deployed runtime
```
