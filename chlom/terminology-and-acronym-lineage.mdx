# CHLOM Terminology and Acronym Lineage

CHLOM has evolved across multiple whitepapers, technical compendia, Help Center eras, implementation plans, and reconstructed institutional records. Phase 2.7 makes terminology drift explicit.

## DLA

Historical CHLOM materials use **DLA** for **Decentralized Licensing Authority**. The current reconstructed CrownThrive operating model uses **DLA** for **Dynamic Licensing Asset**.

These are not interchangeable meanings.

- Historical meaning should remain attached to its original papers and architecture period.
- Current machine-readable records should use Dynamic Licensing Asset unless an ADR states otherwise.
- Agents must resolve context and effective date before interpreting the acronym.

## DAIL / DAL

Legacy source families contain variations around data/audit/information-ledger terminology. The current institutional architecture reserves **DAIL** for the durable event/evidence/audit-ledger function used by Phase 3.

Any historical DAL or variant term should be preserved as an alias or predecessor, not silently rewritten in the original source.

## LEX

LEX remains associated with the licensing exchange / marketplace concept. Historical decentralized or token-oriented implementation assumptions should be treated as target/research architecture unless current implementation evidence exists.

## TLaaS and related research

Terms found in historical CHLOM commercialization or licensing research should remain in the Research & Study Register unless explicitly adopted into the current service architecture.

## Canonical acronym record

Every important acronym should eventually carry:

- acronym
- current expansion
- historical expansions
- effective dates
- source family
- stable concept ID
- predecessor/successor links
- current status
- implementation evidence
- public-safe definition

## Rule

Terminology changes are corrections or evolutions in the institutional record. They are not permission to erase older meanings from source history.
