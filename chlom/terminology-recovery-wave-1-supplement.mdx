# Terminology Recovery — Wave 1 Supplement

This supplement extends the existing [CHLOM Terminology and Acronym Lineage](/chlom/terminology-and-acronym-lineage) with source-specific meanings recovered during Reconstruction Wave 1.

For the full machine-oriented recovery register, use [CHLOM Legacy Acronym and System Recovery Register](/chlom/legacy-acronym-and-system-recovery-register).

## AIE

Recovered source meanings:

- **AI Intelligence Engine** — explicit Genesis Volume meaning; ML/risk/predictive intelligence feeding ACE.
- **Anomaly Intelligence Engine** — later CrownThrive reuse for monitoring/outlier detection.

Current disposition: preserve both; founder adjudication remains available.

## ADE

Recovered source meanings:

- **Autonomous Decision Engine** — explicit Genesis Volume meaning; actuator for eligible policy/governance decisions.
- **Attribution & Distribution Engine** — later CrownThrive reuse for attribution, revenue splits and distribution.

Current disposition: preserve both; founder adjudication remains available.

## ACE

The Genesis Volume explicitly uses **Adaptive Compliance Engine**. Later materials occasionally use looser automated-compliance descriptions. The recovered canonical historical expansion is therefore preserved as Adaptive Compliance Engine unless a later adjudication changes the current naming strategy.

## TLaaS

Two explicit historical expansions are now preserved:

- **Tokenized Licensing as a Service** — Technical Blueprint / Building & Understanding lineage.
- **Trust Layer as a Service** — Grand Prospectus lineage.

Neither is silently selected as the timeless meaning.

## DLA

- historical: **Decentralized Licensing Authority**;
- current machine meaning: **Dynamic Licensing Asset**.

The current authority function is separated into licensing stewardship / issuer authority.

## DAL / DAIL

Recovered historical DAL meanings include:

- **Decentralized Attestation Ledger**;
- **Decentralized Adjudication Layer**;
- distribution-related authority/layer terminology in later recovered module lineages.

Current:

- **DAIL = Decentralized Autonomous Information Ledger**.

Historical source texts retain their original DAL expansion.

## Token notation

- **CHLOM Coin** — historical network utility token concept;
- **CHM** — historical governance/compliance token concept;
- **CHLM** — historical shorthand/native-token notation appearing in portions of the Grand Prospectus; not automatically a separate current token.

## Legacy systems

Wave 1 additionally confirms:

- XENThrive / Get Kinetic! is historical commerce/brand lineage, not a current primary CHLOM platform unless reactivated;
- ThriveCafe remains retired standalone history;
- Melanin Magic Cafe remains separate brand/imprint lineage;
- ThriveApps/CrownApps and Studio-name families require identity-context resolution;
- MVP must be namespaced between Melanated Voices Platform and ordinary minimum-viable-product usage.

## Correction model

Terminology recovery follows:

```text
source meaning
→ source-period concept ID
→ later reuse/rename
→ conflict record
→ current default if established
→ founder adjudication if needed
→ append-only correction
```

A rename never erases the historical expansion.
