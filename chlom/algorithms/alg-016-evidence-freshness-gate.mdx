# ALG-016 — Evidence Freshness Gate

ALG-016 enforces currentness for evidence whose usefulness decays over time. A prior PASS is not automatically a current PASS when the underlying fact can change.

## Procedure

```text
function freshness_gate(evidence, TTL):
    age = now - evidence.observed_at

    if age <= TTL:
        return PASS

    return HOLD_REVERIFY
```

This simple expression is the public core. Production semantics must also define which timestamp controls, clock tolerance, timezone/UTC normalization and whether a more recent revocation/update exists.

## Freshness policy

Freshness is domain-specific. Identity, sanctions, account status, pricing, risk observations, license validity, provider capacity and legal/regulatory state may require different windows. Documentation must not invent one global TTL.

## Timestamp precedence

Where provider receipt time differs from source observation time, the policy should use the time that reflects factual currentness. A delayed API response cannot make old evidence fresh merely because it was received recently.

## Revocation interaction

Freshness PASS does not override a known revocation. A recently issued credential that is explicitly revoked is unusable even though its age is small.

## Failure states

Missing observation time, ambiguous timestamp source, future timestamp beyond tolerated skew, unknown freshness policy, stale mandatory evidence or unavailable refresh path must not be coerced to PASS.

## DAIL evidence

Consequential freshness decisions should retain the evidence ID, timestamps, TTL/policy version and result. Reverification creates new evidence and a new decision rather than changing the old observation timestamp.

## Tests

Test age just below TTL, exactly at TTL, above TTL, missing timestamp, future timestamp, clock skew, newer revocation, source observed before provider received, policy TTL update and evidence with no expiry requirement.

## Versioning

Changes to timestamp precedence, boundary inclusivity or clock-skew handling require a new version.
