## T1 — Value Conservation: Splitter

### Historical statement class

If a base amount `B` is distributed according to a normalized split vector whose weights sum to denominator `D`, allocation plus deterministic residual preserves total value.

Let:

```text
Σ a_i = D
p_i = floor(a_i * B / D)
r = B - Σp_i
```

Then:

```text
Σp_i + r = B
```

### Current invariant

```text
gross = deductions + allocations + holds + residue
```

No unexplained economic value disappears.

## T2 — Override Correctness: Tree

Historical override-routing uses edge rates `r_e` along a path.

Conceptually:

```text
ancestor_share = B * Π r_e
```

### Current correction

A mathematically conserved split is still invalid if the underlying contract or rights state does not authorize the routing.

```text
mathematical conservation != economic authority
```

## T7 — Incentive Compatibility

The Gold Paper provides the deterrence inequality:

```text
S >= G / (p * s)
```

Equivalent:

```text
p * s * S >= G
```

Where:

- `S` = stake/bond;
- `G` = potential gain from misconduct;
- `p` = detection probability;
- `s` = fraction of stake lost if detected/proven.

### Interpretation

Expected penalty:

```text
E[penalty] = p * s * S
```

To make misconduct unattractive in the simplified model:

```text
E[penalty] >= G
```

### Sensitivity

Required stake:

```text
S_required = G / (p*s)
```

Therefore:

```text
∂S_required/∂G > 0
∂S_required/∂p < 0
∂S_required/∂s < 0
```

Higher possible gain demands more bond; stronger detection or stronger permitted penalty lowers the theoretical required bond.

### Boundary

This is mechanism-design research, not a current financial bonding requirement.

## T12 — Rounding Bound

For `m` recipients using floor allocation:

```text
p_i = floor(a_i * B / D)
```

The source states residual bound:

```text
0 <= r <= m - 1
```

when working in smallest indivisible integer units under the modeled normalized split.

### Reasoning sketch

Each floor operation loses less than one unit:

```text
0 <= exact_i - floor(exact_i) < 1
```

Summing `m` losses gives:

```text
0 <= residual < m
```

For integer residual:

```text
r <= m - 1
```

This public-safe derivation is consistent with the source theorem statement.

## T14 — Oracle Accountability

Historical source applies incentive deterrence to false oracle reporting:

```text
p_det * s_V * S_V >= benefit_false
```

Where:

- `p_det` = probability false reporting is detected/proven;
- `s_V` = slash fraction;
- `S_V` = oracle bond/stake;
- `benefit_false` = potential benefit from lying.

### Current generalized assurance model

Without requiring a token:

```text
expected_cost_of_misconduct
   >=
expected_benefit_of_misconduct
```

Controls can include contractual deposits, insurance, access loss, reputation, legal remedies or provider termination.
