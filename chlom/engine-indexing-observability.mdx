## Purpose

This engine converts event/evidence/service state into searchable and monitorable projections without turning indexes, metrics or dashboards into canonical business truth.

```text
DOMAIN EVENTS / DAIL / SERVICE TELEMETRY
                |
                v
NORMALIZE / CLASSIFY
                |
       +--------+--------+
       |                 |
     INDEX            OBSERVABILITY
       |                 |
 search/explorer     metrics/logs/traces
       |                 |
       +--------+--------+
                |
        ALERTS / DASHBOARDS
```

## Two data planes

```text
BUSINESS/EVIDENCE PLANE
  DAIL/domain events, canonical object state, correction lineage

TELEMETRY PLANE
  logs, metrics, traces, health signals
```

They can correlate but are not interchangeable.

```text

```

Material actions re-read the domain service. The index exists for discovery, filtering and analysis.

## Privacy-tier indexes

```text
PUBLIC INDEX
  public-safe projections only

ROLE/INTERNAL INDEX
  authorized operational metadata

RESTRICTED INDEX
  minimal searchable metadata with access-controlled content retrieval
```

Restricted content should not leak through counts, autocomplete or snippets.

## Event indexing

## Rebuildability

An index should be rebuildable from canonical records/events where architecture supports it.

```text
canonical history
   |
replay / rebuild
   |
new index version
```

This reduces dependence on a single search vendor.

## Logs

Logs are diagnostic data, not automatically institutional evidence. Material security/business events can be normalized into DAIL separately.

## Traces

Traces correlate cross-service execution:

```text
request R
  |
identity -> policy -> rights -> provider -> readback -> DAIL
```

Trace IDs can assist incident/debugging without becoming public object IDs.

## Alerts


```text

```

The applicable stale threshold is projection/domain specific. A stale projection can be visibly marked and excluded from material actions.

## Failure modes

### Search vendor unavailable

Canonical services remain authoritative; fail search/discovery gracefully or use certified fallback if available.

### Index says ACTIVE, canonical DLA is REVOKED

Display canonical state on detail/material action; mark index mismatch/stale and repair projection.

### Metrics pipeline drops data

Mark period/metric incomplete; do not claim availability/SLA total as definitive.

### Alert storm

Deduplicate/correlate under protected rules while preserving underlying event evidence.
