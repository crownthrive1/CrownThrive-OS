## Validator selection

Historical algorithms could use stake-weighted or nominated selection. The exact current algorithm is not inferred.

Selection should conceptually depend on adopted criteria such as:

- identity/role eligibility;
- security posture;
- uptime/performance;
- independence/diversity;
- bond/assurance where adopted;
- conflicts/related-party limits;
- geographic/provider concentration where relevant.

## Session keys

Session keys are operational cryptographic credentials. They should be separable from institutional validator identity so rotation does not create a new validator record.

```text
validator identity
   -> active session key set
   -> rotate/revoke
```

## Consensus boundary

Network consensus answers a state-agreement question under a protocol. It does not independently answer whether the agreed state is legally or institutionally authorized.

```text
consensus-valid block/state
      !=
rights-valid transaction automatically
```

CHLOM's policy/pre-check/DLA logic historically existed precisely to constrain otherwise-valid runtime actions.

## Fault assumptions

Historical formal research includes BFT-style assumptions such as `f < n/3` for some mechanisms. That assumption is preserved as source-era mathematical lineage; it is not a current production guarantee.

## Liveness

A validator set should have measurable liveness/availability requirements. Historical chain liveness can be mapped to modern multi-service assurance concepts:

```text
independent replicas/verifiers
+ health evidence
+ failover
+ no single provider as institutional truth
```

## Slashing/penalties

Historical slashing is a mechanism-design deterrent. Current CHLOM may instead use contractual, role, access, reputation or provider-removal remedies. Financial slashing requires separate legal/economic activation.

## Misbehavior evidence

Potential classes:

- double signing/equivocation;
- unavailable/offline behavior;
- invalid state/proof submission;
- oracle/attestation collusion;
- key compromise;
- policy bypass attempt;
- censorship or selective omission.

A flag is evidence for a governed remedy, not automatic proof of misconduct outside adopted protocol rules.
