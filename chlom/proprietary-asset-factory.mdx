## Institutional custody and recovery

The factory uses a strict private/public split:

- **THIVEBASE** holds stable identities, classifications, lifecycle states, authority ceilings, validation receipts, reconciliation state, DAIL references, and commercialization state.
- **Supabase Vault** holds protected recovery material. Raw secret return is prohibited.
- **Encrypted Google Drive custody** holds private generation archives. Drive claims require actual ciphertext upload and exact readback.
- **DAIL** records package, custody, correction, and projection events using restricted digest-only evidence.
- **Mintlify and GitHub** receive only contract-level public-safe summaries.

The Generation-5 raw ciphertext package completed exact encrypted Drive readback. No plaintext package, decryption key, protected formula, prompt body, or private identity mapping is included in the public projection.
