# CHLOM ASCII Architecture and Model Atlas

CHLOM's recovered Genesis Volume and Grand Prospectus explicitly use **ASCII architecture diagrams** as part of the technical documentation strategy. ASCII is retained because it survives Markdown, Git, terminals, code review, archives and plain-text exports without proprietary rendering dependencies.

This atlas contains **public-safe explanatory models**. Machine schemas, runtime state and adopted policy remain authoritative.

## Model classification

```yaml
source_recreated: based directly on recovered source diagram/flow
modernized_mapping: same source concept mapped to current cloud-first architecture
derived_explanatory: new ASCII used to clarify reconstructed institutional contracts
```

## ASCII discipline

Use ASCII to explain:

- architecture;
- trust boundaries;
- state transitions;
- rights lineage;
- money flows;
- evidence flow;
- review/authority routing;
- reconstruction provenance.

Do **not** use ASCII as a substitute for:

- executable schemas;
- API definitions;
- legal agreements;
- production topology evidence;
- security diagrams containing restricted internals.

## Final principle

```text
ASCII = portable explanation
Schema = machine contract
Policy = authority
Runtime = evidence
```

CHLOM needs all four.
