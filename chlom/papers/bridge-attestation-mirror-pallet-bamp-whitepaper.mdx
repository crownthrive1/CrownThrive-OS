## Mirror semantics

A mirror is a projection of an attestation or status, not a second independent truth source.

```text
mirror state <= source attestation state
```

If the source attestation is revoked, corrected or superseded, dependent mirrors must update or become stale/HOLD according to the profile.

## Attestation boundary

```text
attestation != raw evidence
attestation != universal truth
signature != issuer authority
```

A target system verifies issuer identity, authority, scope, freshness and source evidence requirements before relying on a mirrored claim.

## Bridge boundary

A bridge transports or references institutional state. It does not create rights, identity or authority merely by moving a message between systems.
