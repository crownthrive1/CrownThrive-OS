## Application-based grants

A grant workflow can be modeled as:

```text

 -> identity/organization resolution
 -> eligibility
 -> evidence/review
 -> governed approval
 -> award record
 -> milestone/condition tracking
 -> disbursement authorization
 -> provider execution
 -> reconciliation / DAIL
```

## Milestone-controlled disbursement

Some grants/subsidies may require milestones. Completion evidence must be verified before the next tranche if the program requires it.

```text
milestone evidence PASS
 -> authorized disbursement candidate
```

A provider invoice or self-reported completion is not institutional proof automatically.

## LEX adoption incentives

A licensing exchange incentive can encourage legitimate supply/demand without weakening rights controls.

```text
subsidized listing fee
   != listing eligibility bypass
```

No grant can make a non-transferable DLA transferable or waive mandatory eligibility.
