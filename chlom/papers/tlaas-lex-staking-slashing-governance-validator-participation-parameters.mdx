## Historical purpose

The source-era design used economic stake to align validators, issuers/oracles and governors with correct behavior:

```text
eligible participant
 -> post required stake/bond
 -> perform bounded role
 -> earn reward for valid service

```

## Current authority correction

```text
stake held
 != source rights
 != issuer authority
 != validator eligibility automatically
 != governance authority automatically
```

A current role requires an adopted authority/eligibility contract independent of historical token possession.

## Slashing predicate

Slashing must be tied to an explicit, provable rule—not an AI suspicion or mere disagreement.

```text
eligible role
+ adopted rule
+ evidenced violation
+ authorized adjudication/execution path
= slash candidate
```

## Slash classes

Possible historical/current-safe categories include:

- equivocation/double-signing;
- knowingly false oracle/attestation data;
- provable protocol abuse;
- unauthorized signing/action;
- severe availability breach where the adopted agreement makes it slashable.

Exact production categories remain profile-specific.

## No AI-only slashing

```text
AI anomaly signal
 -> evidence/review input
 != slash authority
```

An AI score can trigger review/HOLD within policy but cannot confiscate value by itself.

## Quorum relationship

```text

```
