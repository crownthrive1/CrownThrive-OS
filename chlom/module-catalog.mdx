# CHLOM Module Catalog

The legacy CrownThrive Help Center preserved an unusually broad CHLOM module taxonomy. Phase 2.5 keeps those names in institutional memory while separating **recovered terminology** from **current production status**.

> A module appearing in the recovered Help Center does not prove that the module is deployed. Unless verified by current production evidence, decentralized and autonomous modules remain planned, research, or target architecture.

## Compliance, policy, and risk

- **ACE — Adaptive Compliance Engine** — dynamic rule mapping, risk scoring, and policy enforcement concept.
- **AIE — Anomaly Intelligence Engine** — fraud, drift, and outlier-detection concept.
- **Policy Engine / Policy DSL Compiler** — declarative rules and versioned policy compilation.
- **Policy Pallet** — target on-chain policy references and pre-execution hooks.
- **Risk Scoring Engine** — multi-vector risk evaluation.
- **Risk / Scoring Pallet** — target lightweight runtime risk gating.
- **Compliance Pack Registry** — versioned sector and jurisdiction policy-pack concept.
- **Rate Limiting & Throttle Engine** — policy-based abuse and issuance throttling.
- **Parameter & Config Service** — versioned runtime configuration and rollback.
- **Parameter / Runtime Config Pallet** — target governance-controlled parameter updates.

## Status normalization

Phase 2.5 does not force every recovered module into production. Each module should eventually receive one governed status:

- **current-core** — required by the current cloud/API baseline
- **active-production** — verified live implementation
- **controlled-test** — deployed but intentionally limited
- **planned** — approved future work
- **research** — retained design or formal exploration
- **target-architecture** — future decentralized or cryptographic layer
- **deprecated** — no longer recommended for new use
- **superseded** — replaced by a newer canonical construct

The source taxonomy is preserved so CrownThrive can continue building without losing the reasoning and vocabulary that came before.
