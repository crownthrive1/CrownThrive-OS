> **State:** documentation work queue only. Queue position does not prove implementation, rights clearance, certification, commercial availability or Phase-3 readiness.

## Queue rules

A queue item moves to a documentation PR only when Agent F can identify authoritative or appropriately classified source support and an acceptable #131 public projection.

A queue item stays HOLD when:

- source bodies or current policy are not recoverable;
- source generations conflict without accepted disposition;
- rights or IP classification are unresolved;
- public wording would reveal restricted implementation;
- the proposed claim would imply current deployment, commercial availability or certification without evidence;
- required signer identity is missing for a founder/executive override.

Research-created records remain `RESEARCH_CANDIDATE` until deliberate promotion. SimpleBase remains historical recovery provenance only.

## Current source boundaries

The first two drafted families are grounded in current public-safe CHLOM doctrine, the IP/chain-of-title standard, issue #131's disclosure gate, issue #150's identity/fingerprint distinction and restricted aggregate runtime checks. Runtime rows, private contracts, restricted evidence bodies, credentials, private economics and implementation-security internals are deliberately excluded from the public projection.

## Review handoff

Each drafted item must identify the exact branch/head, sources, changed records, classification, tests, risk, rollback/reopen conditions and unresolved items. Agent F does not vote on its own packet; the accepted constitution and current governed review path determine approval.

The queue is continuous: after one packet is accepted, rejected or held, the next Agent F pass selects the next highest-value source-supported CHLOM documentation delta.
