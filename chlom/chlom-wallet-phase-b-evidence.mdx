# CHLOM Wallet Phase B evidence

**Evidence state:** `CONTROLLED_TEST`  
**Human institutional phase:** Phase 2.99  
**Phase 3 entry:** unchanged / blocked pending the Phase 2.99 hard exit

This packet advances wallet engineering without converting test evidence into production claims.

## Stripe webhook canary

A dedicated controlled-test webhook receiver now exists behind a database runtime gate. The receiver verifies a Stripe-format HMAC signature from the exact raw body, applies timestamp tolerance, rejects `livemode: true`, enforces an event allowlist, persists a provider receipt, prevents exact provider-event replay and appends CHLOM wallet evidence without inferring entitlement.

An end-to-end canary sent the same signed synthetic event twice through the deployed Edge Function:

```yaml
first_http_status: 200
first_state: RECORDED_TEST
second_http_status: 200
second_state: DUPLICATE
result: PASS_EDGE_WEBHOOK_REPLAY_CANARY
live_event: false
money_movement: false
rights_grant: false
```

The test signing secret is synthetic and restricted. It is not a Stripe live endpoint secret.

## Entitlement and Unified Value Receipt canary

A separate controlled-test canary proved the required rights separation:

```yaml
payment_without_independent_rights: HOLD
payment_with_active_independent_rights: ALLOW_TEST
unified_value_receipt_created: true
unified_value_receipt_tamper_rejected: true
synthetic_entitlement_final_state: revoked
money_movement: false
production_rights_grant: false
result: PASS_ENTITLEMENT_UVR_CANARY
```

This is the intended CHLOM invariant: **provider evidence can participate in an entitlement decision, but it cannot be the entitlement decision by itself**.

## Runtime controls

The restricted runtime currently carries explicit controls:

```yaml
stripe_test_webhook_enabled: true
stripe_live_webhook_enabled: false
mainnet_anchor_enabled: false
```

The existence of a deployed Edge Function is therefore not equivalent to a live commerce route.

The live CrownThrive Stripe account currently contains multiple enabled and retired webhook endpoints for other CrownThrive properties. The previous Supabase institutional observer endpoint is disabled/retired. No new CHLOM Wallet live Stripe endpoint has been registered by this packet.
