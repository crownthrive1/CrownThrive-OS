# CHLOM Worked Calculations, Simulation Scenarios and Test Vectors

This page turns CHLOM formulas into **worked examples** that can be used for documentation, test fixtures and simulation.

Every number below is illustrative unless explicitly identified as source-derived historical research. None is a current price, tax rate, royalty schedule, token parameter, investment promise or legal rule.

## TV-001 — Historical net supply balance

Source-derived Genesis example.

### Inputs

```text
S = 1,000,000,000 CHLOM
i = 5% = 0.05
b = 0.001 CHLOM / transaction
N = 50,000,000,000 transactions/year
```

### Calculation

```text
issuance = iS
         = 0.05 * 1,000,000,000
         = 50,000,000

burn = bN
     = 0.001 * 50,000,000,000
     = 50,000,000

ΔS = issuance - burn
   = 0
```

### Expected result

```text
S_next = 1,000,000,000
```

Historical equilibrium illustration only.

## TV-023 — Historical risk-score arithmetic

Use the source-style expression:

```text
R = α*(amount/std_dev) + β*peer_risk + γ*KYC_level
```

Illustrative inputs:

```text
α = 0.4
β = 0.3
γ = 0.3
amount/std_dev = 2.0
peer_risk = 0.6
KYC_level = 1.0
```

```text
R = 0.4*2.0 + 0.3*0.6 + 0.3*1.0
  = 0.8 + 0.18 + 0.30
  = 1.28
```

This demonstrates why raw source formulas require clear normalization and feature semantics before production. A score over `1` may be fine for an unbounded score but not if consumers incorrectly assume probability.

## Regression principle

Once a vector tests an adopted invariant, later changes should not alter its expected outcome without a documented version change.

```text
old vector changes result
      |
      v
is behavior intentionally changed?
  |                    |
 NO                   YES
  |                    |
  v                    v
REGRESSION        NEW VERSION + ADR
```

## Final rule

Worked examples exist to expose assumptions.

```text
FORMULA + NUMBERS + EXPECTED RESULT
             |
             v
        TESTABLE CLAIM
```

That is far more useful than leaving CHLOM mathematics buried in narrative prose.
