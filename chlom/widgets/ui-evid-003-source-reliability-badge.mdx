# UI-EVID-003 — Source Reliability / Applicability Badge

## Component identity

```yaml
surface_id: UI-EVID-003
component: Source Reliability / Applicability Badge
classification: public_safe_component_contract
owner_capabilities: Evidence; Oracle; Policy
```

## Purpose

This badge identifies what kind of source produced an observation and whether that source is applicable to the claim being evaluated. It keeps provider observations, institutional records, user submissions, model outputs and other sources from being displayed as interchangeable.

## Data contract

Source stable ID, source class, claim domain, applicability state, registry version, freshness/revocation state, independence group where relevant and public-safe source label.

## States

`PRIMARY_FOR_CLAIM`, `SUPPORTING`, `OBSERVATIONAL`, `UNVERIFIED`, `OUT_OF_SCOPE`, `STALE`, `REVOKED`, `REDACTED`.

## Semantics

Source status is claim-specific. A provider can be primary evidence for its own transaction event while being only supporting evidence for ownership or licensing. The consuming policy determines institutional effect.

## Interactions

Open source-registry details, inspect freshness, and view corroborating-source summaries where permitted.

## Accessibility and tests

Use textual states rather than color alone. Test one source used for different claim domains, stale/revoked records, provider alias changes, independence-group handling and restricted metadata.

## Versioning

Source classes and applicability rules are registry-versioned; presentation must not infer them from brand/logo alone.
