# UI-EVID-001 — DAIL Event Timeline

## Component identity

```yaml
surface_id: UI-EVID-001
component: DAIL Event Timeline
classification: public_safe_component_contract
owner_capabilities: DAIL; Evidence; Audit
```

## Purpose

The DAIL Event Timeline renders canonical or authorized-projection events for an object, showing how its institutional state evolved. It is not merely an activity log; it preserves typed corrections, supersessions, authority/evidence references and effective-state transitions.

## Data contract

Event ID/type, actor class, subject/object refs, occurred/observed/effective timestamps, public-safe payload summary, evidence refs, authority/policy refs, correction/supersession links, classification/redaction state and event digest/receipt where permitted.

## States

`CURRENT`, `CORRECTED`, `SUPERSEDED`, `REVERSED`, `CONFLICT`, `REDACTED`, `PARTIAL`, `ERROR`.

## Semantics

Never remove prior events from the timeline because a correction exists. Present current effective state separately while allowing authorized users to inspect lineage.

## Interactions

Filter by event type, actor, time or state; expand safe payload; open evidence; trace correction chain; copy stable event reference; navigate to object/case/calculation.

## Privacy

Projection policy must redact restricted event bodies and prevent client-side access to hidden fields. The timeline can disclose that a protected event exists without exposing its contents where policy allows.

## Accessibility/tests

Provide table/list equivalent, keyboard filters and explicit time labels. Test correction chains, backdated effective events, redactions, conflicts, pagination and timezone normalization.

## Versioning

Event schema versions remain visible to the renderer; compatibility mappings must preserve historical meaning.
