# UI-INT-003 — Platform Adapter Health

## Component identity

```yaml
surface_id: UI-INT-003
component: Platform Adapter Health
classification: role_scoped_component_contract
owner_capabilities: Integrations; API Gateway; Observability
```

## Purpose

This component reports whether an adapter connecting CHLOM to a platform/provider can currently translate identities, events, rights, payments or other records according to its contract.

## Data contract

Adapter ID/version, platform/provider class, tenant/environment, supported capability set, schema/version compatibility, status, last sync/read/write, last error class, mismatch count, dependency refs and deployment/config version.

## States

`HEALTHY`, `DEGRADED`, `SCHEMA_MISMATCH`, `AUTH_REQUIRED`, `SYNC_LAG`, `DISABLED`, `UNSUPPORTED_VERSION`, `ERROR`.

## Semantics

Adapter health indicates technical integration capability only. A healthy adapter cannot create CHLOM rights, authority or policy approval from provider state.

## Interactions

View supported mappings, inspect public-safe errors, refresh/sync, open dependency status and navigate to governed adapter configuration. Secrets remain vaulted.

## Tests

Test supported version, provider schema drift, auth loss, stale sync, wrong tenant mapping, partial capability, provider outage and adapter rollback.

## Versioning

Adapters are independently versioned and must declare compatibility with CHLOM contract/schema versions.
