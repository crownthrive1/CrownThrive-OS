# UI-REV-002 — Royalty / Commission Statement

## Component identity

```yaml
surface_id: UI-REV-002
component: Royalty / Commission Statement
classification: role_scoped_component_contract
owner_capabilities: Economics; DAIL; Settlement
```

## Purpose

This component gives a recipient or authorized operator a reproducible statement of how a governed economic event produced an allocation, while keeping calculation, provider execution and final settlement clearly separated.

## Data contract

Statement ID, economic event, gross/net basis, approved deductions, schedule ID/version, recipient allocation, currency/unit, rounding/residue summary, hold/reserve state, provider aliases, settlement status and calculation/DAIL refs.

## States

`CALCULATED`, `PAYMENT_PENDING`, `SETTLED`, `PARTIALLY_SETTLED`, `HOLD_MISMATCH`, `REFUNDED`, `REVERSED`, `SUPERSEDED`.

## Semantics

A calculated earning is not necessarily settled cash. Provider balances are evidence; the statement's institutional meaning comes from the authorized schedule and reconciliation process.

## Interactions

Inspect calculation record, schedule, source event, payment evidence, reconciliation and correction/reversal history. Export is role/purpose scoped.

## Tests

Test exact statement, partial settlement, provider fee mismatch, refund/reversal, schedule boundary, rounding residue and recipient visibility isolation.

## Versioning

Statement schema retains the exact schedule/calculation versions used.
