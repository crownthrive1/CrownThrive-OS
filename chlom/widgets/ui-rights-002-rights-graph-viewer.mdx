# UI-RIGHTS-002 — Rights Graph Viewer

## Component identity

```yaml
surface_id: UI-RIGHTS-002
component: Rights Graph Viewer
classification: public_safe_component_contract
owner_capabilities: Rights; DLA; LEX; DAIL
```

## Purpose

The Rights Graph Viewer visualizes the chain from source/control evidence through agreements, Dynamic Licensing Assets, sublicenses, derivative grants and restrictions. It is the visual companion to ALG-004 and FORM-009/FORM-010.

## Data contract

Nodes use stable IDs, typed node classes, status, effective dates and public-safe labels. Edges use typed semantics such as `controls`, `grants`, `sublicenses`, `derives_from`, `supersedes`, `revokes` or `constrains`. An untyped line must never imply transfer of rights.

## States

`RESOLVED`, `PARTIAL`, `CONFLICT`, `HOLD_EVIDENCE`, `REVOKED_BRANCH`, `REDACTED_NODE`, `ERROR`.

## Visualization rules

Show source roots distinctly from provider aliases. Show revoked/expired nodes without deleting them. Flag cycles or unresolved conflicts. Redacted nodes retain existence/relationship where disclosure allows without exposing private metadata.

## Interactions

Pan/zoom, select node, inspect rights summary, open evidence lineage, filter by territory/time/channel, compare versions and trace effective-right path. Editing is separate and authority-gated.

## Accessibility

Provide a non-graph textual/tree alternative with keyboard traversal and relationship labels. Color alone cannot encode status or edge type.

## Security/privacy

The viewer consumes an authorized projection. It must not query unrestricted evidence directly from the client. Restricted contract terms or private Fingerprint data stay behind role-scoped evidence views.

## Tests

Test deep chains, branch revocation, conflict, cycle detection, redacted node, mobile fallback, large graph performance and text-equivalent accessibility.

## Versioning

Node/edge taxonomy is schema-versioned; old graph records remain renderable through compatibility mappings.
