# UI-INT-001 — API Client Status

## Component identity

```yaml
surface_id: UI-INT-001
component: API Client Status
classification: role_scoped_component_contract
owner_capabilities: API Gateway; Identity; Audit
```

## Purpose

This component shows whether an API client/application is registered and usable for a defined CHLOM environment and scope. It exposes metadata and health—not client secrets, API keys or tokens.

## Data contract

Client stable ID, display name, owner/tenant, environment, authentication method class, granted scopes, status, credential rotation/expiry indicator, last successful use, last failure, rate/usage summary and audit/DAIL refs.

## States

`ACTIVE`, `LIMITED`, `ROTATION_DUE`, `AUTH_EXPIRED`, `REVOKED`, `SUSPENDED`, `RATE_LIMITED`, `ERROR`.

## Semantics

Technical credentials grant only their configured API scope. They do not substitute for underlying business/legal authority enforced by the called endpoint.

## Actions

View scopes, rotate/revoke through approved credential management, inspect audit events and test connection where policy allows. Never render or recover a secret value after creation unless the secret system explicitly supports it.

## Tests

Test active client, expired token, revoked scope, wrong environment, rate-limited client, cross-tenant client, secret redaction and scope change.

## Versioning

Auth/scope schemas are versioned; clients bind to explicit API contract versions where applicable.
