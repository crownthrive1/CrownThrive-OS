# UI-RIGHTS-003 — Provenance / Evidence Timeline

## Component identity

```yaml
surface_id: UI-RIGHTS-003
component: Provenance / Evidence Timeline
classification: public_safe_component_contract
owner_capabilities: Rights; Evidence; DAIL
```

## Purpose

This timeline presents how the current asset/rights state came to exist: registration, source evidence, agreement, license issuance, transfer, correction, revocation, dispute and adjudication events. It makes lineage visible without flattening history into one mutable status.

## Data contract

Stable event ID, event type, effective/observed time, actor/source class, public-safe description, evidence reference, supersedes/corrects relationship and resulting status. Confidential evidence bodies remain behind protected references.

## States

`COMPLETE`, `PARTIAL_LINEAGE`, `CONFLICT`, `REDACTED_SEGMENT`, `LOADING`, `ERROR`.

## Timeline semantics

Order events by the applicable event/effective time while preserving recorded-at metadata. Corrections display as corrections, not replacements. Conflicting evidence should be visible as unresolved rather than silently resolved by UI order.

## Interactions

Filter by event class, open public evidence details, compare correction chains and navigate to rights/DLA records. Restricted users may open protected evidence through a separate access-controlled viewer.

## Accessibility

Provide a chronological list/table equivalent, semantic headings and text descriptions for event relationships.

## Tests

Test out-of-order observations, backdated correction, redacted evidence, branch conflict, large timeline, mobile view and timezone normalization.

## Versioning

Event-type vocabulary follows DAIL schema versions; visual redesign must not change historical semantics.
