# UI-RIGHTS-005 — Usage / Territory / Term Summary

## Component identity

```yaml
surface_id: UI-RIGHTS-005
component: Usage / Territory / Term Summary
classification: public_safe_component_contract
owner_capabilities: Rights; DLA
```

## Purpose

This component makes permission boundaries visible in a compact, comparable format so users can answer: **what use is permitted, where, when, through which channel, and under what quantity/cap limits?**

## Data contract

Use/right types, territory/jurisdiction set, valid-from/valid-until, channels/media, exclusivity, quantitative usage cap and used/remaining values where applicable, transferability/sublicensing indicators and scope version.

## States

`IN_SCOPE`, `OUT_OF_SCOPE`, `PARTIAL_SCOPE`, `EXPIRED`, `NOT_YET_EFFECTIVE`, `UNLIMITED_WHERE_AUTHORIZED`, `HOLD_UNKNOWN_SCOPE`, `REDACTED`.

## Semantics

Unknown is not unlimited. An omitted territory or term is not automatically global/perpetual. Unlimited values must be explicit under the governing license/schema.

## Interactions

Role-scoped viewers can expand included/excluded territories, compare requested use to licensed scope, open parent rights and inspect cap/usage history.

## Accessibility

Territory maps, if used, require a textual jurisdiction list. Dates and caps must be displayed in unambiguous formats/units.

## Tests

Test global versus explicit territories, time boundaries, channel mismatch, cap reached, explicit unlimited, missing scope, inherited narrower child scope and timezone handling.

## Versioning

Scope taxonomy and territory codes are versioned; historical versions remain interpretable.
