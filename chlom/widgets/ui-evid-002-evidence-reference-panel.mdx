# UI-EVID-002 — Evidence Reference Panel

## Component identity

```yaml
surface_id: UI-EVID-002
component: Evidence Reference Panel
classification: public_safe_component_contract
owner_capabilities: Evidence; DAIL; Vault
```

## Purpose

The Evidence Reference Panel gives users a canonical way to inspect the evidence **reference and status** supporting a decision without copying the evidence body into every page, case or task.

## Data contract

Evidence stable ID, evidence type, source/issuer class, custody/visibility class, observation/creation time, digest or integrity reference where permitted, currentness state, supersession/revocation state, related decision/object IDs and access-request/open action.

## States

`AVAILABLE`, `RESTRICTED`, `REDACTED`, `STALE`, `SUPERSEDED`, `REVOKED`, `MISSING`, `INTEGRITY_HOLD`, `ERROR`.

## Semantics

A reference proves that an evidence object is tracked; it does not prove the underlying claim is true. Source authority and attestation verification remain separate.

## Privacy

Restricted filenames, personal data, private contract text or vault paths should be hidden if revealing them would disclose protected information. Access uses explicit role/purpose controls.

## Interactions

Open authorized evidence, copy stable reference, inspect source authority/currentness, trace supersession, request access or attach reference to a review/task where permitted.

## Tests

Test public evidence, restricted evidence, stale item, missing custody object, digest mismatch, superseded evidence and role change while panel is open.

## Versioning

Custody classes and evidence metadata schemas are versioned centrally.
