## Source basis

Portions of historical CHLOM material, including Grand Prospectus/tokenomics lineage, use **CHLM** as token/native-token shorthand. Other source families distinguish **CHLOM Coin** as a utility/economic token and **CHM** as a governance token.

The recovered evidence does not justify silently converting `CHLM` into a third current token identity.

## Purpose of this record

This article exists to prevent notation drift from becoming false architecture.

```text
historical source says CHLM
       |
       v
preserve exact source notation
       |
       +--> map to source/context lineage
       |
       +--> DO NOT infer third token
```

## Current interpretation rule

```text
CHLM occurrence
 -> historical notation requiring source/context inspection
 -> not a current canonical token symbol by default
```

If a source explicitly defines CHLM differently, that source-era definition should be attached/versioned rather than normalized away.

## Relationship to CHLOM Coin

Some CHLM occurrences may function as shorthand/native-token notation near material otherwise discussing CHLOM Coin/economic-token behavior. That contextual relationship can be recorded, but this article does not globally declare every CHLM occurrence synonymous with CHLOM Coin unless the source supports it.

## Relationship to CHM

CHM is separately preserved as historical governance-token research. CHLM should not be autocorrected into CHM because one character differs.

```text
CHLM != CHM automatically
```

## Relationship to current CHLOM

Current CHLOM is the **Compliance Hybrid Licensing and Ownership Model**, not a token ticker. Current architecture does not require a live token.

## Failure modes

- OCR/transcription error treated as intentional symbol;
- CHLM auto-normalized to CHM;
- CHLM treated as third token without evidence;
- historical notation promoted to current product claim;
- source-specific meaning generalized ecosystem-wide;
- formula rewritten so original source notation is lost.

## Test vectors

1. source says `CHLM` with no definition -\> preserve \+ mark ambiguous;
2. source explicitly defines CHLM as native token -\> record source-era mapping only;
3. current docs mention token governance -\> use CHM historical record, not CHLM unless sourced;
4. current utility-token history -\> link CHLOM Coin record, preserve source notation separately;
5. public page claims CHLM is live -\> fail current-evidence check;
6. founder adjudicates one source occurrence -\> update that lineage without erasing original notation;
7. search for CHLM -\> surface notation page plus related token records;
8. historical formula -\> retain source symbol and normalized interpretation if known.
