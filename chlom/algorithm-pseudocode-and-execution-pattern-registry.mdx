# CHLOM Algorithm, Pseudocode and Execution Pattern Registry

CHLOM source papers explicitly reference novel algorithms, trade secrets, pseudocode, state machines and machine-executable compliance logic. The institutional knowledge base must register those assets without publishing protected implementation secrets as if documentation were source code.

## ALG-001 — Three-valued policy evaluation

**Purpose:** resolve required controls to PASS, HOLD or DENY.

```text
function evaluate_required_controls(controls):
    disposition = PASS

    for control in controls:
        result = evaluate(control)

        if result == DENY and control.hard_block:
            return DENY

        if result == DENY:
            disposition = max_restrictive(disposition, DENY)
        else if result == HOLD:
            disposition = max_restrictive(disposition, HOLD)

    return disposition
```

Invariant:

```text
UNKNOWN required fact != PASS
```

## ALG-002 — Authority-aware decision gateway

```text
function authorize(action, provisional_decision, actor, context):
    if provisional_decision == DENY:
        return DENY

    authority = resolve_authority(actor, action, context)

    if authority == NONE:
        return DENY

    if required_approval_missing(action, context):
        return HOLD

    if evidence_stale(action, context):
        return HOLD

    if provisional_decision == HOLD:
        return HOLD

    return PASS
```

Core invariant:

```text
AI recommendation != execution authority
```

## ALG-004 — Rights graph closure

Let a rights graph contain source nodes, claims, agreements, licenses and derivative grants.

Public-safe traversal:

```text
function effective_rights(node):
    if node.type == SOURCE_RIGHT:
        return node.controlled_rights

    parent = effective_rights(node.parent)
    granted = node.granted_rights
    constraints = node.constraints

    return intersect(parent, granted, constraints)
```

Invariant:

```text
child_rights ⊆ parent_rights
```

function validate_sublicense(parent_dla, requested_child):

## ALG-020 — Risk threshold evaluation

```text
function risk_disposition(score, uncertainty, rules):
    if rules.hard_block:
        return DENY

    if rules.required_evidence_missing:
        return HOLD

    if uncertainty > rules.max_uncertainty:
        return HOLD

    if score >= rules.deny_threshold:
        return DENY

    if score >= rules.hold_threshold:
        return HOLD

    return PASS_CANDIDATE

## ALG-023 — Review quorum

function review_quorum(reviews, policy):
    eligible = filter_valid_reviews(reviews)

    if count(eligible) < policy.minimum_count:
        return HOLD

    support = sum(weight(r) for r in eligible if r.decision == APPROVE)
    total = sum(weight(r) for r in eligible)

    if support / total >= policy.threshold:
        return APPROVED_CANDIDATE

    return NOT_APPROVED
```

```text
algorithm exists
purpose
inputs/outputs
safety invariants
interface contract
source lineage
```
