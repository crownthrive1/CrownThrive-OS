# Virality Music Universe and Canon Registry

## Purpose

Virality Music is organized around governed worlds, series, characters, corrections, editions and rights—not a flat genre catalog. This registry distinguishes established public portals, nested series/record rooms, governed source-level worlds, developing lanes and archived structures.

No agent may promote a collection into a universe merely to make a count reconcile.

## Canon authority stack

When sources disagree, preserve this order:

1. live Virality site — current public position;
2. approved books/current editions — what already happened in published canon;
3. protected canon bible/canon sheets — protected continuity/source truth;
4. VM-BOOK-001 — release/quality gate;
5. VM-BOOK-002 — packaging/slate/commercialization governance;
6. working conversations/notes — supporting design context.

Conflicts stop for a canon ruling. Do not silently retcon published canon.

## Publishing gate

A manuscript is not a release merely because a PDF exists. Require canon/series position, final editable manuscript, searchable PDF, validated EPUB where applicable, spoiler-safe preview, cover/rear/spine/mockups, story art, rights/series metadata, accessibility/technical QA, approved pricing, checksum/release manifest, archived source package and final release approval.

Reader/store lifecycle remains:

`concept → manuscript → canon_locked → master_complete → release_manifest_complete → reader_upload_pending → reader_verified → price_verified → entitlement_verified → offer_active → superseded|archived`.

## Audience and licensing firewall

Adult TrapOpera/ZaZa/Pacific Pressure material must not flow into Little Crowns, family, ministry or open-public bundles without explicit audience/rights governance.

Universe-level licenses resolve explicit assets, rights, territory, term, media, exclusivity, approvals and reserved rights. A universe partnership never automatically includes every master, composition, character, mark, edition or future derivative.
