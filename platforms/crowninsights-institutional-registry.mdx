## Current public evidence

CrownThrive portfolio material describes CrownInsights as a work in progress for a holistic learning experience. The intended role includes visual guides, step-by-step walkthroughs, videos and future interactive learning support across CrownThrive platforms.

The currently reachable host at `insight.crownthrive.com` presents a guide-search interface but currently reports that no categories have been added.

Therefore CrownInsights must **not** be classified as a mature populated learning library merely because the host responds.

## Naming conflict

- `CrownInsights` in CrownThrive portfolio and ecosystem copy;

Classification: `alias/naming reconciliation required`.

Until founder/brand registry adjudication changes the name, use `CrownInsights` as the canonical institutional working name and retain `CrownInsight` as an observed alias/current-host label. Do not silently rewrite historical URLs or branding without redirect and SEO review.

## Intended role

The portfolio concept positions CrownInsights as a central visual-support layer that can be embedded or linked across CrownThrive properties.

Potential content classes include:

- visual guides;
- annotated screenshots;
- step-by-step walkthroughs;
- onboarding guides;
- explainer videos;
- feature demonstrations;
- accessibility-oriented alternative explanations;
- role-specific guidance;
- future quizzes or progress-linked learning objects where appropriate.

## Boundary with ThriveSupport

CrownInsights should not become a competing institutional source of truth.

Recommended relationship:

```text
authoritative knowledge / policy / platform record
               ↓
ThriveSupport knowledge authority
               ↓
CrownInsights visual-learning projection
               ↓
embedded visual guides across platforms
```

A visual guide should reference the same stable knowledge/platform records as text documentation so screenshots and walkthroughs can be invalidated automatically when interfaces change.

## Boundary with CrownThriveU and QuizNuggets

- `CrownInsights` — visual explanation and guided support;
- `CrownThriveU` — governed courses, learning paths, credentials and education programs;
- `QuizNuggets` — micro-learning, knowledge checks, challenges or gamified validation;
- `ThriveSupport` — institutional knowledge authority and support documentation.

These can share source records and content components without duplicating ownership.

## Screenshot and media provenance

Visual guides require stronger provenance than ordinary prose because screenshots may reveal:

- private user data;
- administrator controls;
- API keys or tokens;
- unpublished product features;
- third-party copyrighted content;
- outdated prices or policy text;
- unsafe example account information.

Required controls:

- sanitized demonstration accounts;
- redaction/DLP scan;
- asset source/ownership record;
- interface version;
- accessibility alt text/captions;
- sensitive-area review;
- expiration/review trigger.

## Authentication and role projection

Current public host reachability does not establish authenticated role-specific guidance.

Future CrownInsights may project:

- public guides;
- member guides;
- partner/developer walkthroughs;
- operator training;
- role-restricted visual SOPs.

Restricted/operator guides must inherit the same RBAC/ABAC rules as the private knowledge control plane. Hiding a category is not authorization.

## Automation opportunity

CrownInsights is a strong candidate for governed semi-automated generation:

```text
platform release/event
→ detect changed interface/component
→ find dependent guides
→ capture approved test-environment screenshots
→ regenerate draft steps/callouts
→ accessibility and secret scan
→ compare against prior guide
→ human/agent review according to risk
→ publish new guide version
→ archive/supersede prior projection
```

Legal, payment, security, child/minor, sensitive identity and irreversible-action guides require higher review classes.
