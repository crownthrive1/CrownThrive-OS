## ThriveTools OPT API evidence and provider-mapping HOLD

`S109` preserves an earlier dated API snapshot that identified **ThriveTools OPT v4.0.0** and REST base `https://optimize.thrivetools.io/api`, with server-side credential binding and an authenticated `GET /check-status` read passed. That evidence remains valid as a dated interface observation; it is **not** sufficient to identify the current application engine.

A newer founder-supplied administrator snapshot dated 2026-08-21 for `https://optimize.thrivetools.io/admin/dashboard` visibly presents **CrownPulse** branding and **66socialproof / AltumCode v57.0.0**, with `v61.0.0` available and support expired.
