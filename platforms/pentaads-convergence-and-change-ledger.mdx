## Source authority rule

The private PentaAds repository is the package source. Consumer repositories contain exact-SHA federation pointers. They do not fork or duplicate private runtime code.

The public Brilliant Directories MCP repository may:

- discover BD capabilities;
- prepare and validate placement contracts;
- report holds;
- register readback.

It may not copy private source, expose credentials, activate campaigns, move money or manufacture BD write authority.

## ThriveBase evidence surfaces

Release `0.2.0` introduced additive, RLS-protected registries for:

- BD adapter definitions;
- reusable BD surfaces;
- source/inventory/public certifications;
- convergence releases;
- recovery records;
- recent CrownThrive change reconciliation.

Historical rows are retained. Certification, recovery and change-ledger records are append-only.

## Governance state

CHLOM preserves:

- D2/A2 operating ceiling;
- D3 reservation for spend and money movement;
- human gate for live BD template mutation;
- independent verification;
- no-delete evidence policy;
- no-secret exposure;
- recovery and public-readback requirements.

CIE maps PentaAds to community publisher monetization, cultural distribution infrastructure and contextual advertising integrity. The release has no fabricated score.

## Institutional mirror rules

Drive/Sheets is a human and institutional mirror—not the HOT production database. It may display:

- inventory and zone identities;
- placement surfaces;
- release and certification status;
- public-safe source and evidence hashes;
- recovery and hold state;
- recent-change reconciliation.

It must not contain API tokens, service-role keys, cPanel credentials, private source bodies or other secrets.

## Reconciliation semantics

Each change is classified as one of:

- `CURRENT` — current durable state;
- `SUPERSEDED` — retained historical state with a forward pointer;
- `HELD` — defined but blocked by a named unresolved predicate;
- `TEMPORARY` — diagnostic, migration or one-time execution artifact;
- `UNVERIFIED` — observed but not independently established;
- `DOCUMENTED` — current PentaDocs representation exists.

Reconciliation never silently deletes or flattens conflicting history.
