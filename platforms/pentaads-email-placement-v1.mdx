<Info>
  PentaAds Email Placement v1 is both a native PentaAds add-on and an independently licensable software asset. It is intentionally narrower than the planned V2 deployment system.
</Info>

## What v1 does

PentaAds Email Placement v1 accepts message context, a deterministic seed, and an optional placement/personality level. It scores an approved sponsored-placement catalog, chooses a bounded placement and an email-compatible zone projection, then renders the result as static email-safe HTML with a plain-text fallback.

| Property | V1 behavior |
| --- | --- |
| Selection | Server-side contextual scan \+ deterministic tie-break |
| Placement state | Explicitly `sponsored` |
| Render mode | Static email HTML \+ plain text |
| Browser scripts | None |
| Iframes | None |
| Tracking default | None |
| Provider credentials bundled | No |
| Production selector | `pentaads-email-placement` v1 |
| Product contract | `ct.pentaads.email-placement.product-manifest.v1` |
| Runtime contract | `ct.pentaads.email-placement.v1` |
| Source package | `packages/email-placement-v1/` in the canonical private PentaAds repository |

The product is designed to keep sponsored material distinguishable from editorial communication. A customer may change presentation styling but should preserve a clear sponsored disclosure.

## Default rights boundary

CrownThrive retains ownership of PentaAds, CrownThrive marks, architecture, selection/routing logic, algorithms, schemas, documentation, commercial packaging and derivative versions.

Standard checkout does **not** grant:

- ownership transfer;
- sublicensing or assignment;
- standalone source/binary resale;
- OEM or white-label resale;
- PentaAds or CrownThrive trademark ownership;
- provider credentials or Vault material;
- autonomous campaign spend, payout or settlement authority;
- future major versions, including V2.

The Developer, Network and Self-Hosted Source tiers grant source or self-host rights only inside their stated licensed scope. Enterprise/OEM/white-label/resale terms require a separately executed agreement.

## Credential and Vault boundary

V1 requires **no new secret**. The selector and renderer are credential-free. Provider credentials are not copied into the package, checkout, documentation or customer delivery.

If a deployment later needs provider access, it must consume the applicable PentaAds provider lane through governed server-side custody. Purchasing the software never grants an AdLuxe, Stripe, Mailgun, Supabase or other provider credential.

## Production evidence

The production selector is deployed as `pentaads-email-placement` v1 with authenticated access. The commercial package is integrated into the PentaAds distribution index and repository test suite, and exact-head product/release CI passed for the commercialization source revision.

This evidence establishes the packaged V1 implementation and commercial rail. It does not grant campaign authority, prove advertiser spend, prove publisher revenue or certify future V2 behavior.

## V2 is deliberately frozen

<Warning>
  V1 is the current commercial release. Universal website installation and one-button cross-platform deployment are **not** V1 claims.
</Warning>

Reserved V2 work includes:

- dynamic modular runtime behavior;
- richer signal-driven placement;
- universal website script/bootstrap installation;
- one-button deployment and rollback;
- portable deployment to arbitrary websites;
- broader entitlement and deployment automation;
- stronger self-service commercial operations.

V2 ships only after sufficient V1 production data and stability evidence plus an explicit CrownThrive release decision. V2 is separately versioned and is not automatically included in a V1 purchase.
