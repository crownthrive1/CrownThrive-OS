## Required automation posture

The current founder-authorized GitHub scope is intentionally limited to **`crownthrive1/CrownThrive-Support`**. Do not connect additional GitHub repositories to this documentation workflow unless a later explicit founder decision changes that boundary.

Within CrownThrive-Support, automation should register and maintain:

- repository and branch;
- platform/service IDs represented by documentation;
- documentation impact mapping;
- code/document owners and approval class;
- public-safe API/schema/event documentation sources;
- changelog policy;
- secrets boundary;
- documentation-agent permissions;
- rollback path.

Application/platform state outside the repository is imported as governed evidence through authorized public inspection, source/release artifacts, Drive/File Library records, provider exports and other registered sources. Those external sources remain `not_connected_to_mintlify_workflows` rather than candidates for automatic Git attachment under the current directive.

Documentation agents should run from CrownThrive-Support PR/change events and bounded scheduled evidence/drift checks. Hourly no-change runs are heartbeats and must not create timestamp-only commits.

## Publication boundary

Mintlify may publish approved public-safe or authenticated projections. It must not receive unrestricted production secrets, raw customer/payment payloads, privileged communications, confidential rights evidence or protected trade-secret implementation merely because the rendering service can store text.

## Recovery standard

CrownThrive must retain:

- Git repository and release history;
- machine-readable navigation/article manifest;
- off-provider content export;
- source register and checksums;
- redirect/canonical map;
- custom-domain/DNS record;
- workflow definitions;
- rebuild instructions;
- last known good deployment reference.

The institution must be able to rebuild documentation if Mintlify becomes unavailable.

## Service-product status

Mintlify is registered as a **third-party documentation infrastructure service/product** in the CrownThrive operating spine. It is not a CrownThrive-owned SaaS product and should not be marketed as such.
