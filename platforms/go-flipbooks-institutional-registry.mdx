# Go Flipbooks Institutional Registry

## Identity

- **Stable platform ID:** `ct.platform.go-flipbooks`
- **Owner:** CrownThrive, LLC
- **Type:** digital library, interactive reader, preview and licensed-content delivery layer
- **Management state:** P0 / Active-Expand in the August 2026 Holdings registry
- **Pass B state:** `institutional_role_verified / direct-host-vendor-api verification pending`

Go Flipbooks renders authorized reading experiences. It does not automatically own the books, courses, catalogs, guides or source IP it displays.

## Lifecycle separation

Virality publication evidence shows a completed Publication V3 asset can still be `Go Flipbooks upload pending`. Therefore keep these states separate:

`master_complete → checksum_manifest_complete → reader_upload_pending → reader_verified → price_verified → entitlement_verified → offer_active`.

A finished master is not automatically an active reader or retail offer.

## Commerce and entitlements

Use separate records for product, price, payment, license/terms, entitlement, reader grant, access event and revocation/expiration. Technical access does not create a license; a payment receipt does not grant commercial rights beyond its terms.

## Virality and ministry integration

Virality remains the source institution for its books/worlds/catalog IP; Go Flipbooks renders authorized reader routes. KJV Visualized / Sermon Toolkit may use approved readers for studies, visual resources and licensed ministry publications while preserving Scripture/commentary boundaries and license classes.

MVP/IO should link to authorized reader routes rather than copying protected source PDFs into a universal media store.

## API / vendor state

Pass B public scan could not independently retrieve the direct `goflipbooks.com` host or public API documentation. Current engine/vendor/API remains `unverified_current`, not `nonexistent`.

Potential adapters: provision reader, sync edition/version, verify entitlement, grant/revoke access, issue preview, fetch analytics, archive/supersede and export metadata.

## Recovery

CrownThrive must retain outside the reader vendor canonical masters, metadata/IDs, rights/licenses, customer/order/entitlement source records, route mapping, analytics exports and edition history.

**Current conclusion:** Go Flipbooks has a verified institutional role and priority, but its current direct vendor/API implementation is not yet production-verified by Pass B.
