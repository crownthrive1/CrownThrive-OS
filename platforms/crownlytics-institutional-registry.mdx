# CrownLytics Institutional Registry

## Identity

- **Stable platform ID:** `ct.platform.crownlytics`
- **Canonical name:** CrownLytics
- **Owner/operator:** CrownThrive, LLC
- **Primary role:** privacy-first web analytics, conversion measurement, visitor-journey analysis, evidence normalization and approved institutional metric support.
- **Historical engine source row:** `S100-ENG-085` — 66analytics lineage.

Current CrownLytics public positioning describes real-time analytics, anonymized visitor tracking, visitor journeys, conversion measurement, heatmaps, session replays, outbound-click monitoring, custom reporting, data exports, team collaboration and developer API access.

Those product claims are useful current public evidence. Exact implementation/version/provider/data-retention and entitlement state remain independently governed.
