## Institutional role

Penta App Factory is CrownThrive's governed software-generation and application-production lane. It converts approved application intent into repeatable source, tests, deployment contracts, documentation, continuity records and provider-specific release assets.

It is not an unrestricted autonomous deployer. It separates:

- blueprint and specification generation;
- source generation and compilation;
- testing and validation;
- provider deployment preparation;
- bounded deployment execution;
- independent certification;
- continuity and recovery.

## Phase 1 evidence package

The August 30 release evidence contains:

## Operating chain

`intake → blueprint → source generation → compile → test → package → provider preflight → governed deploy → readback → certification → continuity`

## Authority boundaries

The Phase 1 factory may autonomously perform low-impact, deterministic work such as:

- validate an application request;
- generate source and contracts;
- run tests and static checks;
- create deployment artifacts;
- prepare branches and pull requests;
- record evidence and continuity metadata.

It does not automatically inherit authority to:

- publish to an unverified production destination;
- expose or transfer credentials;
- change payment, rights or legal terms;
- delete production data;
- bypass provider or repository governance;
- self-certify a deployment it originated.

## Offline hardening

The offline-hardening record strengthens the factory's ability to survive provider or model interruption by preserving:

- canonical source and package identities;
- deterministic build inputs;
- local validation and test assets;
- release manifests;
- provider adapter contracts;
- recovery and handoff documents;
- restart and continuity instructions.

A model may assist planning and generation, but the factory's durable source, state, tests, contracts and evidence remain independently inspectable.

## Convergence requirements

Every factory release must converge across:

- canonical GitHub source;
- ThriveBase runtime and evidence state;
- Penta execution and certification contracts;
- PentaDocs operator and governance documentation;
- Drive custody mirrors;
- provider deployment and public readback;
- recovery records.
