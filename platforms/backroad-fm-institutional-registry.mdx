# Backroad FM Institutional Registry

## Identity

- **Stable platform ID:** `ct.platform.backroad-fm`
- **Parent:** `ct.platform.virality-music`
- **Owner/operator:** CrownThrive, LLC
- **Type:** radio/broadcast continuity, programming, discovery, requests, premieres and listening-room lane
- **Evidence state:** `operational_evidence_present / capability_verification_partial`

Backroad FM is a governed Virality radio universe, not merely an embedded player. It connects approved catalog programming, requests, radio edits, premieres, listening rooms, sponsor inventory and cross-media continuity.

## Requests and premieres

An August 10, 2026 Backroad submission used the route `Sponsored Premiere Build · $500+`. Treat this as a dated intake option, not a permanent rate or guaranteed editorial placement.

Recommended state flow:

`received → identity_checked → rights_checked → content_reviewed → programming_review → commercial_review → approved → scheduled → aired → evidence_logged → retained/archive`.

Advertising/sponsorship payment remains separate from editorial/programming discretion.

## Rights controls

Before broadcast, resolve work/master IDs, composition/master authority, provider restrictions, broadcast/performance permission, clean/explicit rating, territory/window, sponsor restrictions, cue metadata, takedown/hold state and source evidence.

A DSP release, SoundCloud upload or distributor acceptance is not proof of broadcast or monetization clearance.

## Melanated Studios handoff

The Melanated Studios V1.0 plan assigns Backroad FM the radio-continuity lane for radio edits, replay blocks, simulcasts, listening-room tie-ins and music-led programming. Backroad distributes approved derivatives; it does not own the show IP.
