## Institutional role

PentaAds Placement OS is the governed advertising-placement, connector, installation, verification and maintenance layer for CrownThrive's AdLuxe Network estate. It converts provider inventory into reusable placement contracts without giving individual sites, models or browser runtimes direct access to AdLuxe credentials.

It supports the controlled lifecycle:

`inventory discovery → provider-code readback → site scan → surface classification → placement manifest → connector preflight → bounded installation → source readback → public readback → certification → maintenance → recovery`

PentaAds does **not** replace:

- AdLuxe Network as provider and inventory authority;
- the verified source/write authority of each target property;
- CHLOM authority, rights, policy and impact controls;
- CIE corridor and cultural-context controls;
- D3 approval for spend, campaign activation, payments, payouts or destructive mutation;
- consent, privacy, brand-safety or independent readback requirements.

## Deterministic survival

The package includes `PENTA_SURVIVAL_CONTRACT` v1. It preserves identity, state, deterministic functions, queues, leases, recovery, evidence, authority enforcement, health checks, replaceable-model behavior and restart semantics.

## Continuing controls

1. Do not mark Locticians installed until a BD global template, custom-code or widget-placement write chain is independently certified.
2. Capture a source preimage and rollback payload before every live write.
3. Require source and public readback after installation.
4. Keep VAST player-owned; the adapter emits a player handoff and does not silently replace a player.
5. Reconcile exact provider IDs and code before deployment.
6. Append new certification and recovery records; never overwrite or delete prior evidence.
7. Re-run repository, ThriveBase, Drive/Sheets and PentaDocs convergence for each material release.
