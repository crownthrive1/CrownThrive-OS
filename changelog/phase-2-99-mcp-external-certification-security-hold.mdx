## Current state

`CT-MCP-EXTCERT-001` is on `SECURITY_HOLD`. Earlier payloads and attestations are historical evidence only and cannot authorize capture, deployment, provider access, conformance execution, schema migration, certification PASS or Phase 3 advancement after material security remediation.

## Public/private projection

The public repository retains only the certification identifier, protocol/version target, aggregate resource limits, acceptance-predicate identifiers, safe interfaces, lifecycle state and evidence digests. Production identities, authorization architecture, provider-operation topology, runtime locators, derived schemas/migrations, credentials, private evidence and protected implementation belong in governed private custody.

## Controls added

- workflow dispatch and OIDC minting are absent from the public hold workflow;
- provider reads and writes are disabled;
- the conformance proxy enforces request/response byte ceilings;
- upstream requests have explicit timeout and downstream cancellation propagation;
- capture, schema inference, migration generation and live execution fail closed;
- public CI records hashes and negative-test outcomes, never derived evidence bodies.

## Reopen criteria

At the time of this historical hold, a replacement packet required private-custody restoration, exact-artifact IP/rights classification, Security/Privacy and Operations/SRE review, negative resource/cancellation tests, a new exact payload digest, a fresh named founder attestation for that digest, and the then-current A/B/C/D/S review model including Agent D with no block. That scheduler-specific model is now archived and has no current clock, dispatch, vote, or quorum effect. Phase 3 remained separately blocked by the Phase 2.99 hard exit and documentation/readiness gates.

## Current-main reconciliation

The packet preserves prior correction artifacts as historical evidence only. Public runtime remains a non-deployable security hold; provider execution, certification, commerce authority and Phase 3 entry are not created by build evidence.
