# Phase 2.99 — Design Control Plane & Agent Routing

**Date:** 2026-08-20<br />**Program namespace:** `institutional_build_phase`<br />**Current subphase:** `2.99`<br />**Disposition:** `implemented_governance_and_registry / executable_design_foundations_gated`

## Decision implemented

CrownThrive now treats Figma as the governed visual/product-design control plane and Canva as the downstream creative-production layer. The controlling architecture is documented in [Design Control Plane and Creative Production Governance](/technology/design-control-plane-and-creative-production).

This checkpoint does not promote unverified design tokens, Code Connect mappings or unattended provider dispatch into production state.

## Machine-control changes

The existing THIVEBASE/Supabase `integration_control` plane now contains governed connector-service records for:

- Figma design control;
- Canva creative production;
- Mintlify documentation control;
- Google Drive artifact mirroring;
- GitHub repository control.

Managed OAuth credentials are classified `provider_managed_only`; no OAuth token value was copied into Vault. Future CrownThrive-controlled PATs, client secrets, refresh credentials or service-account material require Vault-backed references, least-privilege scope, rotation and runtime-consumer registration.

Bounded MCP tool contracts are registered for Figma design inspection/editing/Code Connect, Canva brand/design operations, Mintlify docs operations, Google Drive artifact operations and GitHub repository operations. They remain **dispatch-disabled** in the central CrownThrive MCP/API registry until a real unattended adapter is certified. Registration is not execution proof.

## Agent-control changes

The agent factory is extended conceptually and institutionally with four task-scoped specialist roles:

- Design System Architect;
- Design-to-Code / Code Connect;
- Brand Content Production;
- Design Quality & Accessibility Auditor.

They inherit the existing autonomy, approval, evidence, budget, collision, DAIL, recovery and separation-of-duties rules. Tool availability cannot expand their authority.

## Figma Phase 0 state

Phase 0 discovery completed with these results:

- authenticated Figma workspace verified;
- canonical CrownThrive global design-system file created;
- current connector limits classified and budgeted;
- Canva CrownThrive-family brand-kit presence verified as supporting evidence;
- no reusable CrownThrive component/token library result was found through the inspected library path;
- exact authoritative CrownThrive color/font/token payload has not yet been extracted through a source capable of proving those values;
- Code Connect remains gated until exact production repository paths/exports are verified.

Therefore Figma Phase 1 foundations are **NEED\_TO\_DO / hard-gated**, not PASS. Agents are prohibited from filling the file with guessed brand values merely to make the design system look complete.

## Downstream inheritance

- **Phase 3:** executable design-token/component schemas, accessibility/evaluation fixtures and verified design↔code mappings become part of the institutional core.
- **Phase 4:** certified components/patterns federate across platform cohorts while preserving brand/corridor differences.
- **Phase 5:** production throughput, design drift, accessibility defects and reusable-component/content economics become measurable operational evidence.
- **Phase 6:** mature templates, UI kits, SDK patterns and MM Suites patterns may become governed licensable/developer assets only with current rights and support evidence.
- **Phase 7:** certified patterns extend into kiosks, tap stations and other phygital/location interfaces.
- **Phase 8:** portfolio-wide custody, portability, asset valuation and provider-exit controls apply to design-system IP.
- **Phase 9:** machine-readable provenance/interoperability is introduced only where justified by validated need.
- **Phase 10:** design-system exports, source mappings, component lineage, agent definitions and restoration procedures become continuity artifacts.

## Hard gates preserved

1. No invented design token may become canonical.
2. No Code Connect mapping may be created from a guessed source path.
3. Managed OAuth connector state does not imply a CrownThrive-owned secret exists in Vault.
4. MCP registry presence does not imply central dispatcher execution.
5. Canva cannot supersede the Figma design contract or CHLOM/CIE authority.
6. Figma/Canva/GitHub/Mintlify/Drive mutations remain subject to the applicable autonomy/approval class and provider-specific commit semantics.
7. Phase 3 remains blocked until the independent Phase 2.99 hard-exit ledger passes; this checkpoint alone does not advance the top-level program phase.
