# Phase 2.99 — Authoritative Expert Source Fabric

**Date:** 2026-08-20

## Purpose

Add a reusable, source-authority-aware routing fabric so CrownThrive projects, agents and MCP surfaces can select government APIs, standards bodies, official provider sources and bounded open registries according to the task and subject at hand.

- public-safe operating contract for authoritative expert-source routing;

- fail-closed validator with adversarial routing tests;
- dedicated read-only GitHub Actions validation workflow;

- evidence-envelope requirements;
- explicit SoundCloud API founder-override deny rule;
- macro homepage projection;
- agentic operating-model and developer-platform integration.

## Evidence boundary

The source list is based on official provider/government/standards documentation and established open research registries. A source's inclusion means it is an approved routing candidate within its claim scope. It does **not** prove CrownThrive account entitlement, live credentials, adapter deployment, data completeness or production health.
