### Database subagent runtime

A deterministic database subagent runtime now executes the bounded interoperability observation and validation work for all six interoperability agents. The runtime:

- runs contract-drift and route-observation scans;
- validates the root plugin package;
- records six evidence-bound agent-run receipts;
- updates agent health using the explicit `scheduled_database_subagent_runtime` class;
- appends a DAIL event;
- performs no provider write, commerce activation, D3 decision, secret exposure, or sovereign vote.

The runtime is registered through PostgreSQL cron at minute `:47` each hour and consumes no ChatGPT external scheduler slot. The function and registration have been exercised in a controlled bootstrap cycle. The first receipt generated by the cron job itself remains a separate verification gate.

### Request-budget drift protection

The founder-directed request-budget semantics are now protected by a versioned policy table, a final database trigger, a five-minute reconciliation function, and a recurring cron guard:

- `-1` — no CrownThrive local monthly ceiling;
- `0` — disabled;
- positive integer — CrownThrive local monthly ceiling;
- `NULL` — unresolved/fail closed.

Provider throttles, quotas, billing, included capacity, contracts, and abuse controls remain authoritative. Locticians retains its explicit 20,000 local ceiling and provider-wide throttle. Adserver/AdLuxe remains locally unlimited while retaining the 3-million included-plan threshold, billable-overage monitoring, and no automatic hard stop.
