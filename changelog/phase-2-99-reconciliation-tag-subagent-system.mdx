## Core rule

A tag is routing metadata, not institutional authority. `CT:PASS` remains drift-watched and source-scanned. `CT:DEFERRAL` always includes `CT:NOT-PASS`; an approved deferral never becomes PASS by naming convention.

## Self-controls

Agents L/M/N/O are non-voting and inherit self-state awareness, self-audit, deterministic self-healing, self-reconciliation, least-privilege self-limiting, escalation, documentation and recovery controls. These are operational engineering controls, not a claim of independent consciousness or sovereign authority.

## Draft reconciliation

The initial draft index identifies current-main drafts, stale-base CHLOM stacks, dependency-pending branches and the superseded RLS evidence PR. Agent O is responsible for refreshing exact heads/bases and opening reconciliation handoffs whenever current GitHub state changes.

## Security

No new provider credential, customer data, restricted evidence, payment authority, rights authority or production mutation is introduced. Cross-source runtime agents may use only sources actually permissioned and available to that run, and source content cannot alter agent authority.
