# Governance Observability and Archive Continuity Institutionalized

CrownThrive now separates infrastructure and evidence-acquisition failures from institutional policy dispositions. The governed merge path hydrates exact pull-request source identity before trusted-diff evaluation, and a deterministic classifier prevents generic CI failures from being represented as CHLOM `HOLD` or `DENY` without authoritative policy output.

A machine-owned pull-request readback surface records current GitHub base/head identity and tracked governance workflow state without rewriting human-authored PR bodies or creating institutional acceptance.

The private THRIVEBASE archive control plane has also moved from a monolithic whole-corpus encryption transaction to a resumable encrypted-chunk architecture. The active controlled-test v21 profile freezes source membership, encrypts bounded chunks, persists ciphertext checkpoints, and seals only after exact count/hash reconciliation. It reuses the existing CSS hourly subroute and creates no new top-level scheduler slot.

The v20 sizing canary remains preserved as superseded evidence. The failed v19 monolithic retry model is retired from automatic execution. No direct-main merge, D3 automation, sovereign vote, provider write, money movement, Rights grant, pricing, checkout, credential disclosure, legal/professional certification, or phase advancement is authorized by this tranche.
