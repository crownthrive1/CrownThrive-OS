## Security closeout

Temporary deployment and origin-probe scripts deleted themselves and were independently checked for removal. One-time release, Passenger-registration, and synchronous DNS functions were retired after provider readback. The maintained rollback path uses the governed asynchronous DNS operation queue rather than a persistent one-shot write endpoint.
