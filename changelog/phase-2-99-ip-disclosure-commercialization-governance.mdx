# Phase 2.99 — IP Disclosure & Commercialization Governance

## Purpose

This patch converts CrownThrive's protected-knowledge and monetization strategy into governed, machine-readable institutional controls. It does not claim a patent filing, trademark registration, certification mark, product price, Stripe checkout, customer launch or Phase 3 transition.

## Permanent IP rule

Before CrownThrive materially publishes, distributes, licenses, open-sources or externally discloses detailed technical, agentic, CHLOM, policy, software, research, security, economic or operating material, the exact artifact must receive a disclosure classification.

The permanent projection model separates:

- public specification / public doctrine;
- copyright/licensed implementation;
- restricted institutional implementation;
- trade-secret kernel;
- patent candidates;
- trademark/certification-mark candidates;
- third-party licensed material and unresolved rights review.

Unknown classification fails closed. Publishing first is not an accepted way to discover whether an artifact should have been protected.

## What Phase 2.99 may do

Phase 2.99 may inventory, classify, design, package, document and validate commercial candidates. It may produce sanitized reference materials, agent/template packs, capability-pallet definitions, SDK contracts, implementation-service scopes, training curricula, support definitions and conformance-test designs.

Phase 2.99 does not gain authority to invent prices, accept external license terms, create live Stripe checkout, transfer ownership of core CrownThrive IP or disclose protected technical mechanisms merely because the assets are commercially promising.

## Agent impact

The permanent gate is routed into the agent operating model:

- A routes classification and commercialization dependencies;
- B audits chain of title and classification evidence;
- C builds the approved public/licensed/restricted projection only;
- D blocks incomplete publication/license/live-sale gates;
- S blocks credential/security/restricted implementation leakage;
- F classifies material public documentation before articleization/publication;
- N verifies the classification evidence;
- R&D defaults high-value mechanisms to research plus IP review before public promotion.
