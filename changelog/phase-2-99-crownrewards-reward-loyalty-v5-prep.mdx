# Phase 2.99 — CrownRewards Reward Loyalty v5 Preparation

## Trigger

Founder clarification established that:

- Partnero remains the Crown Affiliates/Ambassadors provider relationship;
- Adserver.Online remains the AdLuxe Network ad-serving provider relationship;
- Reward Loyalty / NowSquare remains the engine beneath CrownRewards / My CrownRewards;
- the CrownRewards provider and API migration must be prepared without collapsing those systems into one platform.

## Current evidence

NowSquare Support confirmed on 2026-08-19 that the existing v4 installation may keep running as-is while the supported updates/support path now runs through v5. The public My CrownRewards site remains reachable.

Reward Loyalty current v5 documentation establishes separate session-token REST and machine-to-machine Agent APIs. The Agent API uses scoped `X-Agent-Key` credentials, generates OpenAPI 3.0 documentation and can emit tool definitions in OpenAI, Anthropic, MCP and generic formats.

## Changes in this packet

- added machine manifest `crownrewards-reward-loyalty-v5-readiness.v1.json`;
- added substantive Mintlify readiness article;
- added Reward Loyalty / NowSquare to the Partner/Vendor/Referral Registry as `S100-ENG-024` / `ct.platform.crownrewards`;
- locked provider-separation invariants for Partnero, Adserver.Online and Reward Loyalty;
- seeded THIVEBASE/Supabase current v4 versus target v5 state;
- seeded v5 REST API, Agent API, OpenAPI, Swagger, health and MCP-format tool-discovery targets;
- kept all Reward Loyalty API/MCP write tools disabled pending v5 upgrade and certification;
- updated the existing Engine & THIVEBASE monitoring schedule to track My CrownRewards health, v4→v5 migration, vendor changelog/API/security changes and upgrade readiness.

## Phase boundary

This packet does not perform the v5 production upgrade, purchase a v5 license, create an Agent API key, enable Reward Loyalty writes, migrate customer/member data, or claim v5 is deployed.

Phase 2 / 2.99 remains current. Phase 3 remains blocked pending the complete Phase 2.99 hard exit.
