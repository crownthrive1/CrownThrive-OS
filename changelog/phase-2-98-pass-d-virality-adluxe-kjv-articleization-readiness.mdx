## Evidence and state corrections

### Current versus historical

Current public Virality routes, featured doors, counts and starting-price evidence are dated snapshots. An older Virality market/monetization assessment remains research evidence and does not override the later public rate model.

### Provider capability versus deployment

Official provider documentation may establish that an API or report family exists. It does not certify CrownThrive's account plan, credentials, base URL, scopes, retention, limits, current campaign data or production health.

### Public output versus editable source

A live, crawlable site is not automatically an editable source repository. A saved deployment artifact is not automatically a safe source-code backup. Repository state remains separately documented.
