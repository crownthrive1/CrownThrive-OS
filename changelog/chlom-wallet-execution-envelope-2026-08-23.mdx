## Handoff boundary

The Wallet Agent does not create independent evidence. The router can validate an existing receipt, identify missing/stale/held/denied evidence, and bind it to an exact source head. It cannot create a reviewer DID, heartbeat, receipt, vote, certification, or capability grant.
