## Audit corrections preserved in this release

### Custom-domain maturity correction

An earlier audit penalized the project because Mintlify was not connected to a CrownThrive subdomain. That was the wrong maturity assumption. The project is explicitly being built in phases and is not yet the final public Help Center or private institutional portal. Domain activation is now classified as a later release gate, not a Phase 2.97 defect.

### External-standard correction

A preliminary standards note identified SLSA 1.1 as current. Primary-source re-verification established that SLSA 1.2 is the current Approved specification and 1.1 is retired. The original preliminary statement remains in the audit history and is superseded by the corrected dependency record.

### MCP baseline correction

The prior 2.97 baseline referenced MCP `2025-11-25`. The final current target is `2026-07-28`, including a stateless protocol core, self-describing requests, header-based routing, optional discovery, cache-aware lists, Multi Round-Trip Requests, extensions and updated authorization/deprecation behavior.

## Repository and projection hardening

The accepted release made the source repository and Mintlify projection CrownThrive-owned by establishing:

- CrownThrive support and ecosystem links instead of Mintlify template links;
- the CrownThrive repository link instead of the Mintlify example repository;
- working-projection language instead of implying the final Help Center is already launched;
- CrownThrive README and agent instructions;
- CrownThrive-owned logo/favicon assets;
- an explicit repository/IP notice separating CrownThrive institutional content from third-party template or dependency licenses;
- automated checks for missing navigation files, frontmatter-only pages, template residue and visibility/secret defects.
