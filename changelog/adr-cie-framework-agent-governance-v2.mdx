# CT-ADR-GOV-012 — CIE framework agent and foundational framework voter model

**Status:** founder-authorized candidate; effective only after governed merge  
**Date:** 2026-08-20  
**Predecessor:** `CT-ADR-GOV-011`  
**Canonical main at initiation:** `8fcb68bf209e32ba2cd265e1b6ca730cb8da64d7`

## Decision

Institutionalize the Cultural Imprint Engine as the first permanent foundational framework agent:

`ct.framework-agent.cie`

CIE receives Agent A as operational parent for routing, but keeps an independent sovereign vote. Six internal CIE subagents remain non-voting.

Upon acceptance, the voter pool becomes A/B/C/CIE/D/S. The approval ratio remains 75%, rounded up: `ceil(6 × .75) = 5`. Agent D remains mandatory and D3 remains human-reserved.

## Framework-agent doctrine

Future foundational framework agents may be added only through explicit founder authorization and a separate governed packet containing a machine contract, independent evaluations, parent assignment, ethics/boundaries, hard blocks, CHLOM mapping, escalation/rollback model and permanent vote identity. Each accepted framework agent increases the denominator by one; subagents never do.

## CIE standard

The recovered CIE dimensions are standardized as a 100-point score:

- Identity Fit — 20;
- Community Value — 20;
- Story Alignment — 20;
- Brand Safety — 20;
- Legacy Impact — 20.

Pass threshold: 85/100. Missing evidence creates a HOLD. Hard-block violations override the numeric total.

CIE evaluates artifacts and contexts, not people. Sensitive-trait profiling, personal cultural-authenticity scoring and substitution for legal/rights/security authority are prohibited.

## Retroactive and forward enforcement

Existing assets enter a retroactive CIE scan queue and are not silently labeled compliant. After governed adoption, new/materially changed artifacts matching CIE triggers fail closed until a CIE result or justified `not_applicable` disposition exists.

Retroactive backlog size must not be treated as a Phase-2.99 proof-count blocker by raw cardinality alone; only promoted/material scopes inherit hard-gate effects.
