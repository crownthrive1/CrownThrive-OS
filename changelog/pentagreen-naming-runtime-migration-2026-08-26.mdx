# PentaGreen Naming & Runtime Migration — August 26, 2026

## Decision

CrownThrive canonically renamed **ThriveEvergreen™** to **PentaGreen™** and established **PentaCredits™** as its credits/economic-value subsystem. Other current economic-execution primitives were normalized into the Penta naming family.

> **PentaGreen may optimize within authority. It may never manufacture authority.**

The decision contract remains `ECAC | HOLD | DENY`.

## Canonical subsystem cohort

PentaGreen now includes PentaCredits, PentaSKU, PentaLedger, PentaReconcile, PentaHold, PentaSettle, PentaEntitle, PentaInvoice, PentaPayout, PentaPrice, PentaCatalog, PentaCheckout, PentaReceipt, PentaCompensate, PentaPolicy, PentaBridge, and PentaMarket.

## Runtime implementation

The live ThriveBase/Supabase control plane received an additive migration rather than a destructive table rename. Canonical `pentagreen_*` compatibility views and wrapper functions were placed over existing verified `thriveevergreen_*` runtime objects, while PentaCredits compatibility surfaces were placed over existing governed credit primitives.

PentaGreen and its child components were registered in the PENTA runtime component registry. `ct.penta.agent.green` was registered as a bounded A2/D2, non-voting, non-self-approving agent for economic gate assessment, alias resolution, reconciliation supervision, and status evaluation.

## Provenance rule

Historical changelogs, signed/hash-bound evidence, immutable receipts, prior releases, exact event identifiers, database migration history, and provider bindings may retain `ThriveEvergreen` where changing the identifier would damage provenance. New current-state records should use PentaGreen and identify ThriveEvergreen only as a legacy alias when backward context is required.

## Governance unchanged

The rename does not grant new provider-write, money-movement, licensing, settlement, D3, or sovereign authority. Provider success remains execution evidence rather than institutional economic truth. Required reconciliation, SAFE\_HOLD, rollback/compensation, CHLOM authority, evidence, finance/legal/security controls, and human/quorum gates remain intact.

## Documentation

The prior ThriveEvergreen current page is retained as a hidden/deprecated compatibility record with a successor notice.
