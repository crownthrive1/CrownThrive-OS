## Architecture fixed for activation

```text
Private GitHub source
  ↓
ThriveBase institutional ingest
  ↓
Vercel stateless edge and relay
  ↓
Dedicated Verpex/cPanel Laravel runtime
  ↓
cPanel MySQL transactional state
  ↓
GitHub Actions ephemeral Android builder
  ↓
Penta canary, digest, receipt, and rollback
  ↓
ThriveApps published-only catalog
```
