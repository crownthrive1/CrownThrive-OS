## Security and IP

- no secret or credential value is introduced;
- no service-role key is required by child GitHub workflows;
- federation authentication uses GitHub Actions OIDC;
- child workflows cannot certify children or call `sync_agents`;
- no child/workflow/repository creates a sovereign vote;
- public-safe templates contain interface/control logic only;
- protected calibration/private eval corpora/restricted evidence remain outside public outputs;
- repository license remains the existing CrownThrive All Rights Reserved institutional knowledge/configuration notice;
- no general external implementation license is granted by publication.

## GitHub self-sustain behavior

The child governance template may autonomously maintain **visibility of failure**, not authority:

- hourly validation;
- bounded federation state/heartbeat checks;
- deterministic drift issue create/comment;
- deterministic recovery close;
- daily Dependabot GitHub Actions proposals.

It cannot auto-merge, direct-write repairs to `main`, change quorum, create votes or enable provider/customer writes.
