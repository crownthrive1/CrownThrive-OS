## Repository posture

The CHLOM protocol repository is being left intact for now.

The CrownThrive Support / Mintlify knowledge base is being expanded into the comprehensive institutional documentation layer. This avoids destructive repository migration while giving Phase 3 a single operational knowledge surface.

## What Phase 2.5 does not claim

Phase 2.5 does not claim that:

- a CHLOM mainnet is live
- CHLOM tokens are deployed
- LEX is a production decentralized exchange
- DAO governance is active
- all recovered Help Center articles have verbatim surviving bodies
- every portfolio asset is active or monetized
- the proposed holding-company structure is legally completed

## Phase 3 gate

1. event / audit layer (DAIL)

4. DLA service
5. rules/policy registry
6. roles and authority service
7. revenue allocation registry
8. remedies / case service

Phase 3 should build executable services from the institutional model rather than inventing a second architecture.
