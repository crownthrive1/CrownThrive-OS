### Partnero control plane and webhook receiver

`partnero-api-control` was upgraded to **v2**. The v2 read-only runtime now:

- preserves JWT + founder/admin authorization;
- streams inbound control requests with a **32 KiB** pre-parse ceiling;
- enforces provider response `Content-Length` when available and also streams responses with a hard **512 KiB** ceiling before decode/parse;
- retains the bounded provider timeout, JSON enforcement, response hashing/redaction and provider-write prohibition.

`partnero-webhook-receiver` was upgraded to **v2**. It now requires JSON and streams the raw webhook body with a hard **64 KiB** limit before HMAC-SHA256 verification and parsing. It still fails closed with HTTP 503 until the Partnero webhook signing secret is safely bound in Vault.
