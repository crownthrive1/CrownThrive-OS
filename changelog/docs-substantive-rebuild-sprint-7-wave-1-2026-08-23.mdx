# Docs Sprint 7 — P0 Substantive Rebuild Wave 1

Sprint 7 changes the documentation program from **candidate-map completion** to **substantive-current successor qualification**.

## Pass A

The deterministic builder recomposes the completed 795-row candidate map from Sprints 3–6, isolates the **449 P0 candidates**, and applies a deliberately restrictive machine lane.

A row qualifies only when it is a P0 `merged_successor` candidate with no missing continuity route, no D3/high-risk condition, and at least one approved canonical anchor whose current MDX body is substantive and already internally connected.

Result:

```yaml

wave_1_selected: 16
p0_outside_wave_1: 433
selected_sections:
  CrownThrive Legal Depot: 10
  Convergent Ecosystem: 5
  Hybrid Incubator: 1
wave_sha256: 518a37a3ac0485987c281761012b9411d3f1fbae155bac73ef7a3929fbda15f6
```

## Pass B

The sixteen selected recovered identities bind to four substantive current control articles:

- [Security & Privacy Continuity](/technology/security-privacy-continuity) — 9 rows;
- [Phase 3 Readiness Gate](/technology/phase-3-readiness-gate) — 4 rows;
- [Ecosystem Status & Resilience](/technology/ecosystem-status-resilience) — 2 rows;
- [Documentation Source of Truth & Autonomous Governance](/standards/documentation-source-of-truth-and-autonomous-governance) — 1 row.

The qualification state is `substantive_current_successor_machine_verified_parent_review`. No legacy historical body is represented as recovered, and no terminal disposition is self-authorized.

## Held lanes

Wave 1 intentionally excludes investment/securities, valuation/prospectus, patent/provisional-patent, franchise/regional-license, confidential/internal, token/exchange/settlement and other explicitly high-risk material. Those records remain governed specialist or parent-review work rather than being pushed through a weaker automated rule.
