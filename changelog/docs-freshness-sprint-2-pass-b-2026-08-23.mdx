## Why the 795-title rebuild is not 795 new pages

The recovered legacy Help Center contains 795 title/hierarchy records. The current documentation estate contains new institutional registries, technical records, standards, runbooks and changelogs that did not exist in the old system.

A legacy title may therefore become a canonical article, merge into a stronger successor, permanently redirect, move to restricted knowledge, remain historical, or stay unresolved. **Subtracting the current Mintlify page count from 795 is not a valid missing-article metric.**

See [Documentation Rebuild Coverage Census](/knowledge/documentation-rebuild-coverage-census) and [795-Article Disposition Seed](/support/help-center-795-article-disposition-seed).
