## Credential security blocker

The founder supplied current API keys for all three services. A direct Supabase Vault write was attempted through the connected database tool and was rejected by the secure-write policy before persistence. No raw value is stored or exposed by this packet.

Intended secret references:

```text
vault:thrivepush_api_key
vault:crownlytics_api_key
vault:crownpulse_admin_api_key
```

Each also has a planned `_recovery` alias. The credential-continuity registry is `blocked_missing_secret` until an approved secret-write path succeeds. Encoding or committing a secret to bypass the control is prohibited.
