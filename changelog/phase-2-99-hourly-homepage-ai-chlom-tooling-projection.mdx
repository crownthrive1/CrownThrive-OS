# Phase 2.99 — Hourly Homepage, AI/CHLOM and Tooling Projection

## Exact-main lineage hardening — August 21, 2026

The scheduled projection workflow now binds each mutation attempt to the exact triggering `main` SHA, rejects a pre-existing automation branch unless its complete lineage delta is only `index.mdx` and its commits have the registered bot author, proves the complete candidate PR diff is only `index.mdx`, and refuses non-fast-forward updates.

Before mutation, it also requires GitHub's current `main` branch readback to report `protected=true`; that boolean does not replace independent required-check/ruleset evidence. After a push, it reads back the remote branch and draft PR head/file list and records actor, lineage, candidate/rollback SHA and homepage digests. The rollback exercise is non-destructive retrieval of the canonical pre-change homepage. These controls respond to exact-head Agent A review and do not constitute acceptance, Mintlify deployment proof or permission to merge.

## Outcome

This packet replaces ad hoc homepage freshness with a bounded, deterministic projection contract. A machine-readable manifest declares public-safe inputs, a renderer owns one marker-bounded homepage region, pull-request checks reject stale output, and an hourly scheduled workflow opens or updates a dedicated draft pull request only when canonical inputs produce a semantic change.

The workflow never writes directly to `main`, force-pushes, self-merges, mints OIDC tokens, activates commerce or treats CI as public deployment acceptance. An unchanged run emits a workflow heartbeat without a timestamp-only commit.
