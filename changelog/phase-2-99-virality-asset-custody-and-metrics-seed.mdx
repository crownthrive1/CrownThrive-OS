## SoundCloud boundary correction

Earlier wording could be misread as though the SoundCloud credential blocker prevented public listening. That is now explicitly corrected.

- **Public playback:** supported SoundCloud oEmbed / standard iframe is permitted for public Virality playback; official HTML5 Widget API is used when custom playback controls/events are required; autoplay remains off by default.
- **Authenticated measurement:** Artist Studio/API/signed-export evidence remains separately blocked until a least-privilege read credential/export path is certified.
- **Provider writes:** remain prohibited.

A working public embed is not authenticated metric evidence. A missing analytics credential is not a public-embed outage.

## Public-surface quality control

Virality public releases now carry a separate public-surface review profile. Material layout/media/navigation changes should be evaluated for responsive behavior, visual hierarchy, CTA clarity, persistent-player collisions, keyboard/focus behavior, artwork crops, touch targets, reduced motion, contrast, third-party loading, layout stability and Virality's premium/cinematic/editorial presentation.

Where the executing runtime cannot actually inspect a required visual state, that state remains `unknown` rather than being promoted from HTTP health or source markup.

## Scheduled execution state

The daily lane uses an at-most-once-per-America/New_York-day guard inside existing hourly agents. Agent G gathers and classifies provider evidence, Agent E performs idempotent private-registry reconciliation, Agent F protects public wording/evidence context, Agent C publishes only material method/schema/gate changes and enforces Drive custody, Agent S reviews third-party media/security/privacy, Agent D controls exact-head quorum/checks, and the Integration Heartbeat detects missing or contradictory handoffs.

Authenticated provider reads remain blocked pending credential certification. Public embed/playback health is evaluated separately. All provider and Sites writes remain prohibited until their respective adapter/authority gates pass.
