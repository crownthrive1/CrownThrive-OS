# Phase 2.99 — Agent Factory and Specialist Expansion

## Patch status

```yaml
patch_id: CT-P299-AGENT-FACTORY-001
phase: 2.99
classification: D2-governed automation architecture
sovereign_voter_pool_changed: false
scheduled_specialists_added: [E, F, G, H]

production_provider_writes_enabled: false
```

This is a **major institutional automation patch** because it formalizes a reusable agent factory and expands specialist execution coverage across the remaining Phase 2.99 hard-exit gates. It does not open Phase 3 and does not change the five-agent sovereign voter pool.

## Before and after

### Prior effective execution model

The accepted relay centered on A/B/C/D/S as voters, Agent E as a non-voting API/MCP specialist and three THIVEBASE helper subagents.

### Current patch model

- A/B/C/D/S remain the only sovereign voters.
- Agent E remains the API/MCP specialist.
- Agent F is added for source/articleization and GATE-002 execution support.
- Agent G is added for domain/engine/vendor certification and GATE-001 execution support.
- Agent H is added for webhook/provider-delivery certification and GATE-006 execution support.
- Agent I is preserved as embedded `ct.subagent.continuity-recovery` for GATE-007/continuity.
- Agent J is preserved as embedded `ct.subagent.phase3-snapshot-packet` for GATE-008 preparation.
- Agent K is preserved as embedded `ct.subagent.roadmap-transition` for downstream Phase 3–10 reconciliation.

The platform scheduler's active-task ceiling therefore does not erase institutional roles or force a quorum change; capacity-constrained roles remain source-controlled embedded subagents.

## Source/template package

The patch adds or formalizes:

- `developers/manifests/institutional-agent-topology.v1.json`;
- `developers/templates/agent-definition.template.yaml`;
- `developers/templates/subagent-definition.template.yaml`;
- `scripts/scaffold_crownthrive_agent.py`;
- `scripts/validate_agent_topology.py`;
- expanded `developers/manifests/thivebase-operational-automation.v1.json`;
- CI execution of the topology validator in Documentation Governance and Governed Merge Gate.

No third-party source code is incorporated by this patch. The scaffold and validators use CrownThrive-authored standard-library code, while the documentation establishes an attribution/license-intake contract for any future dependency.

## Rights and commercialization

CrownThrive may license its own agent-definition/governance/evaluation/orchestration templates and CHLOM capability mappings. Third-party/open-source components remain governed by their own licenses and cannot be redistributed merely because they are used by CrownThrive.

Commercialization is separated into product, license and entitlement states. Stripe product/price objects may be prepared, but public checkout must remain gated until the package, CrownThrive license text, notices/attribution inventory, fulfillment and support/update policy are all accepted.

## Phase effects

- **Phase 2.99:** increases execution capacity for GATE-001/002/006/007/008 while preserving all current blockers.
- **Phase 3:** receives a more reproducible agent/service seed contract only after the hard exit passes.
- **Phase 4:** can activate federated specialist queues from versioned templates rather than ad hoc prompts.
- **Phase 5:** can commercialize approved template/service packages only after commerce/license/fulfillment evidence exists.
- **Phase 6:** can expand the developer/licensing economy around agent templates and CHLOM pallets under current IP/developer terms.
- **Phases 7–10:** inherit the same archive, provider-independence, recovery and succession model.

## Rollback

Rollback means reverting the current agent-topology/source-template patch while retaining this changelog and prior source versions. It does not delete historical agent definitions, schedules or evidence.

The canonical operational status remains in the [Phase 2.99 Roadmap & Watch Control Center](/changelog/phase-2-99-roadmap-and-operational-watch-control-center); this page is the detailed major-patch record.
