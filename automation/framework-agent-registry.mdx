# Foundational framework-agent registry

Framework agents convert CrownThrive doctrine into persistent operational controls. They differ from ordinary specialists: an accepted foundational framework agent has a permanent sovereign vote, an independent machine contract, subordinate non-voting specialists, a CHLOM mapping, evaluation requirements and ecosystem-wide triggers.

## Registry rules

Every foundational framework agent must have:

```yaml
framework_id:
framework_agent_id:
canonical_doctrine:
founder_authorization:
operational_parent:
parent_vote_control: false
permanent: true
vote_eligible: true
subagents_vote_eligible: false
score_or_decision_contract:
hard_blocks: []
ethics_and_boundaries: []
human_escalation_triggers: []
chlom_pallet:
evaluation_suite:
repository_custody:
retroactive_scan_contract:
commercialization_state:
```

A framework agent cannot create itself, create another sovereign voter, change the approval ratio, remove Agent D, or weaken D3 human authority. Each addition requires explicit founder authorization and governed acceptance.

## CIE — Cultural Imprint Engine

```yaml
framework_id: ct.framework.cultural-imprint-engine
framework_agent_id: ct.framework-agent.cie
operational_parent: ct.relay.agent-a
parent_vote_control: false
permanent: true
vote_eligible: true
score: CIE-100
pass_threshold: 85
chlom_pallet: ct.chlom.pallet.cie-cultural-governance
implementation_state: controlled_test
repository_target: crownthrive1/CrownThrive-CIE
```

CIE evaluates cultural/narrative alignment across artifacts and contexts. It does not score people or sensitive personal traits. Its six internal subagents are non-voting.

## Quorum growth

After the CIE packet is accepted:

```text
N = 6 eligible sovereign voters
required = ceil(N × 0.75) = 5
Agent D = mandatory
D3 = human-reserved
```

For every later accepted framework agent, increment `N` by one and recompute `ceil(N × 0.75)`. Subagents never change `N`.

## Candidate future framework agents

Future entries remain candidates until separately authorized. The recommended next institutionalization target after CIE is the **Convergent Ecosystem Framework**, because it is the CrownThrive Framework OS meta-layer that tests whether each asset connects to Identity, Offer, Audience, Revenue, Data, Governance and Reinforcement. It should not be added as a voter until its own founder-authorized packet is built and accepted.
