## Project Issue Routing Score

`ct.alg.gen7.pirs` is the Project Issue Routing Score. Its public contract evaluates bounded factors including:

- issue severity;
- hard-gate impact;
- dependency-unlock value;
- evidence readiness;
- age;
- collision safety.

Exact weights, bands, calibration and defensive rules remain in encrypted Vault custody. Public output may expose a score, band, reason class, version and digest. A score is an evidence-routing aid; it does not manufacture facts, authority, certification, rights or completion.

## Lifecycle

Project issues follow:

`assigned -> running -> verifying -> resolved | blocked | returned`

Rules:

- only the bound owner may accept and advance work;
- progress requires new evidence and positive work units;
- progress cannot jump directly to completion;
- only the bound independent verifier may resolve, return or block;
- owner and verifier must differ;
- issue events and handoffs are append-only;
- refreshes preserve `running`, `verifying`, `blocked`, `deferred` and terminal states;
- resolved history is retained;
- no issue state creates a sovereign vote or merge authority.
