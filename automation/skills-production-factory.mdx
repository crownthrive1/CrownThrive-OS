The CrownThrive Skills Production Factory extends the installed PentaFactory and PentaSELF runtime. It processes the 59-skill registry in idempotent hourly tranches, packages exact-subject evidence, appends master-ledger records, and hands each stable package to PentaGreen.

## Current contract

- Factory: `ct.factory.skills.v1`
- Registry: `CT-SKILLS-REGISTRY-001`
- PentaGreen handoff: `ct.pentagreen.skills.handoff.v1`
- Command center: `/command-center/factory/`
- Status API: `/api/factory/status`

Reversible preparation is fast-tracked. Rights, tax, money movement, entitlement, credentials, provider-write certification, and provider readback remain hard controls.

## Runtime continuity

Version 1.0.1 hydrates the durable state branch before each hourly tick and runs `ct.pentagreen.skills.processor.v1` after package generation. This preserves cursor continuity across ephemeral runners and prevents a repeated tranche from masquerading as new output.
