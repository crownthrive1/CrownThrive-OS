# CHLOM Wallet Agent — Phase C skill package

The canonical specialist remains `ct.agent.chlom-wallet-settlement`. Phase C expands its technical competency without changing its constitutional authority.

```yaml
vote_eligible: false
authority_ceiling: D2
autonomy_ceiling: A2
self_approval: false
production_activation: false
live_money_movement: false
public_chain_broadcast: false
```

## New bounded skills

### `ct.skill.chlom.harp-proof-capsule.v1`

Build and verify deterministic HARP proof capsules from sanitized commitments. The skill may create roots and inclusion proofs but may not publish evidence, sign a chain transaction or claim legal sufficiency.

### `ct.skill.chlom.easor-settlement-plan.v1`

Compile deterministic allocation and reversal previews. The skill may calculate obligations but may not execute settlement, determine taxes, grant rights or represent ThriveFund obligations as disbursed.

### `ct.skill.chlom.portable-wallet-capsule.v1`

Build and verify provider-neutral continuity capsules and HOLD-only remap plans. The skill may not export credentials, write to a provider, import customer state or move value.

## Commercialization boundary

The skills map to governed product families but do not authorize pricing, Stripe objects, checkout or fulfillment. Commercial activation requires a separately certified offer, rights package, support model, security posture, tax treatment and live delivery path.
