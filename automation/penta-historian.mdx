# PentaHistorian™

**Status:** ACTIVE — Phase 3 / PENTA v3  
**Canonical ID:** `ct.penta.historian`  
**Control API:** `penta-historian-control`  
**Primary collaborators:** PentaScribe, PentaDocs, PentaCertify, PentaArchive, PentaVersion, PentaSerialized

PentaHistorian roams registered CrownThrive sources of truth, detects changes and contradictions, preserves source-era context, and hands verified documentation deltas to PentaScribe. It does not rewrite history to fit the present and it never promotes an old source merely because it is detailed.

## Five-layer role

1. **Discover** — inventory and rescan registered GitHub, ThriveBase, PentaDocs, recovered Help Center and other governed sources.
2. **Govern** — rank source authority, distinguish history-only from current-truth-capable sources, detect contradictions, and preserve protected-source boundaries.
3. **Execute** — create bounded reconstruction/reconciliation jobs and PentaScribe handoffs.
4. **Verify** — require current provider/runtime readback before a current-state claim is promoted.
5. **Preserve** — retain source-era bodies, digests, supersession lineage, archive state, and successor links.

## Permanent rules

- No fabrication of missing historical bodies.
- No silent overwrite or deletion of historical evidence.
- A recovered source is evidence, not automatic current authority.
- Historical-only sources cannot independently create current runtime claims.
- Current truth requires current evidence/readback within the claim's exact scope.
- Protected/private source bodies stay outside public PentaDocs; public records may reference safe digests/IDs.
- Every substantive current-documentation delta routes through PentaScribe.

## 795 Help Center rebuild

The full 795-title recovered Help Center corpus is an active PentaHistorian reconstruction program. Every record is expected to reach a substantive body or an explicit evidence-backed terminal state while preserving original title/hierarchy/source lineage. Missing prose is reconstructed only as a clearly new current artifact from surviving evidence and current truth; it is never represented as the unrecovered historical original.

The machine job is `help-center-795-substantive-rebuild` and remains open until all 795 records have substantive or explicit terminal disposition coverage.

## Runtime data

Private machine state lives in:
- `integration_control.penta_historian_sources_v1`
- `integration_control.penta_historian_observations_v1`
- `integration_control.penta_historian_jobs_v1`

The control API supports status, bounded job queueing, and observation recording. It returns source metadata/evidence references, never restricted source bodies by default.
