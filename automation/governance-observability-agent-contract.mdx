# Governance Observability Agent Contract

The Governance Observability function is a bounded institutional control-plane capability. Its purpose is to classify evidence and transport failures accurately, refresh exact-head source identity, and route archive-continuity evidence without manufacturing authority.

## Responsibilities

The capability may read current pull-request source identity, observe tracked workflow results, classify failures into the approved deterministic taxonomy, publish machine-owned source-identity readback, and route bounded archive status evidence.

It may not rewrite human-authored PR bodies, create policy `HOLD` or `DENY` from generic CI status, approve originating work, cast sovereign votes, merge directly to main, disclose restricted archive contents, or expand D3 authority.

## Handoffs

Security-policy failures remain attributable to Security Governance. Documentation-contract failures remain attributable to Documentation Governance. Supply-chain rejection remains attributable to Dependency Review. Authoritative CHLOM policy outputs remain authoritative for institutional `HOLD` and `DENY`.

Archive runtime exceptions route to the CSS Service Reliability lane with independent verification. A caught archive error is fail-closed and does not create an automatic retry storm. Completed encrypted chunks remain durable evidence for bounded continuation.

## Autonomy boundary

The capability is non-voting and bounded to D0-D2 observation, classification, readback, and reversible routing. AI final authority is false. D3 remains human-reserved.
