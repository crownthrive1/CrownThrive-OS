<Warning>
This suite is a controlled-test capability layer. It creates no sovereign voter, officeholder, committee seat, quorum member, D3 authority, live price, checkout, entitlement, publication approval, or production deployment.
</Warning>

## Purpose

The suite adds 26 scoped subagents under the existing CHLOM orchestration spine. It extends the Framework Factory with utility capability packs; it does not create a ninth framework or change the canonical eight-framework sequence.

The governed domains are:

- pricing research and independent price-policy verification;
- ZIP, checksum, file, workflow, dependency, and supply-chain integrity;
- source-attributed institutional-knowledge extraction and retroactive internal-link candidates;
- deterministic framework architecture, compilation, tests, and parent-certification routing;
- version and security-threat upgrade proposals with rollback plans;
- independent agent identity, privilege, heartbeat, source, output, and self-review audits;
- marketing intelligence and sales-enablement drafts; and
- nonvoting support for public ThriveAlumni governance surfaces.

## Operating modes

| Mode | Behavior | Boundary |
|---|---|---|
| Rigid | Deterministic verification, evidence capture, rule checks | Cannot originate and approve the same consequential output |
| Fluid | Research, synthesis, options, scenario development | Cannot publish, contact, price, bind, or activate |
| Hybrid | Bounded planning or patch generation plus deterministic gates | Writes remain candidates until a separate receipt exists |

## Hard controls

- No silent deletion. Governed records are superseded additively.
- No self-approval, machine vote, synthesized quorum, officeholder impersonation, appointment, removal, sanction, signature, spend, merger, deployment, or credential export.
- D3 remains human-reserved.
- Special privileges are denied by default, identity-bound, non-inheritable, time-limited, independently reviewed, and fail closed on expiry or heartbeat failure.
- Pricing, security, governance, rights, status, and public claims remain controlled content.
- MCP and commercial packages remain disabled/HOLD until independent verification and human release evidence exist.

## Framework Foundry flow

1. The Knowledge Extractor collects attributable claims from approved GitHub, Mintlify, Drive, recovery, and public sources.
2. Conflicts remain explicit; recovered titles never become invented original bodies.
3. The Framework Architect produces a candidate specification, invariants, evidence gates, version, rollback, and downstream-impact map.
4. The deterministic compiler emits a candidate manifest and tests.
5. The independent Framework Verifier runs the acceptance suite.
6. The package remains `PENDING_PARENT_CERTIFICATION`; Agent D and the governed human process remain mandatory.
7. Only a separate release receipt can enable MCP, public, or commercial states.

## Source-generation quarantine

The retained recovery generation is preserved as title-level evidence with bodies still marked for reconstruction. A detached, incompatible generation does not certify it and remains `HOLD / NEED_TO_DO`. The generations may not be co-mingled, overwritten, or silently normalized; controlled counts and lineage evidence remain outside public Git.

## Custody

Every material release artifact requires independent human-recovery and replaceable private-object-store receipts with matching checksums and a restore test. A separate secret-seal store may hold cryptographic seal material, never bulk files. Provider bindings and custody locators remain in the private control plane.

## Current evidence state

Manifest, compiler, archive-safety, additive-link, workflow-supply-chain, and unit tests pass locally. Runtime execution, live heartbeats, dual-custody restore, governance adoption, MCP publication, Stripe activation, checkout, and commercial entitlement are not proven and must not be represented as complete.
