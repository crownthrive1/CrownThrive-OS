## Superseded record

The former Phase 2.99 staggered `:00 / :15 / :30 / :45 / :55` Agent A/B/C/D/S ChatGPT relay is retired scheduling scaffolding. It is not part of the current CrownThrive production execution surface and must not be reactivated, cloned, renamed, or used as a template for new recurring external tasks.

<Warning>
  The historical relay clock never created authority, and its retirement does not erase legitimate separately governed agent, verifier, security, or supervisory capabilities that happen to use similar names.
</Warning>

## Canonical successor

Current recurrence and dispatch resolve through:

```yaml
topology_id: ct.scheduler-topology.production.v1
primary_execution:
  - ThriveBase
  - CrownThrive OS
  - Software Factory
  - Framework Factory
  - pg_cron
  - governed queues
  - provider-native workflows
connector_failure_domain:
  schedule_id: ct.schedule.external-evidence-relay.hourly.v1
  scope: due connector-dependent work only
clock_authority: none
```

The external evidence relay is a connector failure-domain, not a replacement one-agent-one-clock scheduler. It may service only due logical subroutes explicitly bound by the production topology when no certified internal executor can complete the connector portion.

## Historical model

The retired Phase 2.99 model once described a sequence similar to:

```text
:00 Agent A → :15 Agent B → :30 Agent C → :45 Agent D → :55 Agent S
```

That sequence is retained only to interpret prior changelogs, handoffs, receipts, migrations, risk reviews, and governance experiments. It has no current dispatch effect. A scheduler tick cannot cast a vote, satisfy quorum, approve a merge, grant rights or entitlements, move money, expand provider access, or perform a human-reserved action.

## Historical governance language

Prior records may refer to a five-agent voter pool, a four-of-five threshold, mandatory Agent D participation, or an hourly handoff chain. Those statements describe prior governance and scheduling experiments only. Any current approval, independent-review, risk, or authority requirement must resolve from the current registry, charter, ADR, software policy, exact evidence, and human-reserved boundary—not from this archived relay.

## Operator rule
