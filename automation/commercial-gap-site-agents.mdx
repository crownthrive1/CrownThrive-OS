# Commercial Gap Site Agents

These agents are scoped execution identities. They create no sovereign votes, quorum seats or scheduler slots. They inherit the A/B/C/D/S relay, D0–D3 authority model, specialist routes, IP disclosure gates and fail-closed commerce lifecycle.

- `ct.agent.crownthrive-launch-ops-product` owns Launch product and Ops Care preparation.
- `ct.agent.crownthrive-ready-readiness` owns readiness evidence and deterministic checks.
- `ct.agent.crownthrive-procure-vendor-sourcing` owns sourcing evidence and comparison packets.
- `ct.agent.commercial-release-packager` assembles the common per-product release package and is independently verified by `ct.chlom.agent.release-certifier`.

The existing Commercial Sites Governance Relay remains the parent. At most one non-colliding bounded packet is selected per dispatch cycle. No new external scheduler slot is added.

`concept -> candidate -> packaged -> rights_cleared -> pricing_authorized -> fulfillment_certified -> checkout_staged -> publication_staged -> accepted -> live`

A generated product, Sites preview, ZIP, hash, Drive file, database row, provider object or agent vote cannot skip a required state.
