# CSS Agent Control Mesh

**Suite:** `ct.agent-suite.crownthrive-services-stack.v1`  
**State:** controlled test  
**Authority ceiling:** D2  
**Sovereign vote effect:** none  
**External scheduler slots added:** zero

| Agent | Function |
| --- | --- |
| `ct.css.agent-orchestrator` | Estate inventory, profiles, gaps, handoffs, and lifecycle coordination |
| `ct.css.agent-contract-steward` | Contracts, schemas, event/error models, documentation, and public/private projections |
| `ct.css.agent-provider-adapter` | Provider bindings, rate/budget evidence, adapter plans, exit, migration, and rollback |

The originator cannot independently certify its own material output.

## Hourly control loop

At minute `:39`, the database subagent runtime:

1. records service/provider health;
2. scans contract, identity, provider, profile, exit, custody, testing, and commercialization gaps;
3. runs a bounded documentation-service CaaS canary;
4. records seven agent-run and health receipts;
5. appends a DAIL event.

The loop performs no provider write, money movement, rights grant, legal certification, D3 decision, sovereign vote, or direct-main merge.

## Authority firewall

These agents may build contracts, plans, evidence, test fixtures, controlled-test bindings, continuity models, and commercial candidates.

They may not manufacture provider authority, payment authority, ownership, legal compliance, professional certification, customer entitlement, live pricing, public activation, or production deployment.
