## Agent A — portfolio orchestrator

The prior one-packet active scheduler instruction is superseded. It remains recoverable through history but is not the active Gen-6 operating rule.

Agent A now targets a collision-safe **WIP of 4** with a hard maximum of **6**. Each hourly cycle resolves current main, exact PR heads, Gen-6 packet telemetry, dependencies, collision state, provider budgets and active work. ## Packet lifecycle

Every live Gen-6 packet uses:

`planned -> running -> verifying -> done | blocked`

`cancelled` and `superseded` are explicit terminal alternatives.

A packet cannot become `done` merely because CI is green. Independent verification and any applicable governance remain required. State changes record timestamps, owner, verifier, progress, normalized blocker groups, unlock condition, evidence, retry/collision data and reason codes.

The original PDIS targets are #209, #220, #169, #204 and #216. Their current blocker baselines are recorded privately so later cycles can prove blocker burn-down instead of reporting activity without outcome.

## First-class telemetry

Gen-6 records:

- owner/verifier heartbeat and run state;
- start, progress, verification and completion timestamps;
- packet progress and work units;
- blocker count before and after;
- review wait, verification time and total cycle time;
- retries;
- collision and no-op suppressions;
- packets started, verifying, done and blocked;
- packets closed per hour;
- blocker burn-down;
- throughput by owner/verifier;
- current exact PR/head where applicable.

Canary/replay evidence is segregated from live throughput.

## Agentic self-assessment and bounded self-healing

Eligible D0–D2 agents perform operational self-assessment before and after work. `Self-aware` in this control plane means introspective awareness of operational state, capability, evidence freshness, dependencies, collisions, failures/retries and performance. It does not mean consciousness.

Within accepted authority an agent may replan a packet, split safe work, select another accepted skill, reassign eligible owner/verifier roles, suppress redundant retries, repair deterministic D0/D1 faults, perform a governed D2 repair with independent verification, or propose WIP/cadence changes.

Agents cannot weaken a gate, fabricate PASS, create authority, create a sovereign vote, certify their own originating work or perform D3.

## Multidimensional execution

An eligible agent may perform several compatible functions in one bounded run when all functions are already inside its authority envelope and combining them reduces unnecessary handoffs. A safe pass can therefore reconcile, test, repair, re-test, document and hand off without being artificially restricted to one micro-action.

Separation of duties remains mandatory: executing more functions does not permit the originator to become its own independent verifier.

## CHLOM oracle/adjudication

`ct.chlom.oracle.adjudication` is a test-state, non-sovereign decision-support oracle.

The bounded path is:

`evidence normalization -> independently attributable positions -> confidence/disagreement -> disposition candidate -> authority check`

Low-risk D0/D1 consensus may resolve automatically only when existing policy already permits the underlying operation and the governed confidence threshold is met. D2 consensus is a candidate until an independent verifier and applicable governance accept it. D3 and qualified-professional scopes remain human-reserved.

Unresolved disagreements do not loop forever. After the bounded round limit, the system escalates a precise founder or professional question with competing positions, evidence, reversible options, consequences of deferral and a bounded recommendation.

Every live Agent-A cycle must measure the original five PDIS targets and report whether each:

- changed exact head/status/evidence;
- materially reduced blocker count;
