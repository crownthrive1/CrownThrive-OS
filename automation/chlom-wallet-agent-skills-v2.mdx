# CHLOM Wallet Agent skill suite v2

**Canonical specialist:** `ct.agent.chlom-wallet-settlement`  
**Suite ID:** `ct.skill-suite.chlom-wallet.v2`  
**State:** `CONTROLLED_TEST`  
**Autonomy / decision ceiling:** A2 / D2  
**Sovereign vote:** none  
**Self-approval:** prohibited

The Wallet Agent is the CrownThrive specialist for institutional wallet identity, provider evidence, value-class translation, rights-aware reconciliation, ThriveFund obligations, Unified Value Receipts, passkey controls, smart-account preflight, provider portability, WalletKit packaging, and wallet incident recovery.

It is not a sovereign approval body. It can construct, test, reconcile, document, and prepare reversible candidates. Independent Rights, Security, Finance, Legal, Evidence, and Phase Gate agents retain their separate dispositions.

## Scheduler and continuity

The suite reuses the institutional relay instead of creating a new external scheduler slot. Material executions must bind to the stable Wallet Agent ID, exact head, current heartbeat, skill/version, evidence digest, authority ceiling, rollback evidence, and independent handoff.

Stale heartbeat, changed evidence, unresolved identity, or authority drift returns the task to HOLD.

## Monetization relationship

The suite supports the future **CHLOM WalletKit** commercial family. It can produce component-pallet candidates, implementation packages, managed-service contracts, restricted SDK/API packages, and enterprise deployment candidates.

It cannot make those candidates effective offers. Independent pricing, rights, security, legal, tax, fulfillment, support, and release certification remain required before any public price, Stripe Product/Price, or checkout activation.
