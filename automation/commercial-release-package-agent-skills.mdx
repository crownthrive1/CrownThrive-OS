# Commercial Release Agent Skill Suite

The suite `ct.skill-suite.commercial-release.v1` decomposes repeatable work into independently testable skills.

| Skill | Output | Hard boundary |
| --- | --- | --- |
| `release-inventory-reconciler` | Exact SKU/version/asset digest inventory | Cannot infer missing assets |
| `rights-license-package-builder` | Rights, license, assent and provenance request | Cannot clear rights |
| `pricing-tax-evidence-builder` | Comparable ledger, credit band and tax decision request | Cannot authorize price or tax conclusion |
| `fulfillment-canary-builder` | Protected delivery, five-download/expiry policy where applicable, rollback test | Cannot expose private masters |
| `credit-checkout-webhook-builder` | Credit-redemption and signed webhook controlled-test packet | No cash checkout or live provider mutation |
| `entitlement-remedy-builder` | License/entitlement/refund/dispute/reversal test vector | Payment is not entitlement |
| `accessibility-security-builder` | Automated checks plus specialist-review request | Automated tests are not conformance certification |
| `domain-tls-package-builder` | DNS/TLS/HTTPS/canonical route evidence request | Cannot mutate DNS |
| `sites-publication-readback-builder` | ChatGPT Sites publish/readback/rollback/reapply packet | Cannot self-publish without acceptance |
| `governed-acceptance-assembler` | Exact-digest review and quorum packet | Cannot manufacture votes |
| `credential-alias-binder` | Primary/recovery Vault alias request | Raw secret return prohibited |
| `release-continuity-replicator` | Agent/skill/API/MCP continuity record | Authority and credentials never inherit |

Every skill is A0–A2 / D0–D2, non-voting, no-self-approval and evidence-producing. D3/A4, final rights, tax/legal conclusions, money movement, credential recovery and external signatures remain human-reserved.
