# Generation 6 Proprietary Factory Agent Fleet

The Generation 6 fleet contains 60 independently addressable builder agents. Fifteen role archetypes are instantiated across four lanes: Platform, Data, Culture, and Assurance.

## Role archetypes

1. Orchestration
2. Research and Gap Mining
3. Capability Architecture
4. Algorithm Synthesis
5. Skill Forge
6. Prompt Forge
7. Script Forge
8. Integration and Wiring
9. Security Red Team
10. Independent Verification
11. Archive Custody
12. Identity and Fingerprinting
13. Commercialization
14. Public Documentation
15. Continuity and Recovery

Each agent has a stable `ct.agent.gen6.factory.*` identifier, deterministic UUID, `did:ct:agent:*` identity, controller-DID binding, SHA-256 fingerprint, heartbeat interval, daily schedule, authority ceiling, and release-package reference.

## Authority model

- Execution mode: `CANDIDATE_ONLY`
- Authority ceiling: `A2`
- Decision ceiling: `D2`
- Maximum concurrent generation runs: 1
- Maximum generated assets per run: 2,100
- Required release quorum: orchestration, security red team, independent verification, and archive custody

Human or governed founder authorization remains mandatory for D3 actions, production writes, checkout activation, money movement, public secret disclosure, and authority expansion.

## Daily operating cycle

| UTC | Work packet |
|---|---|
| 00:15 | Baseline and drift audit |
| 02:00 | Gap mining and candidate generation |
| 04:00 | Security and secret-boundary scan |
| 06:00 | Commercialization scoring |
| 08:00 | Public documentation projection |
| 12:00 | Interoperability contract canaries |
| 18:00 | DAIL evidence and heartbeat rollup |
| Monday 03:00 | Weekly release-candidate package |

The service-only function `chlom_runtime.proprietary_factory_gen6_daily_tick()` updates heartbeats, records bounded run receipts, and hands off to the canonical factory orchestrator when an approved zero-argument orchestrator endpoint is available.

All registries are RLS-enabled and service-only. Generic anonymous and authenticated policies are not granted.
