Build an imprint

Authenticated execution accepts x-ct-api-key or Authorization: Bearer.

curl -X POST \
  -H 'content-type: application/json' \
  -H 'x-ct-api-key: YOUR_CROWNTHRIVE_DEVELOPER_KEY' \
  https://uipojzbnnfifsbkivxoh.supabase.co/functions/v1/cie-api/build-imprint \
  -d '{
    "name":"Example Imprint",
    "identity":"What the brand is and refuses to dilute",
    "audience":"Who it exists to serve",
    "voice":"How it communicates",
    "lanes":["products","media","commerce","advertising"]
  }'

Generate a PentaAds plan

curl -X POST \
  -H 'content-type: application/json' \
  -H 'x-ct-api-key: YOUR_CROWNTHRIVE_DEVELOPER_KEY' \
  https://uipojzbnnfifsbkivxoh.supabase.co/functions/v1/cie-api/pentaads-plan \
  -d '{
    "imprint_id":"cie:example-imprint",
    "placement_intent":"brand_awareness",
    "rights_evidence":{"state":"licensed_for_campaign"},
    "allowed_channels":["owned_media"]
  }'
