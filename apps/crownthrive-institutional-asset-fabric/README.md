# CrownThrive Institutional Asset Fabric

**Plugin ID:** `ct.plugin.institutional-asset-fabric`  
**Plugin version:** `0.1.0`  
**Runtime version:** `0.1.0`  
**MCP server:** `ct.mcp.institutional-asset-fabric`  
**State:** controlled test / governed HOLD

This directory is the public-safe MCP/App scaffold for CrownThrive's institutional asset controller. The protected runtime is deployed through the Supabase Edge Function `crownthrive-institutional-asset-fabric`.

## What the app does

Authorized CrownThrive operators can:

- inspect the sanitized asset estate;
- search assets and candidate blueprints;
- fetch one stable resource;
- inspect dependency plans;
- prepare non-executing compilation plans;
- submit evidence for independent verification;
- run controlled asset scrutiny;
- prepare history-preserving supersession plans;
- inspect asset bundles;
- generate or reconcile candidate blueprint records.

## What the app does not do

It does not:

- expose Vault values, private identity mappings or protected kernel implementation;
- generate or execute opaque native binaries;
- run arbitrary shell commands;
- modify providers;
- merge directly to `main`;
- install or submit plugins;
- publish packages;
- enable checkout or entitlements;
- move money;
- make D3 or sovereign-governance decisions.

## Candidate widget

The widget displays public-safe counts and asset-class summaries from structured tool output. It has no external network domains, no service-role access and no direct database or secret access.

## Promotion gates

Before app installation or submission, the exact package requires:

1. authenticated MCP discovery, resource and tool-call readback;
2. deployed-boundary negative secret and private-identity tests;
3. keyboard, screen-reader, zoom/reflow and mobile-device testing;
4. tenant/session isolation evidence;
5. exact package and runtime digest verification;
6. public-policy and rights review;
7. governed submission and published readback.

The package is not currently installed, submitted, published or monetized.
