## Framework Factory Execution Builder

Framework Factory packages now have a dedicated materialization lane:

`framework agent → build request → Execution Builder → exact artifact bundle → independent verifier`

This solves a throughput gap without weakening sequential promotion. Public-safe precompile may identify work in parallel; the Execution Builder may materialize bounded D0-D2 candidate artifacts; promotion still requires the framework's normal specialist, Agent D, rollback, quorum and founder gates.

The lane never changes framework order and cannot leapfrog CIE, manufacture parent certification, or convert registry growth into acceptance.
