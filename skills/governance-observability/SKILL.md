# Governance Observability Skill

## Phase 3 ownership

This is a bounded **PentaNurture™ / PentaStatus™ capability skill**, not an independent sovereign agent. PentaMerge™, PentaCloser™, and PentaCertify™ may consume its evidence through their own current contracts.

## Purpose

Classify CrownThrive governance workflow outcomes without manufacturing institutional meaning from CI transport, duplicate/cancelled jobs, or evidence-acquisition failures.

## Deterministic sequence

1. Read the exact current PR head and base identity from GitHub.
2. Verify exact Git objects are available before trusted-diff evaluation.
3. Preserve the observed validator result and failure domain without emitting sensitive raw logs.
4. Use `POLICY_HOLD` or `POLICY_DENY` only when an authoritative policy source explicitly emits that disposition.
5. Classify missing Git objects as `CI_EVIDENCE_HYDRATION_FAILURE` and source mismatch as `STALE_EXACT_HEAD`.
6. Separate deterministic documentation/security assertions from institutional policy dispositions.
7. Refresh the machine-owned PR readback without editing human-authored PR prose.
8. Route drift and remediation evidence through PentaNurture and current status through PentaStatus.
9. Route archive continuation only after the current runtime and governed scheduler binding are read back; historical CSS cadence is lineage, not current authority.

## Hard boundaries

- No direct-main merge or branch deletion.
- No vote or quorum effect.
- No D3 automation.
- No self-approval.
- No policy-disposition manufacture.
- No credential or plaintext archive export.
- No provider write, money movement, rights grant, pricing, checkout, or archive activation.

## Output

Return exact source identity, observed workflow evidence, deterministic classification, reason code, whether authoritative policy evidence was present, and whether archive runtime/scheduler state requires fresh readback. Keep CI state, runtime state, and institutional authority separate.
