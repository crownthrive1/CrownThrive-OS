# CHLOM Protocol Commercial Package

This package is the CrownThrive-controlled parent definition for the public `crownthrive/chlom-protocol` repository.

## Repository roles

**Parent:** `crownthrive1/CrownThrive-Support`

The parent retains institutional source authority, protected CHLOM IP, governance evidence, factory controls, public/private release policy and canonical commercial state.

**Child:** `crownthrive/chlom-protocol`

The child is the public and monetized commercial repository. It carries public-safe operating registries, technical specifications, verification artifacts, integration guidance and commercial licensing surfaces.

## What is projected

Only files under `commercial/chlom-protocol/public/` are eligible for the governed overlay. The projection manifest names every managed path. Unmanaged child files are retained.

## What is never projected

- credentials or raw secrets;
- private contracts and legal strategy;
- confidential source evidence;
- protected-person or customer data;
- restricted unit economics;
- unreleased source or implementation assets;
- Fingerprint implementation details;
- any parent content not intentionally placed in the public-safe source root.

## Commercial rule

Public visibility is not a license grant. Commercial implementation, redistribution, hosted services, certification, enterprise deployment and other monetized uses require the applicable CrownThrive commercial agreement.

No price, entitlement, checkout state, public API state, token state or mainnet state is inferred merely because this repository is designated as a commercial surface.
