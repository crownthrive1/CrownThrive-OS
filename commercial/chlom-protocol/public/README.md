# CHLOM™ — Commercial Public Registry & Integration Surface

**CHLOM** is CrownThrive's governed rights and institutional operating system for **Rights, Rules, Roles, Revenue, Records, and Remedies**.

> **Repository role:** This public repository is the commercial, public-safe CHLOM product surface projected from CrownThrive's governed parent. It supports technical evaluation, developer integration, public registries, verification artifacts and commercial licensing. It does **not** by itself assert a live public blockchain, token, DAO, autonomous legal authority, production oracle network, checkout, public API or CHLOM mainnet.

## Parent and child authority

The private CrownThrive parent repository owns canonical institutional product policy, protected implementation knowledge, release authority and the factory that produces the managed public overlay.

This repository is the public commercial child. Every factory-managed release carries exact upstream provenance so public material can be traced to the parent snapshot that generated it.

## Production-first doctrine

CHLOM is developed as a cloud-first, API-first, event-driven, multi-tenant and human-governed system before optional decentralized settlement. The objective is to govern assets, rights, policies, actors, revenue, evidence, agreements, corrections and remedies consistently across CrownThrive and licensed deployments.

## Six canonical functions

1. **Rights** — assets, versions, provenance, authority, permissions and restrictions.
2. **Rules** — policies, conditions, eligibility, risk and approval requirements.
3. **Roles** — organizations, actors, credentials, delegated authority and separation of duties.
4. **Revenue** — fees, allocations, royalties, commissions, holds, adjustments and reconciliation.
5. **Records** — DAIL events, evidence references, approvals, versions, agreements and audit history.
6. **Remedies** — disputes, holds, corrections, suspensions, revocations, appeals and restoration.

## Canonical terminology

- **DAIL** = **Decentralized Autonomous Information Ledger**.
- **DLA** = **Dynamic Licensing Asset**.
- Historical “Decentralized Licensing Authority” responsibilities are represented by **Licensing Stewardship / Issuer Authority**.
- Historical DAL meanings are lineage only and are not the current canonical DAIL identity.
