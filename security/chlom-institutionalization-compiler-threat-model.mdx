# CHLOM Institutionalization Compiler threat model

**State:** `CONTROLLED_TEST`  
**Production or release authority:** none

## Protected assets

- exact source snapshot identity;
- artifact bytes and SHA-256 digests;
- public/restricted classification;
- algorithm IDs, versions and invariants;
- documentation impact and source provenance;
- Rights, Security, Privacy, Finance and Commercialization states;
- rollback and scheduler contracts;
- AI-governance boundaries;
- package digest and correction lineage.

## Threats and controls

| Threat | Failure mode | Control |
| --- | --- | --- |
| Omitted work | code exists without tests, docs, recovery or threat model | required artifact-kind gate and gap resolver |
| Documentation drift | documentation describes a different implementation | artifact byte hashes and frozen source snapshot |
| Source substitution | an unrelated branch or rewritten snapshot is compiled | exact ancestor check in CI |
| Nondeterminism | identical inputs produce different manifests | compile twice and byte-compare |
| Path traversal | spec reads files outside the repository | normalized repository-root containment check |
| Symlink substitution | a declared path redirects to an external file | symlink rejection and realpath containment |
| Secret leakage | live credentials appear in a public package | secret-shape scanning and public/restricted separation |
| Restricted projection | private evidence is marked public | classification/public-projection invariant |
| Stable-ID collision | two artifacts or algorithms share an identity | duplicate-ID rejection |
| False completeness | package passes despite missing institutional controls | eleven artifact kinds plus ten control sections required |
| False rights claim | external standards are represented as CrownThrive IP | third-party provenance and Rights review state |
| False commercialization | candidate product is represented as live | effective price, Stripe and checkout boundaries fixed false |
| AI overreach | AI output approves or writes institutional state | advisory-only AI contract with no decision/write authority |
| Reviewer impersonation | compiler creates approvals or heartbeats | automatic reviewer heartbeat and receipt boundaries fixed false |
| Rollback erasure | correction overwrites prior evidence | append correction package and preserve prior digest |
| Scheduler escalation | automation publishes or releases work | no background write, signer, provider or release authority |

## Secret and privacy boundary

CICC inventories digests and metadata. It does not publish artifact bodies. Live provider keys, webhook secrets, seed phrases, private keys, raw credentials, and private fingerprint commitments are prohibited from the source package.

The compiler rejects known live-secret shapes. This is one layer of defense, not a complete substitute for repository secret scanning, Vault custody, least privilege, code review or incident response.

## Supply-chain boundary

The runtime uses the Node.js standard library. CI schema validation uses exact Ajv and `ajv-formats` versions. Third-party code remains third-party; it is not relabeled as CrownThrive proprietary IP.

Distribution, embedding and commercialization require license and provenance review appropriate to the deployment model.

## AI boundary

Future AI assistance may explain gaps, suggest documentation deltas or propose handoffs. It may not:

- change source files autonomously;
- alter classifications;
- suppress gaps;
- create reviewer decisions;
- certify security, rights, legal, tax or pricing readiness;
- create provider objects or transactions;
- advance a phase or merge a PR.

Every future AI-assisted run must preserve a model-and-prompt receipt and remain subordinate to deterministic gates and independent reviewers.

## Tested negative cases

The controlled test suite rejects:

- missing tests;
- duplicate artifact IDs;
- duplicate algorithm IDs;
- invalid source-head format;
- live boundaries set true;
- AI decision authority;
- secret-shaped content;
- restricted artifacts in public projection;
- repository path escape;
- symlinked artifacts;
- content drift without package-digest drift.

## Current disposition

Passing compiler CI proves deterministic packaging and tested guardrails. It does not prove that the underlying wallet, payment, rights, smart-account, pricing or deployment work is independently approved.
