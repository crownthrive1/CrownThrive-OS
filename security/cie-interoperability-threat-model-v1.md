# CIE Parent-Control-Plane Threat Model v1

The parent packet protects the exact child head, contract digests, non-voting authority boundary, CHLOM private-runtime boundary, rights state and sequence lock.

Primary controls: exact-head references; current-main reconciliation; Agent D mandatory parent certification; current-head OIDC for mutation; immutable protected capability digest; no public protected body; least-privilege capability binding; person-scoring prohibition; fail-closed rights/publication controls; Convergent research-only gate; no price, checkout, entitlement or certification activation.

Residual risks include contextual cultural judgment, stale cross-repository topology, documentation drift, registry metadata being mistaken for certification, and independent specialist evidence not yet accepted. Each remains a HOLD or review gate.
