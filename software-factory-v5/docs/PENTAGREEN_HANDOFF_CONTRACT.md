# PentaGreen Skills Handoff Contract

**Contract:** `ct.pentagreen.skills.handoff.v1`

Every stable skill package is handed to PentaGreen with exact fields for rights, price, tax, fulfillment, entitlement, destination, and provider readback. A package may be commercially designed and technically stable while remaining `HOLD_PROVIDER_BINDING`.

## ECAC entry condition

PentaGreen may advance a handoff to ECAC only when the exact current authority reference, provider product and price IDs, provider tax code, fulfillment destination, entitlement contract, provider destination, and reverse-readback receipt are present and internally consistent.
