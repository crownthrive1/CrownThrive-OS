# Holdings and Asset Spine

CrownThrive is being organized so the ecosystem can evolve without losing institutional lineage.

## Working entity model

The current strategic model separates long-term stewardship from day-to-day operations.

```text
Proposed CrownThrive Holdings
Portfolio stewardship · capital allocation · long-term ownership · succession
        ↓
CrownThrive, LLC
Operating ecosystem · platform operations · revenue · delivery
        ↓
CHLOM / IP governance
Rights · rules · records · licensing · remedies
        ↓
CII / ThriveFund and future SPVs
Impact · reinvestment · project-specific risk isolation
```

The Holdings layer remains a **proposed** legal/organizational structure until entity formation, ownership, tax treatment, and intercompany agreements are formally completed.

## Shared CrownThrive operating spine

The portfolio should not rebuild identity, rights, support, analytics, communications, and operations separately for every platform.

The working shared spine is:

```text
CrownThrive ID
      ↓
CrownThrive IO / MCP
      ↓
CHLOM
      ↓
OpsOasis + Collab Portal
      ↓
CrownThrive Support + CrownInsights
      ↓
CrownLytics + CrownPulse + ThrivePush
      ↓
CrownRewards + partner systems
      ↓
Portfolio corridors
```

The 68 portfolio assets use stable IDs and a fluid priority model:

- **P0 — core:** 21
- **P1 — growth:** 23

These counts are a dated planning snapshot, not a promise that every asset is currently public or production-ready.

## Stable identity, fluid state

An asset should keep the same stable institutional ID even when its status, implementation, domain, vendor, description, or operating lane changes.

Example lifecycle:

```text
Concept
→ Build
→ Revamp
→ Active
→ Monetize
→ Growth
→ Reserve
→ License
→ Sunset
```

## What remains stable

- asset identity
- lineage
- source history
- corrections
- ownership history
- prior decisions

## What may change

- status
- priority
- description
- domain
- vendor
- implementation
- public route
- monetization model
- corridor assignment

## Governing principle

The portfolio registry is the durable institutional record. Business plans, websites, Mintlify pages, and presentations are projections of that governed source—not competing sources of truth.
