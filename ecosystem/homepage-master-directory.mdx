# CrownThrive Homepage Master Directory

This page is the canonical **public-homepage projection** for CrownThrive's current institutional model. It defines what the CrownThrive.com homepage should surface and how those systems should be grouped without implying that every provider path or feature is universally production-certified.

<Warning>
  Inclusion in the institutional directory means the identity belongs in the CrownThrive ecosystem map. It does **not** by itself certify every route, feature, credential, payment rail, provider adapter, public endpoint, or commercial claim as active. Current-state labels must be evidence-backed.
</Warning>

## Institutional spine

- **CrownThrive, LLC** — operating institution and ecosystem steward.
- **Convergent Ecosystem™** — the interoperable institutional field connecting platforms, people, brands, IP, distribution, capital and shared infrastructure.
- **Hybrid Incubator™** — venture, platform and capability incubation model.
- **Cultural Imprint Engine™ (CIE)** — cultural meaning, canon, identity, narrative, representation and reuse governance.
- **Thrive Flywheel™** — discovery → participation → creation → commerce → distribution → rewards → evidence → reinvestment loop.
- **CHLOM™** — rights, rules, roles, records, revenue, remedies and bounded machine authority.
- **Penta Family™** — CrownThrive's durable institutional software, governance, execution, workforce and control systems.
- **ThriveBase™** — shared institutional data/runtime substrate.
- **CrownThrive IO™** — API, MCP, integration, control and developer surface.
- **PentaDocs™** — institutional documentation and knowledge plane.

## Homepage publishing contract

The CrownThrive.com homepage should present the institution in this order:

1. **Production \+ Convergence** identity and current-state statement.
2. The **institutional spine** — Convergent Ecosystem, Hybrid Incubator, CIE, Thrive Flywheel, CHLOM, Penta Family, ThriveBase and CrownThrive IO.
3. A dedicated **Penta Family** section linking the full Penta directory and category/individual guides.
4. The ecosystem corridor directory above, preserving each brand/platform identity.
5. Current evidence-backed metrics, releases, status and calls to action.
6. Clear links to PentaDocs, CrownThrive IO, Support/Concierge, ecosystem products and current institutional news.

## Reconciliation rule

Legacy public copy that still presents an earlier phase as current must be corrected or explicitly labeled historical. Public-facing state should follow current authoritative institutional records, while historical documents remain available as lineage/context and never independently authorize execution.
