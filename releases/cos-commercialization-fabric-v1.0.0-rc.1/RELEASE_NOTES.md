# COS V1 Commercialization Fabric 1.0.0-rc.1

This release candidate introduces the first unified CrownThrive commercialization control plane for production-certified plugins, pallets, modules, packages, APIs/MCP assets, and related component classes.

## Included

- deterministic discovery and explicit certification admission;
- machine-readable withheld reasons and component/version conflict convergence instead of silent promotion;
- universal Git, GitHub Release, OCI, JSON Schema, OpenAPI, and MCP install contracts;
- deterministic installable metadata-adapter packages for npm, PyPI, Maven, NuGet, Cargo, Go, Composer, RubyGems, SwiftPM, Dart/pub.dev, and OCI;
- free Community Discovery evaluation candidate, held until exact-head independent verification;
- negotiated commercial request-quote lane without invented pricing;
- CHLOM Wallet intent validation bound to the existing Base/native-USDC runner policy;
- zero unattended paid value unless separately authorized and certified;
- server-neutral OpenAPI 3.1 plus complete MCP tool contracts, hot/warm/cold dispatch envelopes, and outage degradation;
- deterministic ZIP/TAR packaging, SHA-256 checksums, SPDX 2.3 SBOM, provenance, and rollback.
